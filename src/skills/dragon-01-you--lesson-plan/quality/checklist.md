# 教案质量检查清单（12项）

## 使用方法

生成教案后，逐项检查。不合格项需带反馈重试。

---

## 检查项

### 1. Bloom's动词检查
- [ ] 学习目标是否使用可测量动词
- [ ] 是否避免了"了解"、"掌握"、"学会"等不可测量动词
- [ ] 动词层级是否与教学内容匹配

**不合格处理：** 替换为可测量动词（参考 bloom-verbs.md）

### 2. 时间总和验证
- [ ] 各环节时间是否列出
- [ ] 各环节时间总和是否等于总时长
- [ ] 时间分配是否合理（导入≤15%，主体≥60%，总结≤15%）

**不合格处理：** 调整时间分配，确保总和正确

### 3. 差异化完整性
- [ ] 是否包含ELL（英语学习者）策略
- [ ] 是否包含SPED（特殊需求）策略
- [ ] 是否包含Gifted（资优扩展）策略
- [ ] 每个差异化版本是否有具体材料

**不合格处理：** 补充缺失的差异化部分

### 4. 标准对齐检查
- [ ] 是否引用了课程标准
- [ ] 标准引用是否包含框架+代码+全文
- [ ] 学习目标是否与标准对齐

**不合格处理：** 添加标准引用，确保对齐

### 5. 学习目标可测量性
- [ ] 学习目标是否可观察
- [ ] 学习目标是否可评估
- [ ] 学习目标是否包含条件和标准

**不合格处理：** 重写学习目标，使其可测量

### 6. 活动逻辑连贯性
- [ ] 各环节之间是否有逻辑联系
- [ ] 是否有清晰的过渡
- [ ] 难度是否逐步递进

**不合格处理：** 调整环节顺序，添加过渡

### 7. 评估与目标对齐
- [ ] 课前测验是否覆盖前置知识
- [ ] 课后测验是否覆盖学习目标
- [ ] 测验题型是否多样

**不合格处理：** 补充测验题目，确保覆盖

### 8. 材料清单完整性
- [ ] 是否列出所有需要的材料
- [ ] 材料是否与活动匹配
- [ ] 是否包含数字资源

**不合格处理：** 补充材料清单

### 9. 语音匹配评分
- [ ] 语言风格是否符合教师配置
- [ ] 句子长度是否合适
- [ ] 是否使用了教师常用表达

**不合格处理：** 调整语言风格

### 10. 中文表达规范性
- [ ] 是否符合教学语言规范
- [ ] 是否有语法错误
- [ ] 是否有错别字

**不合格处理：** 修正表达错误

### 11. 误解点真实性
- [ ] 是否是学生真正会犯的错误
- [ ] 误解描述是否准确
- [ ] 正确理解是否清晰

**不合格处理：** 替换为真实的常见误解

### 12. 练习题有效性
- [ ] 练习题是否能检测理解程度
- [ ] 难度是否合适
- [ ] 是否有梯度

**不合格处理：** 调整练习题难度和数量

---

## 评分标准

| 等级 | 合格项数 | 说明 |
|------|---------|------|
| 优秀 | 12/12 | 所有检查项都合格 |
| 良好 | 10-11/12 | 基本合格，需小幅调整 |
| 中等 | 8-9/12 | 需要较多调整 |
| 及格 | 6-7/12 | 基本框架可用 |
| 不及格 | <6/12 | 需要重新设计 |

**目标：** 所有教案必须达到"良好"及以上等级
