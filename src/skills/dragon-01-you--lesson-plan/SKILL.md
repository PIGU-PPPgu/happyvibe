# 备课/写教案 Skill

为K-12教师生成专业、可直接使用的教案。基于6个开源项目最佳实践整合。

## When to use this skill

当用户的请求包含以下内容时触发：

- "教案"、"备课"、"教学设计"、"课程设计"
- "帮我写一份XX的教案"
- "帮我设计一节XX课"
- "XX课怎么上"
- "XX的教学目标怎么写"
- "帮我做一节XX的PPT"
- "帮我写一份教学计划"

**反触发（不要使用此skill）：**
- 用户只是在讨论教学理论，不是要生成教案
- 用户问的是教学方法论，不是具体教案
- 用户要的是学习材料，不是教学设计

## Inputs

### 必需参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **topic** | 课题/教学内容 | "牛顿第二定律"、"二次函数" |

### 可选参数

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| **subject** | 学科 | 从topic推断 | "物理"、"数学"、"语文" |
| **grade** | 年级 | 询问 | "高一"、"初三"、"小学三年级" |
| **duration** | 课时时长 | 45分钟 | "45分钟"、"90分钟" |
| **objective** | 教学目标 | 自动生成 | "让学生掌握F=ma" |
| **method** | 教学方法 | 渐进式释放 | "探究式"、"5E" |
| **standard** | 课程标准 | 自动匹配 | "人教版高中物理必修一" |
| **style_file** | 风格文件路径 | 无 | "~/.eduagent/soul.md" |

## Workflow

### Step 1: 智能推断

1. 解析用户输入，提取所有可推断的参数
2. 检查缺失的必需参数
3. 如有缺失，询问一个问题
4. 确认推断结果（可选）

### Step 2: 风格学习

1. 检查是否提供了style_file
2. 如有，加载并解析风格配置
3. 如无，询问是否提供旧教案进行风格分析
4. 如拒绝，使用默认风格

### Step 3: RAG检索

1. 基于学科+年级+主题构建检索查询
2. 检索相关教案（优先Proven Templates）
3. 构建有界上下文（≤3200字符）
4. 输出参考教案片段

### Step 4: 教案生成

1. 按Schema生成教案
2. 执行12项质量检查
3. 不合格项带反馈重试（最多3次）
4. 输出合格教案

### Step 5: 链式生成

询问用户需要哪些附加产物：
- 学生讲义（去除教学提示）
- 教学PPT（MARP格式）
- 差异化版本（ELL/SPED/Gifted）
- 评估工具（测验+评分标准）
- 概念图（Mermaid格式）

### Step 6: 评分反馈

1. 请用户对教案评分（1-5星）
2. ≥4星 → 保存为Proven Template
3. 收集改进建议
4. 更新风格配置（可选）

## Edge cases（边界情况）

| 情况 | 处理方式 |
|------|---------|
| 用户未指定年级 | 询问"这是哪个年级的课？" |
| 用户未指定学科 | 从topic推断，无法推断则询问 |
| 用户要求的时长不合理（如5分钟） | 提示"5分钟可能太短，建议至少15分钟。要调整吗？" |
| 用户要求的学科不在支持列表 | 告知"暂不支持该学科，但可以尝试生成通用教案" |
| 用户提供旧教案进行风格分析 | 提取语言风格、教学偏好、常用模板 |
| 用户要求生成PPT但无MARP | 提供MARP安装指南，或生成纯Markdown版本 |

## Quality bar（质量标准）

每个生成的教案必须满足：

1. **完整性** — 所有必需部分都存在
2. **准确性** — 教学内容准确无误
3. **可测量性** — 学习目标使用Bloom's可测量动词
4. **时间一致性** — 各环节时间总和等于总时长
5. **差异化** — 包含ELL/SPED/Gifted三个差异化版本
6. **标准对齐** — 对齐相应课程标准
7. **实用性** — 教师可直接使用，无需大幅修改
8. **风格匹配** — 符合教师风格（如有风格配置）

---

## What NOT to do（禁止事项）

1. **不要** 生成没有具体教学内容的空洞教案
2. **不要** 使用"让学生了解"等不可测量的动词
3. **不要** 忽略差异化教学部分
4. **不要** 生成时间分配不合理的教案
5. **不要** 编造不存在的课程标准
6. **不要** 生成与年级水平不符的内容
7. **不要** 一次问多个问题
8. **不要** 在用户未要求时自动调用其他Skill
9. **不要** 生成没有练习和评估的教案
10. **不要** 忽略常见误解部分

## 达尔文评分维度

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 完整性 | 20% | 是否包含所有必需部分 |
| 准确性 | 20% | 教学内容是否准确 |
| 实用性 | 20% | 教师能否直接使用 |
| 差异化 | 15% | 是否满足不同学生需求 |
| 风格匹配 | 10% | 是否符合教师风格 |
| 创新性 | 10% | 是否有创新设计 |
