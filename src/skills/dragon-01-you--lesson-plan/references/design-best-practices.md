## 一、知识卡片设计模式

### 1.1 卡片内容结构

**Anki标准结构：**
```
正面（问题/标题）
├── 核心问题
├── 关键词提示
└── 难度标识

背面（答案/详情）
├── 完整答案
├── 解释说明
├── 相关链接
└── 记忆技巧
```

**知识卡片元数据：**
```yaml
metadata:
  tags: [物理, 力学, 牛顿定律]
  created: 2026-08-06
  reviewed: 3
  difficulty: medium
  mastery: 75%
  next_review: 2026-08-13
```

### 1.2 卡片布局模式

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| 瀑布流网格 | 浏览、发现 | 视觉丰富，适合图片多的卡片 |
| 看板列式 | 管理、分类 | 按状态分列，适合任务管理 |
| 列表式 | 检索、排序 | 信息密度高，适合搜索 |
| 时间轴 | 复习、回顾 | 按时间排列，适合间隔重复 |

### 1.3 交互设计

**卡片翻转动画：**
```css
.card {
  perspective: 1000px;
  transition: transform 0.6s;
  transform-style: preserve-3d;
}
.card:hover {
  transform: rotateY(180deg);
}
```

**滑动评分（Anki风格）：**
- 左滑：忘记（1天后复习）
- 上滑：困难（3天后复习）
- 下滑：良好（7天后复习）
- 右滑：简单（14天后复习）

## 二、教学内容排版设计

### 2.1 认知负荷理论应用

**降低外在认知负荷：**
- 分块呈现：每页一个核心观点
- 消除冗余：文字和图示不重复
- 信号标注：用颜色/图标突出重点
- 空间邻近：相关内容放在一起

**优化相关认知负荷：**
- 多模态：文字+图示+音频
- 样例效应：提供完整示例
- 自我解释：引导学生思考

### 2.2 视觉层次设计

**F型阅读模式：**
```
┌─────────────────────────────────┐
│ ████████████████████            │ ← 标题（第一眼）
│ ████████████████                │ ← 副标题
│ ████████████                    │ ← 正文首行
│ ████████████████████████████████│
│ ████████████████████████████████│
│ ████████████                    │ ← 关键信息
└─────────────────────────────────┘
```

**Z型浏览模式：**
```
┌─────────────────────────────────┐
│ ①                            ② │
│                                 │
│                                 │
│ ③                            ④ │
└─────────────────────────────────┘
```

### 2.3 可访问性优先设计

**WCAG 2.1标准：**
- 对比度：4.5:1以上（AA级），7:1以上（AAA级）
- 字体大小：正文16px以上，标题24px以上
- 行高：1.5-2倍字号
- 段间距：至少2倍行高

### 5.2 排版参数

**中文排版最佳实践：**

### 5.3 对比度验证

**WCAG对比度要求：**
| 元素 | 最低对比度 | 推荐对比度 |
|------|-----------|-----------|
| 正文文字 | 4.5:1 | 7:1 |
| 大号文字 | 3:1 | 4.5:1 |
| 图形组件 | 3:1 | 4.5:1 |

**对比度计算公式：**
```
对比度 = (L1 + 0.05) / (L2 + 0.05)
其中 L1 是较亮颜色的相对亮度，L2 是较暗颜色的相对亮度
```

## 七、教学设计模型

### 7.1 ADDIE模型

```
Analysis（分析）
├── 学情分析：学生已知什么？能做什么？
├── 内容分析：教什么？重点难点？
└── 环境分析：在哪教？有什么资源？

Design（设计）
├── 目标制定：学生要学会什么？
├── 内容组织：怎么排列内容？
└── 评估设计：怎么证明学会了？

Development（开发）
├── 资源制作：PPT、讲义、视频
└── 活动设计：导入、新授、练习

Implementation（实施）
├── 教学执行：按计划上课
└── 过程监控：观察学生反应

Evaluation（评估）
├── 形成性评估：课堂观察、提问
└── 终结性评估：测验、作业
```

### 7.2 UbD逆向设计

```
Step 1：确定预期学习结果
├── 大概念：核心概念是什么？
├── 基本问题：学生要思考什么问题？
└── 学习目标：学生要学会什么？

Step 2：设计评估证据
├── 表现性任务：学生要做什么来证明？
└── 其他证据：测验、观察、对话

Step 3：规划教学活动
├── 学习活动：怎么帮助学生达到目标？
└── 教学资源：需要什么材料？
```

### 7.3 Bloom认知层级应用

| 层级 | 动词 | 教学活动 | 评估方式 |
|------|------|---------|---------|
| 记忆 | 列出、描述、识别 | 讲解、阅读 | 选择题、填空题 |
| 理解 | 解释、举例、比较 | 讨论、演示 | 简答题、概念图 |
| 应用 | 运用、解决、计算 | 练习、实验 | 应用题、实验报告 |
| 分析 | 分析、比较、区分 | 案例分析、探究 | 分析题、研究报告 |
| 评价 | 评估、评判、论证 | 辩论、评审 | 论文、作品评价 |
| 创造 | 设计、构建、创作 | 项目、创作 | 作品、设计方案 |

## 八、差异化教学框架

### 8.1 Tomlinson四维度

**内容差异化：**
- 基础版：简化内容、提供视觉辅助
- 标准版：正常教学内容
- 扩展版：增加深度和广度

**过程差异化：**
- 基础版：更多脚手架、分步指导
- 标准版：正常教学流程
- 扩展版：更多自主探究

**产品差异化：**
- 基础版：选择题、填空题、口头回答
- 标准版：简答题、小论文
- 扩展版：研究项目、创意作品

**环境差异化：**
- 物理环境：座位安排、安静角落
- 心理环境：安全、支持、挑战
- 社会环境：独立/配对/小组

### 8.2 UDL通用学习设计

**原则1：提供多种表征方式**
- 视觉：图表、图像、视频
- 听觉：讲解、音频、讨论
- 触觉：实物操作、模型

**原则2：提供多种行动和表达方式**
- 书写：书面报告、论文
- 口头：口头报告、辩论
- 动手：模型制作、实验

**原则3：提供多种参与方式**
- 自主选择：提供选项让学生选择
- 挑战水平：不同难度的任务
- 合作方式：个人/配对/小组

## 九、评分标准(Rubric)设计

### 9.1 分析型Rubric框架

**SOLO分类法：**
| 层次 | 描述 | 示例 |
|------|------|------|
| 前结构 | 没有理解 | 无法回答 |
| 单点结构 | 一个相关点 | 提到一个因素 |
| 多点结构 | 多个相关点 | 列举多个因素 |
| 关联结构 | 点之间有联系 | 分析因素关系 |
| 抽象扩展 | 提炼原理 | 归纳规律 |

### 9.2 Rubric设计最佳实践

**实践1：从学生作品样本出发**
- 先收集真实学生作品（优秀/中等/需改进）
- 从作品中提取区分不同水平的特征
- 用这些特征构建等级描述

**实践2：使用具体、可观察的行为动词**
- 避免：清晰、深入、较好、适当
- 使用：列出3个例子、用5句话解释、包含2个以上角度

**实践3：等级描述要有"锚定样本"**
- 每个等级配一个真实学生作品作为锚定
- 教师评分前先看锚定样本校准

**实践4：Rubric要与学习目标对齐**
- 每个rubric维度必须对应一个或多个学习目标
- 学习目标的Bloom层级决定rubric的复杂度

**实践5：学生参与rubric制定**
- 让学生讨论"什么是好的表现"
- 学生参与制定标准后，对标准的理解更深

## 十、综合应用建议

### 10.1 教案设计清单

```
□ 教学目标明确（Bloom层级对应）
□ 教学内容结构化（大概念统领）
□ 教学活动多样化（多模态）
□ 评估方式多元化（过程+结果）
□ 差异化策略覆盖（ELL/SPED/Gifted）
□ 视觉设计规范（配色、排版）
□ 可访问性达标（WCAG标准）
□ 技术工具适配（MARP/Typst/python-pptx）
```

### 10.2 技术栈推荐

| 需求 | 推荐工具 | 理由 |
|------|---------|------|
| 快速生成PPT | MARP | 轻量、易用 |
| 精美PDF | Typst | 排版质量高 |
| 程序化生成 | python-pptx | 精确控制 |
| 知识库网站 | Docsify | 零配置 |
| 格式转换 | Pandoc | 万能 |
| 中国风设计 | Shuimo UI | 专业 |

### 10.3 设计原则总结

1. **以学生为中心**：从学情出发，关注学习效果
2. **素养导向**：对接核心素养，培养关键能力
3. **认知科学驱动**：降低认知负荷，优化学习体验
4. **可访问性优先**：WCAG标准，包容所有学生
5. **技术赋能**：善用AI工具，提高效率
