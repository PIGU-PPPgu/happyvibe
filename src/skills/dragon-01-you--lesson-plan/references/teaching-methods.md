# 教学方法详解

## 渐进式释放（Gradual Release of Responsibility）

**适用：** 大多数学科和年级

**流程：**
1. **I Do（教师示范）** — 教师演示，学生观察
2. **We Do（共同练习）** — 师生一起做，逐步放手
3. **You Do（独立练习）** — 学生独立完成

**优势：** 结构清晰，易于操作，适合新手教师

---

## 5E教学法

**适用：** 科学学科（物理、化学、生物）

**流程：**
1. **Engage（引入）** — 激发兴趣，引出问题
2. **Explore（探索）** — 学生自主探索，收集证据
3. **Explain（解释）** — 学生解释发现，教师补充
4. **Elaborate（拓展）** — 应用到新情境
5. **Evaluate（评估）** — 检验学习效果

**优势：** 以学生为中心，培养探究能力

---

## 探究式教学

**适用：** 需要培养思维能力的学科

**流程：**
1. 提出问题
2. 形成假设
3. 设计实验
4. 收集数据
5. 分析结论
6. 交流分享

**优势：** 培养科学思维和问题解决能力

---

## 讲授式教学

**适用：** 知识传递为主的场景

**流程：**
1. 导入（5%）
2. 讲解（60%）
3. 举例（20%）
4. 总结（10%）
5. 作业（5%）

**优势：** 信息量大，效率高

---

## 选择建议

| 场景 | 推荐方法 |
|------|---------|
| 新概念引入 | 渐进式释放 |
| 科学实验 | 5E教学法 |
| 培养思维 | 探究式教学 |
| 知识传递 | 讲授式教学 |
| 复习巩固 | 渐进式释放 |
| 综合应用 | 探究式教学 |
