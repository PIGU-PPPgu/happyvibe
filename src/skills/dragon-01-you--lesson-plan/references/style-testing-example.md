## 教师提供的旧教案样本

### 样本1：《自由落体运动》

**教学目标：**
1. 理解自由落体运动的概念
2. 掌握自由落体运动的规律
3. 能够运用自由落体运动公式解决问题

**教学过程：**
1. 导入：通过生活中的例子引入自由落体运动
2. 新授：讲解自由落体运动的定义、特点、公式
3. 练习：完成课本例题
4. 总结：回顾本节课重点内容

**语言风格特点：**
- 使用"同学们好"开头
- 使用"首先...其次...最后..."结构
- 使用"请注意"强调重点
- 使用"我们来..."引导活动

### 样本2：《牛顿第一定律》

**教学目标：**
1. 理解牛顿第一定律的内容
2. 理解惯性的概念
3. 能够运用牛顿第一定律解释现象

**教学过程：**
1. 导入：通过实验演示引入牛顿第一定律
2. 新授：讲解牛顿第一定律的内容、惯性的概念
3. 练习：完成课本例题和思考题
4. 总结：回顾本节课重点内容

**语言风格特点：**
- 使用"我们来..."引导活动
- 使用"请思考"引导学生思考
- 使用"通过这个实验，我们可以看到..."总结实验
- 使用"同学们，你们发现了吗？"互动

### 生成的教案片段

**导入（10分钟）：**
同学们好！今天我们来学习牛顿第二定律。

首先，我们来看一个实验。请看这个小车，我推它一下，它就会运动。我推得越用力，它运动得越快。这说明什么呢？

同学们，你们发现了吗？（预期：力越大，加速度越大）

通过这个实验，我们可以看到：力和加速度之间存在关系。这就是我们今天要学习的牛顿第二定律。

**新授（25分钟）：**
我们来学习牛顿第二定律的内容。

请注意，牛顿第二定律的表达式是：F = ma

其中：
- F是力（单位：牛顿）
- m是质量（单位：千克）
- a是加速度（单位：米/秒²）

我们来做一个练习。请计算：一个质量为2kg的物体，受到10N的力，加速度是多少？

（学生计算，教师巡视指导）

同学们，你们算出来了吗？（预期：a = F/m = 10/2 = 5m/s²）

通过这个练习，我们可以看到：力越大，加速度越大；质量越大，加速度越小。

**练习（7分钟）：**
我们来完成课本第XX页的练习题。

请注意，第1题是基础题，第2题是提高题，第3题是挑战题。请大家根据自己的水平选择完成。

（学生练习，教师巡视指导）

**总结（3分钟）：**
同学们，今天我们学习了牛顿第二定律。

首先，我们学习了牛顿第二定律的内容：F = ma
其次，我们学习了力和加速度的关系
最后，我们通过练习巩固了所学知识
