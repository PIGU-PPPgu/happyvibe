# 差异化教学策略库

## ELL（英语学习者）策略

### 语言支持
- 提供双语词汇表（中英对照）
- 使用简单句式，避免复杂从句
- 提供图文对照材料
- 使用视觉辅助（图示、表格、流程图）
- 提供句型框架（sentence frames）

### 教学策略
- 小组合作学习，搭配母语同伴
- 使用TPR（全身反应法）
- 提供预习材料，提前熟悉词汇
- 允许使用母语记录，再翻译
- 使用手势和肢体语言辅助

### 评估调整
- 允许使用双语词典
- 延长考试时间
- 提供口头评估选项
- 使用图片-based测验

---

## SPED（特殊需求）策略

### 学习障碍
- 分解任务为小步骤
- 提供步骤检查清单
- 使用多感官教学（视觉+听觉+触觉）
- 提供图形组织器
- 允许使用辅助技术

### 注意力缺陷
- 缩短任务时间，增加休息
- 提供安静的学习环境
- 使用计时器管理时间
- 提供座位选择
- 使用非语言提示

### 肢体障碍
- 提供替代输入方式（语音输入）
- 调整座位位置
- 提供大字版材料
- 允许使用辅助设备

### 情绪行为
- 提供安全空间
- 建立清晰的规则和期望
- 使用正向行为支持
- 提供情绪调节策略

---

## Gifted（资优扩展）策略

### 深度扩展
- 提供更复杂的问题
- 引导探究本质原因
- 要求多角度分析
- 提供原始资料阅读
- 要求批判性评价

### 广度扩展
- 提供跨学科连接
- 引导探究相关主题
- 提供真实世界应用
- 要求创新解决方案
- 提供研究项目机会

### 加速学习
- 提供进阶内容
- 允许自主学习
- 提供在线资源
- 安排导师指导

---

## 学科差异化示例

### 数学
| 需求 | 策略 |
|------|------|
| ELL | 图解法、实物操作、双语公式卡 |
| SPED | 计算器辅助、步骤分解表、延长考试时间 |
| Gifted | 拓展问题、数学建模、竞赛题 |

### 语文
| 需求 | 策略 |
|------|------|
| ELL | 双语对照、拼音标注、简化文本 |
| SPED | 大字版、录音辅助、口头作文 |
| Gifted | 深度阅读、创意写作、文学分析 |

### 英语
| 需求 | 策略 |
|------|------|
| ELL | 母语支持、双语教材、语言伙伴 |
| SPED | 简化语法、视觉词汇、重复练习 |
| Gifted | 原版阅读、辩论、演讲 |

### 科学
| 需求 | 策略 |
|------|------|
| ELL | 实验为主、图示说明、双语报告 |
| SPED | 简化实验、步骤卡、安全指导 |
| Gifted | 探究实验、研究项目、科学论文 |
