# 教案风格分析方法

## 分析维度

### 1. 语言风格

| 维度 | 分析方法 | 示例 |
|------|---------|------|
| **正式程度** | 统计称谓、语气词 | "同学们"vs"学生"、"请"vs"要" |
| **句子长度** | 统计平均句长 | 短句（<15字）vs长句（>25字） |
| **用词偏好** | 统计高频词 | 常用"咱们"vs"我们"、"看一下"vs"观察" |
| **修辞手法** | 识别比喻、排比等 | 是否常用类比、举例 |

### 2. 教学偏好

| 维度 | 分析方法 | 示例 |
|------|---------|------|
| **互动频率** | 统计提问次数 | 高频提问vs低频提问 |
| **互动方式** | 分析提问类型 | 开放式vs封闭式、个人vs小组 |
| **讲解方式** | 分析讲解结构 | 先讲后练vs先练后讲 |
| **反馈方式** | 分析反馈语言 | 正向鼓励vs直接纠正 |

### 3. 结构偏好

| 维度 | 分析方法 | 示例 |
|------|---------|------|
| **环节划分** | 识别主要环节 | 三段式vs四段式vs五段式 |
| **时间分配** | 统计各环节时间 | 讲解占比、练习占比 |
| **过渡方式** | 分析过渡语言 | 直接过渡vs问题过渡 |
| **总结方式** | 分析总结内容 | 教师总结vs学生总结 |

### 4. 评估偏好

| 维度 | 分析方法 | 示例 |
|------|---------|------|
| **评估频率** | 统计评估次数 | 每环节评估vs课后评估 |
| **评估方式** | 分析评估形式 | 口头vs书面、个人vs集体 |
| **题目类型** | 分析题目形式 | 选择题vs简答题vs实践题 |

## 分析流程

### Step 1: 收集样本
- 收集3-5份教师的旧教案
- 确保样本覆盖不同学科和年级
- 确保样本时间跨度足够（至少1学期）

### Step 2: 提取特征

```
对每份教案：
1. 统计词频（前20个高频词）
2. 统计句长（平均句长、最长句、最短句）
3. 统计环节（主要环节、时间分配）
4. 统计互动（提问次数、互动方式）
5. 统计评估（评估次数、评估方式）
```

### Step 3: 建立模式

```
对提取的特征进行聚合：
1. 识别稳定特征（在所有样本中都出现的）
2. 识别变异特征（在不同样本中变化的）
3. 建立风格模式（语言风格+教学偏好+结构偏好+评估偏好）
```

### Step 4: 生成配置

```yaml
# soul.md 配置文件
teacher:
  name: "教师姓名"
  style:
    formality: "正式但亲切"
    sentence_length: "中等"
    interaction_frequency: "高频"
    feedback_style: "正向鼓励"
  teaching:
    preferred_method: "渐进式释放"
    warm_up: "5分钟复习"
    main_lesson: "讲解15分钟+练习20分钟"
    summary: "学生总结+教师补充"
  assessment:
    frequency: "每个环节"
    method: "口头+书面"
    question_type: "开放式为主"
```

## 快速分析法（无样本时）

当教师无法提供旧教案时，使用以下快速分析法：

### 问卷调查

1. **语言风格**
   - 您通常如何称呼学生？（同学们/学生/孩子们）
   - 您喜欢用什么样的语气讲课？（亲切/正式/幽默）

2. **教学偏好**
   - 您通常如何开始一节课？（复习/故事/问题/视频）
   - 您通常如何讲解新知识？（先讲后练/先练后讲/边讲边练）
   - 您通常如何组织学生练习？（独立/小组/同伴）

3. **评估偏好**
   - 您通常何时检查学生理解？（每个环节/课后/不定期）
   - 您通常使用什么评估方式？（提问/测验/观察/作品）

### 默认配置

如果教师无法提供信息，使用以下默认配置：

```yaml
default_style:
  formality: "正式但亲切"
  sentence_length: "中等"
  interaction_frequency: "中等"
  feedback_style: "正向鼓励"
  preferred_method: "渐进式释放"
  warm_up: "5分钟复习"
  main_lesson: "讲解15分钟+练习20分钟+总结5分钟"
  assessment_frequency: "每个环节"
  assessment_method: "口头+书面"
```

## 风格注入方法

### 语言注入

```
根据风格配置调整语言：
- 正式程度：调整称谓、语气词
- 句子长度：控制句子复杂度
- 用词偏好：使用教师常用词汇
- 修辞手法：模仿教师的修辞风格
```

### 结构注入

```
根据风格配置调整结构：
- 环节划分：按照教师偏好划分环节
- 时间分配：按照教师偏好分配时间
- 过渡方式：使用教师常用的过渡语言
- 总结方式：按照教师偏好进行总结
```

### 互动注入

```
根据风格配置调整互动：
- 互动频率：按照教师偏好设置提问次数
- 互动方式：使用教师常用的互动方式
- 反馈方式：模仿教师的反馈风格
```

# 伪代码
def word_frequency(text):
    words = jieba.cut(text)
    freq = Counter(words)
    return freq.most_common(20)

### 句长统计

```python
# 伪代码
def sentence_length(text):
    sentences = re.split(r'[。！？]', text)
    lengths = [len(s) for s in sentences if s]
    return {
        'avg': sum(lengths) / len(lengths),
        'max': max(lengths),
        'min': min(lengths)
    }
```

### 环节识别

```python
# 伪代码
def identify_sections(text):
    patterns = ['导入', '新授', '练习', '总结', '作业']
    sections = []
    for p in patterns:
        if p in text:
            sections.append(p)
    return sections
```
