## PPT设计原则

1. **简洁明了** — 每页不超过5个要点
2. **字体清晰** — 使用大字体（≥24pt）
3. **颜色对比** — 深色背景+浅色文字或反之
4. **图文并茂** — 适当使用图片和图表
5. **动画适度** — 不要过度使用动画
6. **一致性** — 保持统一的风格
7. **可读性** — 确保最后一排学生能看清

## MARP使用方法

### 安装

```bash
# 安装MARP CLI
npm install -g @marp-team/marp-cli

# 或使用npx
npx @marp-team/marp-cli
```

### 生成PPT

```bash
# 生成PDF
marp slides.md --pdf

# 生成PPTX
marp slides.md --pptx

# 生成HTML
marp slides.md --html
```

### VS Code插件

1. 安装 "Marp for VS Code" 插件
2. 打开.md文件
3. 点击预览按钮
4. 导出为PDF/PPTX/HTML
