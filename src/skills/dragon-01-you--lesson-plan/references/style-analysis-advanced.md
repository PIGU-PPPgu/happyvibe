## 1. 语言风格分析

### 词汇特征
**分析维度：**
- 专业术语使用频率
- 口语化程度
- 词汇复杂度
- 词汇多样性

**分析方法：**
```
输入：教师教案文本
处理：
1. 提取所有词汇
2. 统计专业术语数量
3. 计算口语化比例
4. 分析词汇复杂度
5. 计算词汇多样性指数
输出：词汇特征报告
```

**示例输出：**
```yaml
vocabulary_features:
  technical_terms: 45  # 专业术语数量
  colloquial_ratio: 0.3  # 口语化比例
  complexity_score: 7.5  # 复杂度评分（1-10）
  diversity_index: 0.85  # 多样性指数（0-1）
```

### 句式特征
**分析维度：**
- 句子长度
- 句式结构（简单句/复合句/复杂句）
- 修辞手法使用
- 语气词使用

**分析方法：**
```
输入：教师教案文本
处理：
1. 分割句子
2. 计算句子长度
3. 分析句式结构
4. 识别修辞手法
5. 统计语气词
输出：句式特征报告
```

**示例输出：**
```yaml
sentence_features:
  average_length: 18  # 平均句子长度
  simple_ratio: 0.4  # 简单句比例
  compound_ratio: 0.35  # 复合句比例
  complex_ratio: 0.25  # 复杂句比例
  rhetorical_devices: ["比喻", "排比", "设问"]  # 修辞手法
  modal_particles: ["吧", "呢", "啊"]  # 语气词
```

### 语气特征
**分析维度：**
- 指令语气
- 鼓励语气
- 疑问语气
- 感叹语气

**分析方法：**
```
输入：教师教案文本
处理：
1. 识别指令句
2. 识别鼓励句
3. 识别疑问句
4. 识别感叹句
5. 计算各语气比例
输出：语气特征报告
```

**示例输出：**
```yaml
tone_features:
  instruction_ratio: 0.4  # 指令语气比例
  encouragement_ratio: 0.3  # 鼓励语气比例
  question_ratio: 0.2  # 疑问语气比例
  exclamation_ratio: 0.1  # 感叹语气比例
```

## 6. 风格匹配算法

### 相似度计算
**算法：**
```
输入：教师风格配置，生成教案风格
处理：
1. 提取教师风格特征
2. 提取生成教案特征
3. 计算各维度相似度
4. 加权计算总相似度
输出：风格匹配度
```

**权重配置：**
```yaml
weights:
  language: 0.3  # 语言风格权重
  teaching: 0.3  # 教学偏好权重
  structure: 0.2  # 结构偏好权重
  emotion: 0.1  # 情感风格权重
  cognition: 0.1  # 认知风格权重
```

**相似度计算公式：**
```
总相似度 = Σ(维度相似度 × 维度权重)
```

### 匹配度阈值
**阈值配置：**
```yaml
thresholds:
  excellent: 0.9  # 优秀匹配
  good: 0.8  # 良好匹配
  acceptable: 0.7  # 可接受匹配
  poor: 0.6  # 较差匹配
```

## 7. 风格调整策略

### 语言风格调整
**策略：**
- 调整词汇复杂度
- 调整句式结构
- 调整语气表达
- 调整修辞手法

**示例：**
```
原句：请同学们思考一下这个问题。
调整后：同学们，你们发现了吗？（更互动）
```

### 教学偏好调整
**策略：**
- 调整教学方法比例
- 调整互动方式频率
- 调整评估方式比例

**示例：**
```
原活动：教师讲解概念
调整后：小组讨论概念（更合作）
```

### 结构偏好调整
**策略：**
- 调整时间分配
- 调整活动顺序
- 调整难度梯度

**示例：**
```
原结构：导入10分钟，新授25分钟
调整后：导入8分钟，新授27分钟（更紧凑）
```

## 使用指南

### 分析流程
1. **收集样本：** 收集教师3-5份教案样本
2. **提取特征：** 提取语言、教学、结构、情感、认知特征
3. **建立模式：** 建立教师风格模式
4. **生成配置：** 生成风格配置文件
5. **应用调整：** 应用风格调整策略

### 注意事项
- 样本数量要足够（至少3份）
- 分析要全面（语言、教学、结构、情感、认知）
- 调整要适度（不要过度调整）
- 反馈要及时（收集教师反馈）
