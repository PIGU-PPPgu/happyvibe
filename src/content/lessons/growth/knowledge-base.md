> **一句话结论：Obsidian 管你的资料，Agent 管你的流程，两者接起来，就是「个人 / 学科 AI 知识库」。**

![Obsidian](/images/lessons/obsidian-logo.webp)

## 为什么是 Obsidian

- **本地存储**：数据在自己电脑上（.md 纯文本文件），不担心平台倒闭和数据安全；
- **双链与图谱**：知识点互相链接，自动生成关系图谱，越用越聪明；
- **开放格式**：Markdown 文件，任何 Agent 都能直接读写。

![Obsidian 文件夹结构](/images/lessons/obsidian-folders.webp)

培训演示的知识库目录：`00-每日笔记`、`01-班级管理`、`02-教学`、`03-自媒体`、`04-项目`、`05-个人`、`06-知识库`、`07-会议记录`、`08-资源收藏`、`09-归档`、`10-模板`……**编号开头是为了排序稳定**，这个习惯值得抄。

![Obsidian 知识图谱](/images/lessons/obsidian-graph.webp)

## Agent 接上知识库能干什么

![用 Hermes Agent 打造 Obsidian 知识库](/images/lessons/hermes-obsidian.webp)

- 「把今天的会议记录按 07-会议记录 的模板归档，并更新本周待办」；
- 「从 02-教学 里把这三年的一元二次方程教案汇总成一个复习提纲」；
- 每天自动写每日笔记，把班务留痕同步进去。

## 上手建议

- 装好 Obsidian → 建一个笔记本 → 把常用教学资料丢进去
- 在 WorkBuddy / 其他 Agent 里打开这个文件夹作为工作目录
- 对 Agent 说：「读这个文件夹，帮我整理XX」——它就会读写你的知识库
- 具体配置因 Agent 而异，参考各 Agent 的官方文档
