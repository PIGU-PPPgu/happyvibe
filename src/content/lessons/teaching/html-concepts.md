> **一句话结论：PPT 是「看」，HTML 交互页面是「玩」。能让学生动手试的概念，就别让他们只当观众。**

![抛物线交互解析](/images/lessons/physics-interactive.webp)

## 为什么交互页面赢了

看一个真实的交互课件（动图；[点开拖拖滑块](/demos/function-lab/)）：

![函数实验室：拖动参数实时变曲线](/images/demos/function.gif)

同一个「抛物线」概念：

- **PPT**：静态图 + 结论，学生被动接收；
- **HTML 交互页**：角度、距离、速度全是滑块，学生一拖，图形实时变——**变量关系自己就「看出来了」**。

而且页面可以发到班级群，学生课后还能自己玩——课堂的边界被打开了。

## 哪些概念特别适合

| 学科 | 适合交互化的概念 |
|---|---|
| 数学 | 函数图像、几何变换、概率模拟 |
| 物理 | 抛体运动、电路、光的折射 |
| 化学 | 实验步骤模拟、分子结构 |
| 地理 | 地球自转公转、等高线 |
| 英语 | 时态时间轴、语法树 |

## 三步做一个

1. 把概念 + 想要的交互方式描述给 AI（参考模板）：
```
把「____」概念做成一个交互式讲解网页：
- 核心参数可调（滑块），图形/结果实时更新
- 先让学生自己试，再点「看解析」分步讲解
- 单文件 HTML，手机也能打开
```
2. 浏览器打开检查：参数范围对不对、结论对不对（**专业判断永远是你来**）；
3. 发班级群 / 课堂投屏。

真实案例见 [用 HTML 解题](/modules/creation/html-solving/)；课堂演示的更多玩法见下一课。
