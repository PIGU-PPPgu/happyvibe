> **一句话结论：不要让 AI「帮我写个教案」，要让它按你的备课 SOP 产出一整套备课包——先做 MVP，再逐步个性化。**

## 思路：先做「自动备课」MVP

培训里给出的演进路线——**为什么不直接上复杂方案**：

- 水太直接，不需要复杂 API
- 低垂这挂空，立即可用
- 可以迭代化

实现方案（五步）：用户输入（如「讲一次二次式」）→ 联网搜资源 → AI 技巧 → 批量生成（课件页 → 讲义 → 优质视频 → 练习）→ 打包发送 → 输出完整备课包。

![自动备课 MVP 方案](/images/lessons/lesson-mvp.webp)

中期再上「个性化推荐」：记录学生选课/每次点击级视频偏好，逐步积累到 MEMORY；分析错题、匹配风格、调整难度。

## 产出的备课包长什么样

![完整备课包](/images/lessons/lesson-pack.webp)

一次生成的《单项式与多项式》备课包包含：

- ✓ 知识点：单项式与多项式
- ✓ 年级：七年级
- ✓ 课时：45 分钟
- ✓ 3 个精选教学视频（已下载）
- ✓ 15 道课堂练习题（10 选择 + 5 计算）
- ✓ 完整教学流程设计
- ✓ 课后作业布置
- ✓ 教学建议

![生成的讲义](/images/lessons/lesson-handout.webp)

配套讲义同步输出（概念讲解、正反例、巩固练习），可直接打印。

## 提示词模板（照抄改主题）

```
你是一位有 15 年经验的初中数学老师。
请为「________」（年级：____，课时：45 分钟）生成完整备课包：
1. 教学目标（按课标） 2. 知识点讲解（含正反例）
3. 15 道分层练习（10 选 5 填，附答案）
4. 45 分钟课堂流程（精确到分钟）
5. 课后作业与教学建议
开始前，先问我需要确认的信息。
```

**注意**：AI 产出的练习和讲义必须过一遍你的专业核对（回看[什么时候值得用 AI](/modules/basics/when-to-use/)的核对成本原则）——备课包是你的草稿，不是你的替身。
