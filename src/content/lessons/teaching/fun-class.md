> **一句话结论：把「不能做、不敢做、做不起」的实验和演示做成网页交互，课堂的「哇」时刻可以无限次重播。**

![欧姆定律实验演示](/images/lessons/ohm-law.webp)

## 案例 1：欧姆定律实验演示

网页上直接搭出电路：调节电压、电阻滑块，电流表实时读数 `I = U / R`——

- 没有接线柱烧坏的风险，学生随便试；
- 「控制变量法」变成两根滑块的事，结论自己冒出来。

![高锰酸钾加热制取氧气](/images/lessons/chemistry-lab.webp)

## 案例 2：高锰酸钾加热制取氧气

实验步骤做成带检查点的流程页：药品用量、加热位置、收集时机、注意事项，逐步骤点亮——

- 课前预习：学生先在网页上「跑一遍」流程；
- 课上实操：出错率明显下降；
- 课后复习：随时回看，不用等实验室开放。

## 更多灵感

- 交互式程序声明类：粒子碰撞模拟、地球自转模型（参数全可调）；
- 语文/英语：把课文情景做成选择式剧情页；
- 班会课：价值观两难情境的「选择—后果」模拟器。

## 动手做一个（模板）

```
把「____实验/演示」做成交互网页：
1. 可操作的器材/参数（滑块或按钮），现象实时变化
2. 分步骤引导，每步有「为什么」说明
3. 最后 3 道自测题
输出 html 版本给我就行
```

**安全提示**：实验类页面只能辅助理解，不能替代真实操作——动手能力和安全规范还是要进实验室练。
