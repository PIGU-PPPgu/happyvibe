> **一句话结论：网页对话框适合「单文件小工具」，Trae 这类 AI IDE 适合「多文件、要迭代、当作品养」的项目。**

## 它是什么、适合谁

在[产品横评](/modules/agent/product-comparison/)里，TraeWork 的特点是「教案＋数据＋PPT＋小程序/网站」样样都行，安全分高（4.9），短板是**模式多、上手成本较高**——所以更推荐给工作坊骨干和信息科技教师。

新手路径建议：先用网页对话框做出单文件 HTML（见[用 HTML 解题](/modules/creation/html-solving/)），有迭代需求了再上 Trae。

## 和对话框的核心区别

| | 网页对话框 | Trae（AI IDE） |
|---|---|---|
| 能看到什么 | 你贴给它的内容 | 整个项目文件夹 |
| 改起来 | 每次整段重发 | 直接改对应文件，边改边预览 |
| 适合 | 一次性小工具 | 持续维护的班级小应用 |

## 上手四步（骨架）

1. **下载安装**：官网下载（地址与版本待补充），首次配置选择主题和语言；
2. **认识界面**：编辑区 / AI 对话区 / 文件树 / 预览区，四个区域各干什么；
3. **跑通第一个项目**：把你在对话框里做过的单文件工具搬进来，让它「加一个设置页，参数可以保存」——体验跨文件修改和实时预览；
4. **学会验收**：每次改完跑一遍功能清单（参考[什么时候值得用 AI](/modules/basics/when-to-use/) 的核对原则）。

## 教师场景推荐

- 班级值日/积分小应用：先做单页版，再用 Trae 加数据保存、多页面；
- 学科交互课件系列：统一模板批量改；
- 和同事协作：项目文件夹直接打包分享。
