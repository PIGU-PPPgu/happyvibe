> **一句话结论：这一课的分水岭是——AI 从「回答你」变成「替你做完并交文件」。学会喂文件、看过程、收结果三件事。**

## 第 1 步：准备一份练习用成绩表（3 分钟）

1. 在桌面空白处**右键** → 新建 → 文件夹，命名 `workbuddy-练习`；
2. 打开这个文件夹，**右键** → 新建 → Excel 表格（WPS 也一样），命名 `成绩.xlsx`；
3. 打开它，照着敲（5 行就行，不用真学生）：

| 班级 | 姓名 | 总分 |
|---|---|---|
| 七(1)班 | 学生A | 285 |
| 七(1)班 | 学生B | 262 |
| 七(2)班 | 学生C | 291 |
| 七(2)班 | 学生D | 248 |
| 七(2)班 | 学生E | 273 |

4. 保存（⌘S），关掉表格。

## 第 2 步：把文件交给 WorkBuddy

1. 打开 WorkBuddy，确认在「新建任务」页；
2. **点一下**中间大输入框；
3. 把桌面上的 `成绩.xlsx` **按住不放，拖进输入框区域**，松手；
4. 输入框里出现一个文件卡片（写着 `成绩.xlsx`）——成功了。

> **拖不进来？** 两个办法：① 点输入框左下角的 **＋** 号 → 选文件 → 找到桌面上的成绩.xlsx；② 不管拖拽，直接在话术里写清楚文件在桌面 `workbuddy-练习` 文件夹里，Agent 也能自己去找（它有读文件的权限）。

## 第 3 步：下任务（照抄）

文件卡片出现后，点回输入框，打这段话：

```
读取我上传的成绩表，做三件事：
1. 按班级统计平均分，从高到低排序
2. 找出总分最高的学生
3. 生成一份新的 Excel 文件，包含以上结果，
   保存到桌面 workbuddy-练习 文件夹里，命名为 成绩分析.xlsx
```

点黑色圆形按钮发送。

## 第 4 步：看它干活（别催）

发送后你会看到它开始**一步步执行**：列计划 → 读取文件 → 计算 → 写文件。过程中可能出现「是否允许读取文件」的确认，点**允许**。

**✅ 怎么算完成**：它回复一段总结，并且提到文件已保存。这时去桌面 `workbuddy-练习` 文件夹看——多了一个 `成绩分析.xlsx`，双击打开验收。

> **执行要多久？** 简单任务几十秒，复杂任务几分钟。看到它一直在动就是在干活；真卡住了（2 分钟完全不动），点输入框打 `继续`。

## 第 5 步：验收 + 追问（最重要的习惯）

打开生成的 Excel，核对：平均分算得对不对？（七(1)班=(285+262)/2=273.5，自己心算验证一下。）

不对就追问，这就是「核对成本」的正确用法：

```
七(2)班的平均分算错了，应该是 270.67，请重新计算并更新文件。
```

对的话再压榨一步：

```
基于这份成绩，生成 3 条给每个班的讲评要点，
追加到 Excel 的第二个工作表里。
```

## 你刚学会的工作流（记住它）

```
喂文件 → 下清楚任务（编号列点） → 等执行 → 打开产物验收 → 追问修正
```

换任何文件（Word、PDF、一叠照片）、换任何活（写总结、做对比、起名单）都是这一套。

**⚠️ 常见状况**

- 它说「找不到文件」：话术里写全路径，比如「桌面 workbuddy-练习 文件夹里的 成绩.xlsx」；
- 生成的文件没在桌面：问它「文件保存在哪里了？」——它会告诉你路径；
- 隐私提醒：练习用假数据；真实学生数据上传前，确认平台隐私条款（WorkBuddy 在腾讯云，数据不用于训练，但涉密内容仍需谨慎）。
