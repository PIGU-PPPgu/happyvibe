> **一句话结论：工作台是你电脑里的文件，数据默认存在浏览器里——自己用零成本；想手机看就免费托管上线；想多端同步再上免费云数据库。服务器？老师不需要买。**

![三档方案对比](/images/lessons/wb-storage.png)

## 八个必问问题（FAQ）

### 1. WorkBuddy 部署的吗？能用多久？

**都不是。** WorkBuddy 只是"施工队"——它把工作台**做成文件**交付给你（就像装修队交钥匙）。交付后的工作台是一个普通文件夹（index.html / app.js / styles.css），**不依赖 WorkBuddy、不依赖网络、不过期**——双击 index.html 就能用，十年后也能用。

### 2. 那我的数据存在哪里？

存在**你这台电脑的浏览器**里（技术名词叫 localStorage——浏览器给每个网站留的一块本地储物柜）。

记住三个推论：
- **换浏览器 = 换储物柜**：Chrome 里记的待办，Safari 里看不到；
- **清缓存 = 清储物柜**：浏览器"清除站点数据"会把数据清掉；
- **换电脑 = 数据不带走**：文件能拷走，柜子拷不走。

### 3. 数据会不会丢？怎么保住？

三道保险，由浅入深：

**保险一：加导出按钮**（1 分钟）。在工作台对话里补一句：

```
给工作台加一个"导出数据"按钮：把全部数据打包成一个 JSON 文件下载；
再加"导入数据"按钮：选择 JSON 文件可恢复。
```

从此每周点一下导出，文件存进你的网盘——**数据真正握在自己手里**。

**保险二：让 AI 定期提醒**。用[自动化](/modules/software/wb-08-automation/)设"每周五 17:00 提醒我导出工作台数据"。

**保险三：上第 3 档云数据库**（见问题 7），数据自动在云端，从此不操心。

### 4. 手机能不能看？

看你在哪一档：

| 档位 | 手机体验 |
|---|---|
| 第 1 档（本地文件） | 勉强：把文件夹发到手机（微信文件传输助手），手机浏览器打开——但手机上记的数据和电脑**不互通** |
| 第 2 档（免费托管） | ✓ 手机浏览器输网址即用 |
| 第 3 档（云数据库） | ✓✓ 手机电脑看到同一份数据 |

### 5. 怳拥有一个网址（像本站这样）？

免费，不需要服务器，10 分钟：

```
【发给 AI】把我的工作台部署到线上，要求：
1. 用 Cloudflare Pages（或 GitHub Pages）免费托管
2. 给我一步步的操作指引，精确到每个按钮
3. 部署完给我一个网址
```

AI 会带你走完注册→上传→上线全程。之后手机电脑打开网址都能用（注意：第 2 档的各设备数据仍然各自独立）。

### 6. 服务器要怎么买？

**不用买。** 老师场景的全部需求都能免费满足：

| 需求 | 免费方案 |
|---|---|
| 一个能访问的网址 | Cloudflare Pages / GitHub Pages（静态托管，0 元，本站就这么跑的） |
| 数据云端保存 | Supabase / 腾讯 CloudBase 免费档（够一个班用几年） |
| 定时任务 | WorkBuddy 自动化（0 元） |

真到了要买服务器那天（比如全校部署、上千人用），那是信息中心的事——把需求写给 IT，别自己掏腰包。

### 7. 想手机电脑数据同步（第 3 档）怎么办？

给 AI 发这句升级话术：

```
把我的工作台升级为云端数据版：
1. 数据存 Supabase 免费数据库（给我注册和配置的逐步指引）
2. 手机和电脑打开同一网址，看到同一份数据
3. 保留"导出 JSON"按钮，数据我随时能带走
```

配置一次约 30 分钟。这就是 [easy-vibe](https://datawhalechina.github.io/easy-vibe/zh-cn/) 教的「数据库 + 部署」路线——工具箱「进阶学习」区给它留了入口。

### 8. 学生真数据放云端安全吗？

红线三条：
- **能脱敏就脱敏**：云端版用化名/学号代替真名；
- **看清条款**：Supabase/CloudBase 是你自己的数据库，不经第三方训练——但别用来历不明的"免费 AI 空间"；
- **导出权握在手里**：任何云端方案，确认有导出按钮再上传第一行数据。
