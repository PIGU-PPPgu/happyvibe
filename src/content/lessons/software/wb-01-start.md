> **一句话结论：这一课你只需要做一件事——把 WorkBuddy 打开，对照截图把 7 个位置各点一遍。**

## 动手前

- 电脑已装 WorkBuddy（没装：浏览器打开 [workbuddy.ai](https://www.workbuddy.ai/)，点「下载」，双击下载的文件，把图标拖进 Applications 文件夹——和装微信一模一样）；
- 能正常上网。

## 第 1 步：打开它

1. 点屏幕底部的「启动台」（一个火箭图标）；
2. 打字搜 `work`，出现 WorkBuddy 图标；
3. 单击它，等待约 10 秒。

**✅ 屏幕上出现「WorkBuddy, 我帮你」几个大字，就成功了。**

> 打不开？检查右上角 Wi-Fi 是否连通；第一次打开杀毒软件可能弹窗，点「允许」。

## 第 2 步：登录

第一次打开会要求登录。点微信图标 → 手机扫码 → 手机上点「确认登录」。下次打开一般不用再登。

## 第 3 步：对照截图认位置

打开后整屏长这样（你的任务列表内容和截图不完全一样，正常）：

![WorkBuddy 主界面](/images/lessons/wb-01-main.webp)

按编号认识 **7 个位置**（先看图，再去软件里逐个点一下）：

| # | 位置 | 是干什么的 | 你现在要做的 |
|---|---|---|---|
| ① | 左上 **新建任务** | 开启一段新对话（= 开始一个新活儿） | 点它一下 |
| ② | 左侧 **助理 / 项目** | 助理=预置的助手；项目=一个主题的所有资料和任务归档 | 今天不用管 |
| ③ | 左侧 **专家·技能·连接器** | 商店：给 AI 配人手、装技能、接工具 | 点开看看，再回来 |
| ④ | 左侧 **自动化** | 定时任务（比如每天早上自动给你发天气预报+日程） | 今天不用管 |
| ⑤ | 左下 **任务列表** | 你历史干过的活，点任何一个能回看全过程 | 点开一条，再回来 |
| ⑥ | 中间 **大输入框** | 你打字下需求的地方，右上角是场景切换（日常办公/代码开发/设计创意） | 点一下输入框，看到光标闪烁 |
| ⑦ | 输入框右下 **模型名 + 圆形发送按钮** | 模型名（如 Kimi-K3）是当前用的大脑；黑色圆钮是发送 | 用鼠标悬停在模型名上，先别点 |

## 第 4 步：一个小练习

在输入框里打字（会用微信打字就会这一步）：

```
你是谁？你能帮我做什么？
```

打完点右下角的**黑色圆形按钮**（发送）。AI 会开始回答——恭喜，你已经在用 Agent 了。下一课我们正式学对话。

**⚠️ 常见状况**

- 点了发送没反应：检查输入框里有没有字；黑色按钮是不是灰色（灰色=发不了，通常是没登录或断网）；
- 界面和截图不一样：软件更新快，位置略有移动，认「名字」不认「位置」。
