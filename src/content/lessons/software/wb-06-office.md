> **一句话结论：抄作业不是丢人，是高效。下面三个任务覆盖老师 80% 的文档工作，每个都自带验收清单——抄一遍，以后只换主题。**

## 任务 A · Word 教案初稿

**什么时候用**：新学期备课、上公开课、换教材版本。

```
【目标】生成一份完整的公开课教案初稿
【输入】课题：《背影》（部编版八年级上册）；课时：1 课时（45 分钟）；班级学情：普通班，40 人
【动作】按以下结构写：教材分析 → 学情分析 → 教学目标（三维）→ 教学重难点
        → 教学过程（导入 5 分钟 / 诵读感知 10 分钟 / 精读研讨 20 分钟 / 拓展 7 分钟 / 小结作业 3 分钟，每环节写教师活动和学生活动）
        → 板书设计 → 教学反思（留空）
【约束】教学过程要具体到"教师问什么问题、预期学生怎么答"；不使用夸张的空话套话
【输出】生成 Word 文件《背影教案-初稿.docx》，放到桌面 workbuddy-练习 文件夹
【验收】教学过程每个环节都有时间标注；提问都能在课文里找到依据；总字数 1500-2500
```

**验收动作**：打开 Word，数环节、对时间、抽一个提问回课文验证。
**常见坑**：生成后直接上交——教案里的「预期学生回答」往往过于理想化，**这一栏必须由你改**。

## 任务 B · Excel 全年级成绩汇总

**什么时候用**：期中期末，收齐各班成绩表后。

```
【目标】把 6 个班的成绩表汇总成一份年级分析
【输入】桌面 workbuddy-练习/成绩 文件夹里的 6 个 Excel（格式相同：姓名/班级/语文/数学/英语/总分）
【动作】1. 合并为一张总表（加一列"班级"）
        2. 统计：各班各科平均分、年级各科平均分
        3. 列出年级总分前 20 名
        4. 用文字写 3 条年级层面能看出来的现象（如"数学两极分化"要给出数据支撑）
【约束】只生成新文件，不动 6 张原始表；所有数字保留 1 位小数；前 20 名名单用"学生A"式化名
【输出】年级成绩汇总.xlsx，放在同一文件夹
【验收】抽查一个班一门课的平均分；总表行数 = 6 个班人数之和；现象条目里必须带有具体数字
```

**验收动作**：总表行数一拉到底核对人数；随便挑一个班的数学平均分手算复核；看「现象」是不是都有数据支撑——**没有数字支撑的现象，让它补**。

## 任务 C · PPT 大纲（先大纲后成品，防止跑偏）

**什么时候用**：要做一个课件/汇报 PPT，先让 AI 出大纲对齐思路。

```
【目标】生成一份家长会 PPT 的完整大纲
【输入】本学期班级情况：期中成绩概况（一段文字我贴在下面）、班级活动 3 件、需要家长配合的 3 件事
【动作】按 40 分钟家长会设计：开场 5 分钟 → 成绩与进步 10 分钟 → 班级活动回顾 8 分钟 → 需要家长配合的事项 12 分钟 → 个别交流环节预告 5 分钟
【约束】每页只写"页面标题 + 3-5 条要点"，不写完整讲稿；成绩部分不公布排名，只讲整体和进步
【输出】直接在对话里输出大纲（每页用"第 N 页"标注）
【验收】页数 ≤ 18 页；每页要点不超过 5 条；看不到任何一个学生的名字
```

**验收动作**：先审大纲，改到满意，再说一句：

```
大纲通过了。请按这份大纲逐页生成 PPT 文件，
风格简洁（白底、深灰文字、金色点缀），保存到桌面 workbuddy-练习 文件夹。
```

**常见坑**：跳过大纲直接「给我做个家长会 PPT」——20 页做完才发现第 3 页方向就错了，返工最贵。**先大纲后成品，改大纲永远比改成品便宜。**

## 三个任务的公共验收习惯（背下来）

1. **数字必抽查**：AI 算的每个统计量，自己心算或抽一个复核；
2. **约束必核对**：约束里写了「不出现排名」，就去搜「排名」两个字；
3. **原文件必不动**：干完活回头看一眼原始文件还在不在、改没改；
4. **过稿前自用一遍**：教案自己在脑子里过一遍课堂流程，PPT 自己放映一遍——AI 的验收代替不了你的课堂判断。
