> **一句话结论：对话 = 打字 + 发送。真正要学的是「怎么打」——这一课教你三句话框架，一辈子够用。**

## 热身：先随便聊两句（1 分钟）

1. 打开 WorkBuddy，确认在「新建任务」页；
2. 点一下中间大输入框（光标开始闪烁）；
3. 打字：`帮我写一句家长会通知的开场白`；
4. 点右下角黑色圆形按钮发送；
5. 读它的回答。**随便追问一句**：`再亲切一点`——看它重新回答。

到这一步你已经超过大多数老师了。但先别得意，下面才是重点。

## 核心：三句话框架

同样的需求，这么说产出质量翻倍。以后每次下需求，照着填空：

```
【身份】你是一位有 15 年经验的班主任。
【任务】帮我写一份秋游告家长书。
【要求】500 字以内，语气亲切，列出集合时间、注意事项、回执截止日。
```

- **身份**：告诉 AI 它是谁（老师？医生？编辑？）——它就会用对应的口吻和专业度回答；
- **任务**：一句话说清要做什么，别绕弯；
- **要求**：字数、语气、必须包含的内容——你写得越具体，它猜得越少。

## 动手练：把一次普通提问改成三句话版

1. 在输入框打字（照抄，感受差别）：

```
你是一位小学二年级数学老师。
帮我出 5 道 100 以内进位加法题。
要求：由易到难，最后一道是应用题，答案单独放在最后。
```

2. 发送，看结果；
3. **追问练习**——对结果不满意是常态，接着打字：

```
第 3 题太难了，换一道简单点的。
```

4. 再试一个「要格式」的追问：

```
把题目重新排成表格，两列：题号、题目。
```

## 三个立刻能用的话术（抄进备忘录）

| 场景 | 直接照抄 |
|---|---|
| 改文风 | `把上面的内容改得口语化一点，像跟家长面对面说话` |
| 要格式 | `整理成 Markdown 表格，两列：事项、负责人` |
| 让 AI 反问 | `开始之前，先问我你需要知道的信息` |

第三条是隐藏大招：你不知道怎么描述需求时，让 AI 来问你。
