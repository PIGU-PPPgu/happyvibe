> **一句话结论：对话 = 打字 + 发送。但「帮我写个通知」和一份六要素齐备的任务说明，产出是天壤之别。**

## 热身：先随便聊两句（1 分钟）

**跟着下面的动图一起点**（这就是你要做的全部动作）：

![打开 WorkBuddy 历史任务](/images/demos/wb2-chat.gif)

1. 打开 WorkBuddy，确认在「新建任务」页；
2. 点一下中间大输入框（光标开始闪烁）；
3. 打字：`帮我写一句家长会通知的开场白`；
4. 点右下角黑色圆形按钮发送；
5. 读它的回答。**随便追问一句**：`再亲切一点`——看它重新回答。

到这一步你已经超过大多数老师了。下面是真正的分水岭。

## 三句话框架（起步版）

每次下需求，最少说清三件事：

```
【身份】你是一位有 15 年经验的班主任。
【任务】帮我写一份秋游告家长书。
【要求】500 字以内，语气亲切，列出集合时间、注意事项、回执截止日。
```

- **身份**：告诉 AI 它是谁——它就会用对应的口吻和专业度回答；
- **任务**：一句话说清做什么；
- **要求**：字数、语气、必须包含的内容。

## 任务说明六要素（高手版，来自蓝皮书方法论）

三句话不够用时（尤其是让 AI 干活的场景），升级成六要素。**照着填空就行**：

```
【目标】把这份成绩表做成给家长看的成绩单
【输入】成绩.xlsx（我上传的文件）
【动作】按班级排序；计算个人总分和班级平均分；给每个学生写一句鼓励性评语
【约束】不要修改我的原始文件；评语不出现排名和分数对比；错别字零容忍
【输出】生成「家长版成绩单.xlsx」，保存到桌面 workbuddy-练习 文件夹
【验收】我会抽查 3 名学生：分数与原表一致、评语无重复、无错别字
```

六个词各管一件事：**目标**（做成什么样）、**输入**（用什么材料）、**动作**（干哪几步）、**约束**（不许做什么——同样重要！）、**输出**（交什么、交到哪）、**验收**（我怎么检查）。

## 动手练：三个照抄任务

**任务 A · 出题**（三句话就够）：

```
你是一位小学二年级数学老师。
帮我出 5 道 100 以内进位加法题。
要求：由易到难，最后一道是应用题，答案单独放在最后。
```

**任务 B · 改格式**：

```
把上面的题目重新排成表格，两列：题号、题目。
```

**任务 C · 六要素完整版**（感受约束和验收的威力）：

```
【目标】为明天班会写一份「课间安全」讲话稿
【输入】无（基于你的常识）
【动作】先讲 1 个 30 字以内的小案例，再给 3 条安全要点，最后 1 句号召
【约束】全程不指责学生；不出现真实班级人名；口语化，像跟学生面对面说话
【输出】直接在对话里给出，300 字左右
【验收】我数一下字数，并且检查是不是真的没有出现人名
```

**✓ 检查点**：任务 C 发出后，对着它自己的输出核对约束——如果出现了人名，你就追问：`出现了人名，请替换成"有同学"，其他不变。`——**验收后追问修正**这个动作，比写话术本身更重要。

## 三个立刻能用的话术（抄进备忘录）

| 场景 | 直接照抄 |
|---|---|
| 改文风 | `把上面的内容改得口语化一点，像跟家长面对面说话` |
| 要格式 | `整理成 Markdown 表格，两列：事项、负责人` |
| 让 AI 反问 | `开始之前，先问我你需要知道的信息` |
