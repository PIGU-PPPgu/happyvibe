> **一句话结论：所有桌面级 Agent 都是同一台机器的不同外壳。你在 WorkBuddy 练的每个动作，换个软件都原样成立——顶多找 30 秒按钮在哪。**

## 为什么敢这么说

你在手把手五课里练的所有动作，拆开其实是**六个概念**。任何桌面 Agent——Trae、DeepSeek Harness、各类 Coding Agent——都由同样的六个概念拼成，只是名字不同：

| 你在 WorkBuddy 学的 | 换个软件可能叫 | 不变的本质 |
|---|---|---|
| 新建任务 / 对话 | 会话、Chat、Session | 你下需求的地方 |
| 拖文件进输入框 / 工作空间 | 工作区、Workspace、打开文件夹 | 给 AI 看你材料的方式 |
| 模型选择器（Kimi-K3、GLM-5.3…） | 模型、Brain、Provider | 换脑子；倍率/价格逻辑一模一样 |
| 默认权限（保守/自动） | 权限、Approval、Auto-run | 它自动干还是每步问你 |
| 专家 · 技能 | Agents、Skills、Rules、扩展 | 预置角色与固化流程 |
| 产物 / 生成的文件 | 产出、Artifacts、输出文件夹 | 交付物，永远要打开验收 |

**五个动作**也一样：喂文件 → 下清楚任务 → 看它执行 → 打开产物验收 → 追问修正。

## 30 秒上手任何一个新 Agent 的套路

1. 找输入框（一定在中间或底部）；
2. 找模型切换（一般在输入框附近，认「模型名/大脑」字样）；
3. 找权限或设置齿轮（先调保守，再逐步放手）;
4. 把你在 WorkBuddy 里写得最顺的一段三句话需求，原样粘进去；
5. 跑一遍第 3 课的 Excel 流程——成了，这个软件你就毕业了。

## 对照速查

| 需求场景 | WorkBuddy | Trae（AI IDE） | DeepSeek Harness 类 |
|---|---|---|---|
| 日常办公、文档、Excel | ✓ 主场 | 能做但绕 | 看配置 |
| 做网页/小工具、要改要预览 | 能做 | ✓ 主场（IDE 边改边预览） | ✓ 主场（代码向） |
| 定时任务、消息派单 | ✓ 内置自动化 | 少见 | 靠配置 |
| 换大脑 | 模型选择器 | 模型设置 | 天生多模型 |
| 上手难度 | ★ | ★★★ | ★★~★★★★ |

一句话：**日常办公留在 WorkBuddy；想做「作品级」的网页小工具再开 Trae；爱折腾、要本地自动化再玩 Harness**。路径是叠加的，不是替换。

## 把这句话带给同事

> 「你用过微信就会用钉钉。桌面 Agent 全是一个道理：找到输入框，把活儿说清楚，等它交文件，打开验收。」

当你身边有老师问「Trae 怎么用」「XX Agent 怎么用」——不用教他软件，带他把 WorkBuddy 五课走一遍，再让他自己找那五个对应物。**授人以渔，这比教十个软件都有用。**
