## 第 1 件 · 全班评语（一个半天）

**准备（关键，占 70% 价值）**：一张「学生特点表」Excel，三列：化名 / 三个关键词 / 一件具体事例。前 10 个学生认真填，后面试试让 AI 从你的零散记录里帮你汇总。

**话术**：

```
【目标】为全班学生生成期末评语初稿
【输入】桌面 workbuddy-练习/评语/ 学生特点表.xlsx
【动作】每人 2-3 句：先说具体事例，再给特点，最后一条鼓励方向
【约束】禁止出现分数和排名；禁止负面表述（待改进写成"如果…会更棒"）；
       每条必须提到那件具体事例；45 份开头句式不得重复
【输出】评语初稿.docx 放同一文件夹
【验收】我抽查 5 份：事例真实、无排名、句式不重复
```

**验收动作**（不要省）：抽 5 份对照原表核对事例；全文搜索「分」「名次」确认零出现。

## 第 2 件 · 素质发展手册（一个半天）

**话术**：

```
【目标】把每学期重复填的素质手册做成半自动
【输入】上学期手册模板（拍照/电子版都行）+ 本学期班级大事记（我提供 5 件）
【动作】1. 识别模板里每栏要什么
        2. 生成全班通用部分的草稿（社会实践/班级活动/寄语）
        3. 个性化的部分留空并标注「需手填」
【约束】不确定的写「待确认」，不许编造经历
【输出】素质手册草稿.docx
【验收】对照模板逐栏检查无遗漏
```

## 第 3 件 · 家长会材料（先大纲后成品，一个下午）

**第一步只要大纲**（改大纲永远比改成品便宜）：

```
你是资深班主任。为 40 分钟期末家长会出 PPT 大纲：
【输入】本班情况：期中概况一段话 / 3 件大事 / 需家长配合 3 件事
【结构】开场 5 分 → 成绩与进步 10 分（不点名不排名）→ 班级活动 8 分
        → 假期建议 12 分 → 个别交流预告 5 分
【约束】每页只写标题+3 条要点；语气「我们一起」不说「你们要」
【输出】直接在对话里给大纲，每页标「第 N 页」
```

**大纲改到满意**，再说：

```
大纲通过。按此生成 PPT 文件：白底深灰字、金色点缀、
每页一图（占位图即可），保存到桌面 my-workbuddy。
```

**验收**：自己从头放映一遍：不超过 18 页、15 分钟内讲完；搜索学生姓名确认零出现。

## 隐私红线（本任务三条铁律）

1. 特点表、成绩、手册——**只在你自己的电脑、自己的 Agent 里处理**；
2. 任何产出（含截图）发群/给领导前，**先过一遍脱敏**；
3. 评语最终版发出前**逐条签名级核对**——署你的名，就是你的话。

## 完成标准

- [ ] 三大件各完成一次真实交付
- [ ] 每件都执行了「验收动作」
- [ ] 把特点表模板存好——下学期能直接复用
