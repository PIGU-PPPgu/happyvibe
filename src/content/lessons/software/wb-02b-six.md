> **一句话结论：日常聊天用三句话就够；让 AI 干活交文件，六要素齐了才稳——尤其是「约束」和「验收」，是别人没教你、却最值钱的两个。**

## 先看同一件事的两种下场

同样是「帮我写秋游告家长书」——

**随手一句，AI 猜着写**：

> 各位家长：我校将于近期组织学生秋游活动……（写了 300 字套话，没写时间地点，没写回执要求，语气像政府公文）

**六要素齐了，AI 照着办**：

> 【关于初二（3）班秋游的通知】各位家长：本周五（10 月 17 日）我们带孩子们去植物园……集合时间 8:00 校门口……请穿运动鞋……回执请周三前交……（信息全、口气对、长短正好）

差别不在 AI，在**你有没有把要求说完整**。六要素就是说完整的填空题：

```
【目标】做成什么样
【输入】用什么材料
【动作】分几步干
【约束】不许干什么
【输出】交什么、交到哪
【验收】我怎么检查
```

## 逐个讲清楚（重点：后三个）

**目标 / 输入 / 动作**：好理解——想干什么、给它什么、分几步。

**约束（防坑的关键）**——写「不许做什么」：
- 「不要修改我的原始文件」
- 「评语不出现排名和分数」
- 「数字用公式核算，不要估算」

AI 最大的风险不是不会干，是**自作主张**。约束就是围墙。

**输出（交付要具体）**——交什么文件、叫什么名、放哪里：
- 「生成 成绩分析.xlsx，放到桌面 workbuddy-练习 文件夹」

**验收（替未来的你省时间）**——要求它主动交检查材料：
- 「完成后报出各班平均分，方便我抽查」

## 动手练（照抄）

```
【目标】为明天班会写一份「课间安全」讲话稿
【输入】无（基于常识）
【动作】1 个小案例（30 字内）→ 3 条安全要点 → 1 句号召
【约束】不指责学生；不出现真实人名；口语化像面对面说话
【输出】对话里直接给，300 字左右
【验收】我检查字数和有没有人名
```

发出去后，对着「约束」逐条查它的产出——**查到违规就追问**：「出现了人名，替换成『有同学』，其他不动。」

这个「验收→追问」的动作，比写话术本身更重要。

## 三句话 vs 六要素，什么时候用哪个

| 场景 | 用哪个 |
|---|---|
| 问知识、改一句话、起个名 | 三句话（甚至一句话） |
| 交文件、批量处理、生成材料 | 六要素 |
| 拿不准 | 先三句话聊聊，感觉靠谱了再补成六要素让它重做 |

## 检查点

- [ ] 用六要素完整跑过一次任务
- [ ] 对照「约束」检查过产出，发现违规并追问修正过至少一次
