## 第 0 步 · 备好你的数据（最重要的 10 分钟）

工作台好不好用，**七成取决于数据备得齐不齐**。对照这张清单准备：

| # | 数据 | 格式建议 | 真实使用注意 |
|---|---|---|---|
| ① | **待办清单** | Excel 两三列：事项/类型/截止 | 平时想到就记，攒一周就有 |
| ② | **本周课表** | Excel：节次 × 周一~周五 | 教务系统导出或手敲 10 分钟 |
| ③ | **学生名单+特点** | Excel：化名/性别/特点/关注点 | **建议先用化名**，跑顺再换真的 |
| ④ | **作业提交记录** | Excel：化名/科目/应交/已交 | 每周更新一次 |
| ⑤ | **常用备忘** | 随便记 | 口头素材也行 |

**没有现成数据？扫码领模拟数据包**（10 位化名学生 + 待办 + 课表 + 作业记录，全部虚构可投屏）：

## 第 1 步 · 骨架 + 今日待办（15 分钟）

**发给 AI 的话术**（把模拟数据一起拖进去）：

```
【目标】做一个教师个人工作台网页，只装我自己用
【输入】我上传的 待办清单.xlsx
【动作】顶部导航五个页签（今日待办/本周课表/学生速查/作业统计/快速备忘），
        本步先做"今日待办"：列表+打勾+完成率统计+添加框
【约束】打勾状态存浏览器本地，关掉再开不丢；界面简洁，紫色系
【输出】单文件 HTML 保存到桌面 my-workbench 文件夹
【验收】我打勾一条 → 关浏览器重开 → 还是打勾状态
```

**做完你会得到**（真实产出）：

![第1步产出：待办可打勾](/images/demos/wb-final.webp)

✅ **验收**：打勾 → 刷新页面 → 状态保留。没保留就追问：「打勾后刷新会丢，请改用 localStorage 保存」。

## 第 2 步 · 加上课表（10 分钟）

同一个对话里继续说：

```
把工作空间的 本周课表.xlsx 加进去：
"本周课表"页签显示表格；今天的列高亮显示。
```

![第2步产出：课表页](/images/demos/wb-sche.webp)

✅ **验收**：今天那一列是不是真的高亮了？（让它自动取系统日期判断，别写死星期几）

## 第 3 步 · 学生速查（15 分钟）

```
把 学生名单.xlsx 加进去做"学生速查"：
卡片墙展示（名字+性别+特点）；点卡片弹出详情：
特点 / 需要关注 / 本周作业情况。
```

![第3步产出：学生卡片墙](/images/demos/wb-stu.webp)

![点开详情](/images/demos/wb-detail.webp)

✅ **验收**：点 3 张卡片看详情对不对；有「需要关注」标旗的学生，详情里能看到。

## 第 4 步 · 作业统计（10 分钟）

```
把 作业提交记录.xlsx 加进去做"作业统计"：
每人一行提交率条形图；未交满的标橙色。
```

![第4步产出：提交率](/images/demos/wb-hw.webp)

✅ **验收**：抽一个人对一下比例（比如 2/3 应显示 67%）。

## 第 5 步 · 快速备忘 + 整体收尾（10 分钟）

```
最后加"快速备忘"：一个大输入框，内容自动保存到本地；
顶部显示今天的日期。全部完成后整体检查一次：五个页签切换正常、手机宽度不乱。
```

✅ **终验三条**：① 打勾/备忘刷新不丢 ② 五页签无死链 ③ 手机浏览器打开排版正常。

## 换成真数据（隐私红线）

- 化名版跑顺一周后，把 Excel 里的化名换成真名单**重新喂一次**即可；
- **换真数据后的这个文件只存在你自己电脑**——别上传任何网盘/群；
- 要投屏演示时，用回模拟数据版（另存一份）。

## 固化成你的技能（顺手一步）

```
把本次工作台的搭建流程保存为技能 my-workbench：
含数据格式要求、六步话术、验收清单。
下次我说"给XX老师搭一个工作台"，按流程自动执行。
```

——存好这句，下学期帮科组每个老师生成一份，你就是全办公室最靓的仔。
