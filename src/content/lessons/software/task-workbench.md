## 第 1 步 · 想清楚你的工作台要什么（最重要的 10 分钟）

别急着发话术。先拿张纸，写下你每天最烦的 5 件事，然后圈出「信息分散类」的。参考模板：

```
我的工作台要有：
1. 今日待办（能打勾）
2. 本周课表
3. 学生速查（点名字出基本情况的假数据版）
4. 作业统计（本周期交/已交）
5. 一句话备忘录
```

## 第 2 步 · 发话术（照抄改细节）

```
【目标】做一个教师个人工作台网页，我自己每天用它
【输入】我的需求清单：上面写的那 5 个模块
【动作】单文件 HTML，左侧竖排导航切换 5 个模块；
        待办可打勾、数据存浏览器本地不丢失；
        学生速查用 8 个化名假数据占位
【约束】界面简洁不花哨；信息密度高；电脑手机都能用
【输出】保存到桌面 my-workbench 文件夹
【验收】待办打勾后关掉浏览器再开还在
```

## 第 3 步 · 逐模块验收（别一口气全要）

每收到一版，只验收一个模块：

- 待办：加一条 → 打勾 → 关浏览器重开 → 还在？
- 课表：双击格子里能改字吗？
- 学生速查：点「学生A」弹出信息卡？

不对就单点改：「待办打勾后刷新会丢，请改成本地存储保存」。

## 第 4 步 · 换上真数据（隐私红线）

- 课表换成你真实的；
- 学生速查**继续用化名假数据**——除非这个页面只存在你自己的电脑上且永不外传；
- 想给学生/同事看 → 先截图脱敏再发。

## 第 5 步 · 设成开机第一页

浏览器把这个页面设为主页 / 收藏夹置顶。你的数字办公桌开张了。

## 进阶方向

- 接入自动化（第 8 课）：每天早上让它自动往待办里写今日日程
- 复用成模板：话术存成 `my-workbench` 技能，帮科组每个老师生成一份
- 做出感觉了 → 挑战[任务一 · 学科主题网站](/modules/software/task-subject-website/)（面向学生）或看[任务三](/modules/software/task-classroom-kit/)
