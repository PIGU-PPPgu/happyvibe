> **一句话结论：WorkBuddy = 工作角色 + 可换的大脑 + Skill + 工具 + 记忆。先跑通第一个任务，再花两周把它养熟。**

![WorkBuddy 对话界面](/images/lessons/workbuddy-chat.webp)

## 它是什么、适合谁

在[产品横评](/modules/agent/product-comparison/)里，WorkBuddy 是「学校只推一款的首选」：

- **强项**：全校办公、教案、公文、Excel 处理、消息端派单；
- **短板**：PPT 审美、复杂桌面操控（这类活儿可以换 Kimi 或 Trae 配合）；
- 适合**普通教师日常办公**，不需要技术背景。

## 桌面五件套（先建立认知）

复习一遍[桌面 Agent 的组成](/modules/agent/agent-anatomy/)，在 WorkBuddy 里对应：

| 五件套 | 在 WorkBuddy 里 |
|---|---|
| 工作角色 | WorkBuddy 本体，接收任务、拆流程、交结果 |
| 大脑 | 设置里可切换 GPT / 混元 / DeepSeek 等模型 |
| Skill | 你教的固定流程（参考 [Prompt 与 Skill](/modules/creation/prompt-vs-skill/)） |
| 工具 | 浏览器、文件、Excel、邮箱等 |
| 记忆 | 历史任务与你的偏好，越用越懂你 |

## 上手三步（骨架）

1. **下载安装**：官网下载桌面版（地址与版本待补充），登录后选择默认大脑；
2. **跑通第一个任务**：发一个 Excel 给它，说「统计每个班的平均分并排序，输出新表格」——观察它拆步骤、调工具、交付结果的全过程；
3. **教它第一个 Skill**：把你最常用的一种文档格式（比如周计划）写成规范，固化成 Skill（做法见[实战案例](/modules/creation/case-study/)）。

![Agent 今日待办](/images/lessons/agent-today.webp)

## 教师场景推荐

- 每周成绩导入 → 自动出[分析报告](/modules/edu-data/grade-analysis/)；
- 会议录音 → 提要点 → 按模板成通知；
- 消息端派单：在外面用手机派任务，回办公室它已做完。
