> **一句话结论：大量重复劳动或有固定流程规范的事 → 交给 AI；需要教育判断、情感连接的事 → 留给自己。**

## 一个判断标准

![要不要交给 AI 的三问决策图](/images/lessons/when-to-use.webp)

**现在就试**：拿出你今天手头的一件事，对照上面的图走一遍三问，把结论写在便签上。

不是所有事都值得 AI 化。判断标准只有一条：

- ✓ **大量重复劳动**——每学期都要做、每次格式都一样的；
- ✓ **有固定流程规范**——有模板、有套路、有章可循的；
- ✗ 一次性、高度个性化、需要当面沟通的事——你自己干可能更快。

## 教师工作里的典型「划算场景」

| 场景 | 为什么划算 |
|---|---|
| 写通知、告家长书 | 格式固定，改改就能用 |
| 成绩统计与初步分析 | 纯重复劳动 |
| 按模板写教案/申报书 | 有固定规范 |
| 出一套练习题 | 量大、可批量生成再筛选 |
| 会议记录整理 | 录音转写 + 格式化 |
| 座位表调整 | 规则明确（成绩/身高/视力/关系） |

## 反例

- 和个别学生的深度谈话——需要的是你，不是 AI；
- 给某个孩子写一句独一无二的评语——AI 可以起稿，但那句话必须过你的心；
- 临时起意的课堂调整——判断在你。

**原则：把「格式」交给 AI，把「判断」留给自己。** 这也是本站工具箱里所有工具的共同逻辑。
