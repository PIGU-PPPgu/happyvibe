> **一句话结论：申报书拖垮人的从来不是写作，是「格式 + 期望焦虑」。拆成五天、每天只做一件小事，AI 负责格式和资料，你只负责判断。**

## 五天流程总览

| 天 | 只做一件事 | 产出 | 耗时 |
|---|---|---|---|
| D1 | 选题三问 | 一句话选题 | 20 分钟 |
| D2 | 让 AI 出对立方案 | 2 个框架选 1 | 40 分钟 |
| D3 | 分章生成（前半） | 背景/意义/目标 | 40 分钟 |
| D4 | 分章生成（后半） | 内容/方法/步骤 | 40 分钟 |
| D5 | 自检 + 格式化 | 可提交版 | 40 分钟 |

**每天只做一件事**——这是对抗拖延的核心设计，比「周末狂写八小时」靠谱。

## D1 · 选题三问（千万别跳过）

拿一张纸回答（不用写得好，口语即可）：

1. 我日常教学中**最烦/最感兴趣**的一个点是什么？
2. 它是不是**别人也烦**？（有没有普遍性）
3. 我打算**用什么新做法**试一试？

然后丢给 AI 收敛：

```
基于我的三个回答：1.___ 2.___ 3.___
帮我收敛成一个课题选题：主标题（≤20字）+ 副标题（研究什么+怎么做）。
再给出这个选题的 1 个最大风险。
```

> 风险那一条是照妖镜——如果风险是「学校不支持」或「根本没时间做」，趁早换题。

## D2 · 让 AI 出**两个对立**方案

```
为这个选题出两个研究框架：
方案A：行动研究路线（先试点班做一学期，用数据说话）
方案B：开发研究路线（先做出工具/课程包，再推广验证）
各自的创新点、适合的申报级别（区级/市级）、失败模式。
```

选哪个？看你**手里已有什么**：已有一学期实践选 A，已有成型做法选 B。

## D3-D4 · 分章生成（每天只生成一半）

一次生成整份申报书 = AI 大量填空话。分章要：

```
只写「研究背景与意义」这一章：
- 用 3 个真实政策/趋势做背景（联网查证，给出处）
- 意义分「理论」和「实践」各 2 条
- 全文 800 字内，不许出现"具有重要的理论意义"这类空话
```

第二天继续（内容/方法/步骤）：

```
只写「研究内容与方法」：
- 研究内容拆成 3 个子课题，每个一句话
- 方法对应内容（不能全是"文献法"）
- 步骤按学期排时间轴，含预期的中期成果
```

## D5 · 查重式自检（AI 最爱写空话的地方）

```
对我这份申报书做"空话检测"：
1. 标出所有没有信息量的句子（如"具有重要意义""奠定基础"）
2. 标出没有出处却装作有依据的论断
3. 标出方法与内容不对应的段落
只报告位置和原因，我来改。
```

**你逐条改**（AI 改空话只会换成另一种空话）。最后：

```
按区级申报书模板排版，一键导出 Word。
```

## 一条底线

申报书里「预期成果」写得越具体越好（几节课、什么工具、几篇案例）——**写虚了，结题的时候全是泪**。

## 完成标准

- [ ] 五天流程完整走过一遍（或模拟走）
- [ ] D2 时真的在两个方案里做过取舍
- [ ] D5 空话检测揪出过至少 3 处并亲手改掉
