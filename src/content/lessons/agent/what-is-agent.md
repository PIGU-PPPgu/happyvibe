> **一句话结论：Agent = 从「能回答」走向「能帮你做流程」。你交代的是一件事，它交付的是一个结果。**

![从问答到流程（手绘）](/images/lessons/agent-qna-to-flow.webp)

## 对话式 AI vs Agent

| | 对话式 AI（普通聊天） | Agent（智能体） |
|---|---|---|
| 你得到的 | 一段回答 | 一件完成的事 |
| 工作方式 | 你问一句，它答一句 | 拆解任务 → 调用工具 → 自动流转 → 交付结果 |
| 卡住了怎么办 | 你来追问 | 它自己找路：搜索、读文件、试错重来 |

![自动流转（手绘）](/images/lessons/agent-auto-flow.webp)

## 一个教师场景感受一下

同样是「帮我准备下周的家长会」：

- **聊天式 AI**：给你一份家长会发言稿模板——然后呢？资料还是你自己找。
- **Agent**：读你班级的花名册和近期成绩 → 起草发言稿 → 生成 PPT 大纲 → 把通知写成家长书格式 → 存进你的班级管理文件夹，最后向你汇报「做了什么、差什么」。

## 三个关键认识

1. **Agent 不是更聪明的聊天机器人，而是「会干活的数字同事」**；
2. 它的能力 = 脑子（模型）+ 工具（浏览器/文件/代码）+ 记忆（历史任务）+ 技能（Skill），下一课拆开讲；
3. 越是「有固定流程」的活（参考[什么时候值得用 AI](/modules/basics/when-to-use/)），Agent 化的收益越大。
