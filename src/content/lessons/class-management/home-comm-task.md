> **一句话结论：家校沟通最耗神的不是想内容，是「措辞」——同一件事，措辞差一分，家长反应差十分。AI 的分工：事实你出，措辞它出。**

## 先看成品（1 分钟，值得）

一次「体育课争抢篮球推搡事件」的完整沟通链——四份材料、四个时间点、全部由话术生成：

![完整沟通链：告知/私聊/台账/跟进](/images/demos/home-comm.webp)
→ [点开看全部四份材料原文](/demos/home-comm/)

注意三个细节（这就是专业度）：
- 群发告知只陈述事实、**不点名**，还给家长明确的「不做什么」（不追问孩子细节）；
- 个别沟通只给家长**一个动作**（不是三个）；
- T+7 跟进消息——90% 的老师漏掉的闭环。

## 第 1 步 · 事件发生后：先口述事实（2 分钟）

别急着让 AI 写。先把事实用三五句话打给它（时间/人物化名/经过/已做处理）：

```
今天16:40体育课后，小航和小宇争抢篮球发生推搡，无受伤。
两人已分别谈话，情绪平复。小航主动承认推人不对。
计划明天班会讲「运动器材共享」，体育课安排两人和解握手。
```

## 第 2 步 · 生成群发告知（当晚必发）

```
基于以上事实，生成班级群告知：
- 只陈述事实，不出现任何学生姓名
- 说明已处理，语气平稳不让家长恐慌
- 最后给家长一个明确的"不做什么"的引导
100字以内。
```

> **黄金时效**：事件当天晚上 8 点前发。你先说，家长就不会从小道消息里听说。

## 第 3 步 · 生成个别沟通草稿（有细节的分寸感）

```
给小航家长生成一条微信私聊：
- 完整说明经过（他孩子先拿球、推人后主动认错）
- 提到孩子当时的真实情绪（他在意"是不是要赔球"）
- 只请家长今晚做一个动作：肯定他"承认错误"这件事
- 语气：老师和他是一队的，不是告状
```

**核对后发送**——AI 的草稿可能不知道孩子的真实情绪细节，你补的那句才是家长信任的来源。

## 第 4 步 · 台账留痕 + T+7 跟进

```
把今天这件事的全部沟通整理成台账：
时间/事件/处理/后续/隐私材料存放位置。

再给我设一个提醒：7 天后生成对双方家长的跟进消息草稿，
内容：反馈两个孩子本周在体育课的正面互动。
```

（用 WorkBuddy 的可设成自动化；普通 AI 就存备忘录。）

## 话术总纲（贴在工位上）

| 场景 | 措辞原则 |
|---|---|
| 群发 | 只事实 + 已处理 + 指导「不做什么」 |
| 私聊 | 一队口吻 + 真实细节 + 只给一个动作 |
| 台账 | 客观时间线，注明隐私材料存放 |
| 跟进 | 只报正面变化，翻篇不翻旧账 |

## 完成标准

- [ ] 用真实（或模拟）事件走完四步全流程
- [ ] 群发告知做到了「三不」（不点名/不恐慌/不引导围观）
- [ ] 给自己设过一次 T+7 跟进提醒
