> **一句话结论：把「排座位」的隐形规则写清楚，机器秒出草案，你只做微调——公平、可解释、可复用。**

![智能座位编排 SEAT OS](/images/lessons/seat-os.webp)

## 它怎么排

**从名单、成绩和画像生成座位草案**：

1. **导入名单**——班级学生名册；
2. **导入成绩 / 成绩分析**——成绩联动（如 50/50 人绑定）；
3. **画像维度**——活跃、自管、协作、情绪四个维度量化每个学生；
4. **智能规则**——选列数（4~8 列，如 8 COLUMNS），生成草案 → 应用方案 → 导出座位表。

## 传统排座的痛点 vs SEAT OS

| | 手工排座 | SEAT OS |
|---|---|---|
| 耗时 | 一晚上 | 几秒钟 |
| 规则 | 在老师脑子里，说不清 | 显式规则，可解释 |
| 调整 | 牵一发动全身 | 改规则重新生成 |
| 视力/成绩平衡 | 靠印象 | 数据驱动 |

## 规则示例（写进提示词或系统设置）

- 视力不佳的学生固定前两排；
- 「活跃」画像与「自管」画像同桌，动静搭配；
- 相邻四人组成绩互补（避免全是同层次）；
- 每月轮换一次，保留特殊固定位。

## 边界

座位表没有标准答案——**最后拍板的必须是你**：谁和谁不能坐、谁最近状态特殊，这些人际判断机器没有。让 SEAT OS 出 80 分的草案，你来补最后 20 分的人情。
