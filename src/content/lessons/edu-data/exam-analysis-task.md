> **一句话结论：考试后的数据分析不是「算平均分」，是回答三个问题——整体怎么样、谁在进步、哪要干预。一份话术全部搞定。**

## 先看成品（30 秒）

一份成绩表 + 一段话术，生成的完整分析报告页（四张表 + 三条行动建议）：

![月考分析报告页](/images/demos/exam-analysis.webp)
→ [点开真报告（含增值榜/分化预警/行动建议）](/demos/exam-analysis/)

## 第 1 步 · 准备成绩表（5 分钟）

Excel 四列起步：`姓名（或化名）/ 班级 / 各科分数 / 上次总分`。**没有上次数据的先跳过增值表**，下次就有了。

> 隐私红线：这份表只在你自己电脑 + 自己的 Agent 里处理；产出用化名/演示数据（本页成品就是化名演示）。

## 第 2 步 · 发话术（照抄）

```
【目标】生成网页版班级月考分析报告，给班主任自己用
【输入】我上传的成绩表（含上次总分）
【动作】四部分：
  1. 各科均分 + 年级排名（没有年级数据就只报班内）
  2. 进步榜：和自己上次比进步前 8 名（增值视角，化名）
  3. 分化预警：各分数段人数与上次对比，标出在滑落的段
  4. 三条行动建议：本周内/两周内/家长会各一条，必须基于上面的数据
【约束】不出现排名倒数名单；不出现真实姓名（全部化名）；
       建议必须引用具体数字，不许空话
【输出】单文件 HTML，深色大屏风格
【验收】我抽查一个学科均分；核对进步榜第一名与我手算一致
```

## 第 3 步 · 验收（对着成品学怎么看）

拿到报告别只看均分，按这个顺序读：

1. **先看第 3 部分（分化预警）**——均分可能没变，但中间层在滑落（成品里数学 16%<60 分，比上次涨 3 个点）；
2. **再看进步榜**——家长会和班会的表扬素材就在这（增值口径：和自己比）；
3. **最后看行动建议**——空话打回：`第 2 条建议没有引用数据，请基于分化表重写`。

## 第 4 步 · 报告怎么用出去

| 场景 | 用哪部分 | 怎么说 |
|---|---|---|
| 班会课 | 进步榜 | 「今天表扬和自己比进步最大的同学」 |
| 科组对课 | 分化预警 | 把数学那栏直接给数学老师 |
| 家长会 | 均分趋势 + 进步榜 | 「我们看进步，不只看名次」 |
| 自己台账 | 存档 + T+14 复盘 | 两周后看干预是否起效 |

## 进阶：把流程固化

第二次考试后你会重复同样的动作——固化它：

```
把本次分析流程保存为技能 monthly-exam-analysis：
输入=新成绩表，自动按四部分出报告，化名处理。
下次我只说「分析这次月考」。
```

## 完成标准

- [ ] 生成过一份四部分完整的分析报告
- [ ] 按三步验收法读过报告（预警→进步→建议）
- [ ] 报告里至少一个发现被你用在了实际工作里
