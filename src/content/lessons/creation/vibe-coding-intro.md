> **一句话结论：只要会「动嘴」（把需求说清楚），就等于会 Vibe Coding——代码是 AI 写的，判断是你的。**

## Vibe Coding 是什么

用大白话向 AI 描述你想要的东西，AI 负责把它写成代码、跑起来：

- 「帮我做一个随机抽学生名字的网页，要能全屏投屏」
- 「做一个座位表，能按成绩和视力自动排」
- 「把这道抛物线中考题做成可以拖动参数的交互课件」

它不是让你成为程序员，而是让你成为**提需求的人**——就像领导力不是自己干活，而是把活说明白。

## 为什么老师们特别适合

老师是这个世界上**最会提需求**的群体之一：教案有教学目标，活动有方案设计，出卷有双向细目表——这些都是精准的需求描述。Vibe Coding 只是把这份专业能力平移过来。

## 成长路径（本站的路线图就来自它）

```
会用 AI → 教学提效 → 场景实践 → 数据分析
       → Vibe Coding → 做出作品 → 形成成果
```
