### 分层作业一键三档（话术 + 真实成品）

**话术**：

```
你是一位「学科」老师。基于「知识点/本次考试范围」，设计三层作业：
A 层（基础巩固，必做）：5 题，直接套用课堂例题套路
B 层（变式提升，选做）：3 题，换情境不改考点
C 层（挑战思维，选做）：1 道综合题，附思路提示（不给答案）
要求：附完整参考答案与每题的考查点标注。
输出 html 版本给我即可，学生网页上先做题再展开答案。
```

**个性化讲评课方案**（话术）：

```
这是本次考试的班级错题统计（我贴在下面）。
请生成讲评课方案：
1. 按错误率排序的前 3 道题，每题给出「学生可能怎么错的」两种典型思路
2. 每道题配 1 道同类变式题
3. 给 2 条面向不同层次学生的课后建议
```

学生得到：讲评针对「自己怎么错的」。你得到：讲评课从「对答案」升级为「归因课」。

### 评语初稿批量生成（话术 + 真实成品）

**话术**（Agent 读表，普通 AI 做不了）：

```
【目标】为全班学生生成期末评语初稿
【输入】桌面 workbuddy-练习/评语 文件夹里的 学生特点表.xlsx
       （三列：化名 / 三个特点关键词 / 一件具体事例）
【动作】每人 2-3 句评语：先说具体事例，再给特点，最后一条鼓励方向
【约束】禁止出现分数和排名；禁止负面表述（待改进要说成"如果…会更棒"）；
       每句评语必须提到那件具体事例；45 份评语开头句式不得重复
【输出】生成 评语初稿.docx 放同一文件夹
【验收】我抽查 5 份：核对事例真实性、开头句式、有无敏感词
```

**真实结果**（化名演示，注意每条都带着「那件小事」）：

![评语初稿成品](/images/demos/pingyu.webp)
▲ [点开评语初稿真实效果](/demos/pingyu/) —— 蓝底是老师提供的观察，其余是 AI 润色

学生得到：45 份评语每份都有「自己的那件小事」，不是套话。你得到：两天的评语季变半天的核对季。

> 边界提醒：评语里那件「具体事例」必须是你提供的真实观察，AI 只负责润色——事实层永远在你。

**家长会材料一套出齐**
学生得到：家长更懂班级，回家少挨「别人家孩子」式对比。
你得到：先大纲后成品，40 分钟家长会的材料一小时备齐。

## 目标五 · 为自己：作品、成长与话语权

> 「工具是别人的，作品和经验是自己的。」

**一件拿得出手的作品**
你得到：一个自己做的学科网页/小工具——公开课展示、职称材料、成果评选，它都是「实打实做出来的东西」，而不是一句「我会用 AI」。

**一套越攒越值钱的 Skill 资产**
你得到：你教给 Agent 的每个流程都是数字资产。三年后换学校、带新人、开讲座，别人从头学，你直接调用。

**在本站留下你的名字**
你得到：把你打磨成熟的话术、案例、Skill 写成任务卡收录进本站任务库，署你的名字——全集团老师用你总结的方法，这就是教学影响力。

**一种「人机协同」的新职业能力**
你得到：你在课堂上示范的每一次人机协同，都是在教学生未来的工作方式；你自己也在从「使用工具的人」变成「设计工作流的人」。这条能力，学生毕业后要靠它吃饭，你靠它领先。
