> **一句话结论：学 AI 的回报是双向的——学生得到更好的课堂，你自己得到时间、成长和拿得出手的成果。下面每个任务都标了两行：学生得到什么、你得到什么。缺哪样点哪样。**

## 目标一 · 让课堂更生动

> 「我希望我的课，学生是抬着头的。」

**《静夜思》情景诵读课件**（15 科任务卡，各科都有）
学生得到：能点、能听、能玩的课文，而不是一页 PPT。
你得到：一件能上公开课的亮点作品，做完可复用到每一届。
→ [学科课件任务](/modules/creation/subject-task/)

**把抽象概念做成可拖动的动画**
学生得到：自己拖滑块「看」出规律（相遇问题、凸透镜成像）。
你得到：这个概念以后永远不用干讲——课件年年复用，讲评有据。
→ [HTML 讲概念 > PPT](/modules/teaching/html-concepts/)

**把中考题变成可试错的解析页**
学生得到：先试错再看解析，印象深三倍。
你得到：题库变成互动资产；讲题时间省一半。
→ [用 HTML 解题](/modules/creation/html-solving/)

**把危险/不可逆的实验搬进网页**
学生得到：随便试、反复看的实验预演，实操出错率下降。
你得到：课前少摆器材、课后少擦「事故」。
→ [让课堂更有意思](/modules/teaching/fun-class/)

**🎮 课堂互动三件套**（现成话术，直接抄）

学生得到：随机点名、小组积分、抢答竞赛——课堂环节像游戏。
你得到：课堂掌控力（随机点名为你省掉「叫谁好」的尴尬），公开课的气氛担当。

```
1. 随机点名器：做一个全班 45 人（名单我贴在下面）的随机点名网页，
   大字投屏、带滚动动画、点过的不再重复、有「重置」按钮。

2. 小组积分板：做一个 8 个小组的积分板网页，
   点击组名 +1/+2/-1，分数实时排序，第一名金色高亮，数据保存在本地不丢失。

3. 知识竞赛抢答页：做一个 20 题选择题抢答网页（题目我贴在下面），
   显示倒计时、答对变绿答错变红、最后显示小组得分排行。
```

## 目标二 · 让学生吸收更好

> 「讲了三遍还不会，不是我讲得不好，是没有对准每个人。」

**分层作业一键三档**
学生得到：跳不过 own 层级的题目，也够得着更高一层。
你得到：出分层作业从两小时变十分钟；「因材施教」四个字第一次可执行。

```
你是一位「学科」老师。基于「知识点/本次考试范围」，设计三层作业：
A 层（基础巩固，必做）：5 题，直接套用课堂例题套路
B 层（变式提升，选做）：3 题，换情境不改考点
C 层（挑战思维，选做）：1 道综合题，附思路提示（不给答案）
要求：附完整参考答案与每题的考查点标注。
输出 html 版本给我即可，学生网页上先做题再展开答案。
```

**个性化讲评课方案**
学生得到：讲评针对「自己怎么错的」，而不是从头对答案。
你得到：讲评课从「对答案」升级为「归因课」，方案 10 分钟出。

```
这是本次考试的班级错题统计（我贴在下面）。
请生成讲评课方案：
1. 按错误率排序的前 3 道题，每题给出「学生可能怎么错的」两种典型思路
2. 每道题配 1 道同类变式题
3. 给 2 条面向不同层次学生的课后建议
```

**从 30 篇周记里提炼共性**
学生得到：老师真的读了我的每一篇，讲评讲的是「我们」的问题。
你得到：三小时的批后阅读压缩成十分钟核对，讲评材料直接带上讲台。
→ [第 6 课 · 任务 B](/modules/software/wb-06-office/)

**成绩分析与增值评价**
学生得到：进步被看见（不只看分数排名）。
你得到：讲家长会、写评语时有数据撑腰，不用凭印象。
→ [成绩分析与增值评价](/modules/edu-data/grade-analysis/)

**互动材料包**
学生得到：扫码即开的预习/复习页（音频+图+自测）。
你得到：一套 = 一个单元的预习任务，零印发。
→ [学科材料包](/modules/creation/material-packs/)

## 目标三 · 教学方式改变

> 「从『我讲他听』，变成『他做他探他讲』。」

**学生自学页（翻转课堂起步）**
学生得到：课前扫码自学 + 自测，带着问题来上课。
你得到：课堂时间从「讲授」腾出来给「讨论和个别指导」——这是教学方式改变的起点。
→ [学科课件任务](/modules/creation/subject-task/)

**PBL 项目任务包**
学生得到：一个真实有趣的驱动问题和清晰的角色分工。
你得到：一份现成的 PBL 设计（驱动问题/里程碑/量规），综合实践课和职称材料都用得上。

```
你是一位项目式学习（PBL）设计专家。
为「年级 + 学科」设计一个为期 2 周的微型 PBL：
驱动问题要真实有趣（学生愿意讨论的那种），
包含：驱动问题、最终成果形式、3 个里程碑（各配课堂时间）、
小组分工建议、评价量规（4 个维度 × 3 档）。
输出 html 版本给我即可，可以直接投屏给学生看。
```

**把你的资料变成学科助教**
学生得到：课后有问题，先问「懂你班情况」的助教。
你得到：把讲义和资料攒成私有知识库——你的经验第一次可以「不在场也在线」。
→ [Agent + Obsidian](/modules/agent/agent-obsidian/)

**用 Skill 固化你的教学法**
学生得到：你的教学法可以被完整复现。
你得到：一套属于你的 Skill 资产——换学校、带新人、开工作坊，它都是你的「独门武功秘籍」。
→ [Prompt 与 Skill](/modules/creation/prompt-vs-skill/)

## 目标四 · 把重复劳动清零

> 「这些活每周都来一遍，凭什么每周都要我做一遍？」

**6 个班成绩表一键合并**
学生得到：（间接）老师有精力看数据背后的他们。
你得到：一晚上的合并活变 10 分钟核对。→ [第 6 课 · 任务 A](/modules/software/wb-06-office/)

**30 篇周记提炼共性**
学生得到：讲评讲的是「我们真实的问题」。
你得到：三小时压缩成十分钟。→ [第 6 课 · 任务 B](/modules/software/wb-06-office/)

**周报流水线（教一次用一学期）**
学生得到：老师周五不再焦头烂额。
你得到：每周五固定任务从 1 小时变 10 分钟，进阶后自动跑。→ [第 6 课 · 任务 C](/modules/software/wb-06-office/)

**评语初稿批量生成**（现成话术）
学生得到：45 份评语每份都有「自己的那件小事」，不是套话。
你得到：两天的评语季变半天的核对季。

```
【目标】为全班学生生成期末评语初稿
【输入】桌面 workbuddy-练习/评语 文件夹里的 学生特点表.xlsx
       （三列：化名 / 三个特点关键词 / 一件具体事例）
【动作】每人 2-3 句评语：先说具体事例，再给特点，最后一条鼓励方向
【约束】禁止出现分数和排名；禁止负面表述（待改进要说成"如果…会更棒"）；
       每句评语必须提到那件具体事例；45 份评语开头句式不得重复
【输出】生成 评语初稿.docx 放同一文件夹
【验收】我抽查 5 份：核对事例真实性、开头句式、有无敏感词
```

> 记住第 6 课的边界：**事实层永远在你**——评语里那件「具体事例」必须是你提供的真实观察，AI 只负责把你的观察写得妥帖。

**家长会材料一套出齐**
学生得到：家长更懂班级，回家少挨一顿"别人家孩子"式对比。
你得到：先大纲后成品，40 分钟家长会的材料一小时备齐。
→ [第 6 课 · 任务 C 的大纲法](/modules/software/wb-06-office/)

## 目标五 · 为自己：作品、成长与话语权

> 「工具是别人的，作品和经验是自己的。」

**一件拿得出手的作品**
你得到：一个自己做的学科网页/小工具——公开课展示、职称材料、成果评选，它都是「实打实做出来的东西」，而不是一句「我会用 AI」。

**一套越攒越值钱的 Skill 资产**
你得到：你教给 Agent 的每个流程都是数字资产。三年后换学校、带新人、开讲座，别人从头学，你直接调用。

**在本站留下你的名字**
你得到：把你打磨成熟的话术、案例、Skill 写成任务卡收录进本站任务库，署你的名字——全集团老师用你总结的方法，这就是教学影响力。

**一种「人机协同」的新职业能力**
你得到：你在课堂上示范的每一次人机协同，都是在教学生未来的工作方式；你自己也在从「使用工具的人」变成「设计工作流的人」。这条能力，学生毕业后要靠它吃饭，你靠它领先。

## 一条使用建议

别按顺序学这个库。**今晚就挑一个最戳你的任务做掉**——既为了学生，也为了你自己。做完第一个，你会发现剩下的任务套路相通；这时候再回头补 [手把手六课](/modules/software/workbuddy/) 里缺的细节，效率最高。

想加新任务？把你的痛点发给吴老师，入选后整套话术会收录进这个库（**署你的名字**）。
