> **一句话结论：没有人是为了「用 AI」而学 AI。老师学 AI，是为了让学生抬头、让知识落地、让自己下班。这个任务库按这四个目标组织，你缺什么就点什么。**

## 目标一 · 让课堂更生动

> 「我希望我的课，学生是抬着头的。」

| 任务 | 适合谁 | 入口 |
|---|---|---|
| 为某一节课做一个交互式课件 | 所有学科，15 科任务卡现成 | [学科课件任务](/modules/creation/subject-task/) |
| 把抽象概念做成可拖动的动画 | 数学物理地理等（参数滑块、实时变化） | [HTML 讲概念 > PPT](/modules/teaching/html-concepts/) |
| 把中考题变成可试错的解析页 | 数理化老师 | [用 HTML 解题](/modules/creation/html-solving/) |
| 把危险/不可逆的实验搬进网页 | 化学生物物理 | [让课堂更有意思](/modules/teaching/fun-class/) |
| 思维导图 / 知识结构图 | 复习课、单元导入 | [用 AI 做思维导图](/modules/teaching/mindmap/) |
| 课堂小游戏（见下方话术） | 课堂环节调剂、公开课 | 本页直接抄 ↓ |

**🎮 现成话术 · 课堂互动三件套**（发给 WorkBuddy 或任何 AI，输出 html 版本即可）：

```
1. 随机点名器：做一个全班 45 人（名单我贴在下面）的随机点名网页，
   大字投屏、带滚动动画、点过的不再重复、有「重置」按钮。

2. 小组积分板：做一个 8 个小组的积分板网页，
   点击组名 +1/+2/-1，分数实时排序，第一名有金色高亮，数据保存在本地不丢失。

3. 知识竞赛抢答页：做一个 20 题的选择题抢答网页（题目我贴在下面），
   显示倒计时、答对变绿答错变红、最后显示小组得分排行。
```

## 目标二 · 让学生吸收更好

> 「讲了三遍还不会，不是我讲得不好，是没有对准每个人。」

| 任务 | 适合谁 | 入口 |
|---|---|---|
| 分层作业一键三档（见下方话术） | 所有学科，尤其大班额 | 本页直接抄 ↓ |
| 从 30 篇周记/作业里提炼共性 | 班主任、语英老师 | [第 6 课 · 任务 B](/modules/software/wb-06-office/) |
| 成绩分析与增值评价（看进步不只看分数） | 考试后 | [成绩分析与增值评价](/modules/edu-data/grade-analysis/) |
| 学生自学页（扫码即开，含自测） | 翻转课堂、病假补课 | [学科课件任务](/modules/creation/subject-task/) 第 7 步 |
| 互动材料包（音频+图+题一页打包） | 诵读、词汇、实验预习 | [学科材料包](/modules/creation/material-packs/) |

**📝 现成话术 · 分层作业三档生成**：

```
你是一位「学科」老师。基于「知识点/本次考试范围」，设计三层作业：
A 层（基础巩固，必做）：5 题，直接套用课堂例题套路
B 层（变式提升，选做）：3 题，换情境不改考点
C 层（挑战思维，选做）：1 道综合题，附思路提示（不给答案）
要求：附完整参考答案与每题的考查点标注。
输出 html 版本给我即可，学生网页上先做题再展开答案。
```

**📝 现成话术 · 个性化讲评生成**：

```
这是本次考试的班级错题统计（我贴在下面）。
请生成讲评课方案：
1. 按错误率排序的前 3 道题，每题给出「学生可能怎么错的」两种典型思路
2. 每道题配 1 道同类变式题
3. 给 2 条面向不同层次学生的课后建议
```

## 目标三 · 教学方式改变

> 「从『我讲他听』，变成『他做他探他讲』。」

| 任务 | 适合谁 | 入口 |
|---|---|---|
| 学生自学页（概念 + 自测 + 反馈，扫码即用） | 翻转课堂起步 | [学科课件任务](/modules/creation/subject-task/) |
| 项目式学习任务包（驱动问题 + 里程碑 + 评价量规） | 综合实践、跨学科 | 见下方话术 ↓ |
| 把你的资料变成学科助教（学生问，它答你的口径） | 有讲义/资料积累的老师 | [Agent + Obsidian](/modules/agent/agent-obsidian/) |
| 用 Skill 固化你的教学法 | 想把自己的打法传给教研组 | [Prompt 与 Skill](/modules/creation/prompt-vs-skill/) |

**📝 现成话术 · PBL 任务包生成**：

```
你是一位项目式学习（PBL）设计专家。
为「年级 + 学科」设计一个为期 2 周的微型 PBL：
驱动问题要真实有趣（学生愿意讨论的那种），
包含：驱动问题、最终成果形式、3 个里程碑（各配课堂时间）、
小组分工建议、评价量规（4 个维度 × 3 档）。
输出 html 版本给我即可，可以直接投屏给学生看。
```

## 目标四 · 把重复劳动清零

> 「这些活每周都来一遍，凭什么每周都要我做一遍？」

| 任务 | 打的痛点 | 入口 |
|---|---|---|
| 6 个班成绩表一键合并 | 期末收表合并一晚上 | [第 6 课 · 任务 A](/modules/software/wb-06-office/) |
| 30 篇周记提炼共性 | 看完三小时看完就忘 | [第 6 课 · 任务 B](/modules/software/wb-06-office/) |
| 周报流水线（教一次用一学期） | 每周五固定交稿 | [第 6 课 · 任务 C](/modules/software/wb-06-office/) |
| 评语初稿批量生成（见下方话术） | 期末 45 份评语 | 本页直接抄 ↓ |
| 家长会材料一套出齐 | 学期两次大材料 | 第 6 课任务 C 大纲法 |

**📝 现成话术 · 评语初稿批量生成**（Agent 读表，普通 AI 做不了）：

```
【目标】为全班学生生成期末评语初稿
【输入】桌面 workbuddy-练习/评语 文件夹里的 学生特点表.xlsx
       （三列：化名 / 三个特点关键词 / 一件具体事例）
【动作】每人 2-3 句评语：先说具体事例，再给特点，最后一条鼓励方向
【约束】禁止出现分数和排名；禁止负面表述（待改进要说成"如果…会更棒"）；
       每句评语必须提到那件具体事例；45 份评语开头句式不得重复
【输出】生成 评语初稿.docx 放同一文件夹
【验收】我抽查 5 份：核对事例真实性、开头句式、有无敏感词
```

> 记住第 6 课的边界：**事实层永远在你**——评语里那件「具体事例」必须是你提供的真实观察，AI 只负责把你的观察写得妥帖。

## 一条使用建议

别按顺序学这个库。**今晚就挑一个最戳你的任务做掉**，做完你会发现其余的任务套路相通——这时候再回头补[手把手六课](/modules/software/workbuddy/)里缺的细节，效率最高。

想加新任务？把你的痛点发给吴老师，入选后整套话术会收录进这个库（署你的名字）。
