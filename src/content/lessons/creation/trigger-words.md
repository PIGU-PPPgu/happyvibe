> **一句话结论：任务词 ＋ 技术词 ＋ 交付格式 ＝ 更稳定的 AI 输出。你说「做个成绩分析」是碰运气，说「用 Python + ECharts 做班级成绩分析看板」就是下订单。**

这不是「提示词大全」，而是老师最该掌握的一批**格式词 / 技术词 / 产出词**。很多老师不知道：对 AI 说出一个**格式关键词**，它就会切换成对应的「专业输出模式」——更快、更准，还能直接渲染成图。使用方法很简单，把关键词写进句子里：

- 「用 **Mermaid** 画一张《岳阳楼记》课文结构的思维导图」
- 「把这道题的公式用 **LaTeX** 写出来」
- 「用 **HTML** 做一个可以点的课堂互动小游戏」

## 01｜网页与视觉表达

| 触发词 | 适合做什么 | 推荐说法 |
|---|---|---|
| **HTML** | 单页课件、网页、互动展示页 | 用 **HTML** 做一页 16:9 的培训课件，适合大屏展示 |
| **HTML + CSS + JavaScript** | 可点击、可交互网页 | 用 **HTML + CSS + JavaScript** 做一个可交互的教学展示页 |
| **React** | 教师工作台、复杂网页、产品原型 | 用 **React** 做一个教师工作台原型 |
| **Tailwind CSS** | 提升网页排版与 UI 质感 | 使用 **Tailwind CSS**，简洁、现代、留白充分 |
| **Reveal.js** | 网页式幻灯片 | 用 **Reveal.js** 做一套可翻页的网页课件 |
| **SVG** | 高清矢量图、图标、信息图 | 输出成 **SVG 矢量图**，方便放大和放入 PPT |
| **Infographic** | 信息图、概念图、总结图 | 做成一张 **Infographic**，突出核心信息和关系 |
| **Responsive Design** | 手机、电脑、大屏自适应 | 做成 **Responsive Design**，兼容手机和电脑 |

进阶（想做炫酷演示时）：**Canvas**（抛体运动/分子热运动等课堂动画演示）、**Three.js**（立体几何截面、分子模型、太阳系等可拖动旋转的 3D 场景）。

## 05｜研究与资料检索

| 触发词 | 适合做什么 | 推荐说法 |
|---|---|---|
| **Deep Research** | 深度资料研究 | 做一次 **Deep Research**，综合论文、政策和案例 |
| **Literature Review** | 文献综述 | 围绕这个主题做一份 **Literature Review** |
| **Evidence-based** | 强调证据 | 所有关键结论都采用 **Evidence-based** 的方式给出证据 |
| **Primary Sources** | 找原始资料 | 优先使用 **Primary Sources**，不要只引用二手资料 |
| **Benchmark** | 横向对比 | 做一次 **Benchmark**，比较几个平台的能力 |
| **Case Study** | 案例研究 | 用 **Case Study** 的方式分析这个学校案例 |
| **Comparison Matrix** | 多工具、多方案对比 | 做一张 **Comparison Matrix** 比较这几个方案 |
| **Fact-check** | 事实核查 | 对这些说法做一次 **Fact-check** |
| **Synthesis** | 多来源综合 | 对这些资料进行 **Synthesis**，提炼共同结论 |

## 07｜自动化与批量处理

| 触发词 | 适合做什么 | 推荐说法 |
|---|---|---|
| **Batch Processing** | 批量处理文件或数据 | 用 **Batch Processing** 一次处理全部文件 |
| **Python Script** | 自动处理重复任务 | 写一个 **Python Script** 自动完成这件事 |

## 08｜Agent 与产品开发

| 触发词 | 适合做什么 | 推荐说法 |
|---|---|---|
| **Agent** | 多步骤自主执行任务 | 设计一个教师办公 **Agent**，可以读文件、分析并输出结果 |

| **YAML** | 层级配置：大纲、课程结构 | 把这学期教学计划写成 **YAML** |

| **Full-text Search** | 全文搜索 | 加入 **Full-text Search**，支持快速检索资料 |

特色学科彩蛋：音乐老师试试 **ABC 记谱法**（文字直接变五线谱，同类 **LilyPond**）；地理老师试试 **GeoJSON**（一句话标出京杭大运河沿线城市、长征路线）。

## 怎么用这一页

1. **收藏本页当词典**：想做什么事，先来查有没有对应的触发词；
2. **每周记 3 个**：优先掌握上面的「必须 20 个」，一个月覆盖日常 90% 场景；
3. **组合着用**：单个词提质感，组合词出成品——参考「常用组合」直接抄。

已剔除 Word / Excel / PPT 等日常格式词——这些不用教，人人都会。描述需求的通用方法见上一课 [关键词与提示词](/modules/creation/keywords/)。
