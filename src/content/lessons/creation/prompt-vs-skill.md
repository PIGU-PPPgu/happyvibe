> **一句话结论：Prompt 用一次就扔，Skill 教一次终身受用。把你的经验封装成 Skill，等于给每个 AI 装上「你的打法」。**

## 一个 Skill 是怎么长出来的

![一个 Skill 是怎么长出来的](/images/lessons/skill-cat-grow.webp)

过程就三步：**先有一个管用的 Prompt → 反复用、越改越顺 → 固化成 Skill（文档化、可分享、可复用）**。

## Skill 里面到底装了什么

![Skill 里面装了什么](/images/lessons/skill-cat-inside.webp)

一个完整的 Skill = **提示词 + 工作流程 + 标准 + 经验 + 资源**：

- 提示词：这个技能怎么被触发、角色是谁；
- 工作流程：第一步做什么、第二步做什么、出错了怎么办；
- 标准：好的成品长什么样（格式、字体、语气、字数）；
- 经验：容易踩的坑、特殊情况的处置；
- 资源：模板、范例、参考文件。

![Skill 像游戏技能](/images/lessons/skill-cat-game.webp)

就像游戏里的技能树：Prompt 是一次性的「普攻」，Skill 是可反复释放、可升级的「技能」。

## 为什么老师们特别有优势

**大家丰富的教学经验、班级管理、行政管理经验，都是非常宝贵的 Skill！**

- 「怎么写一封让家长愿意配合的告知书」——你有方法论；
- 「怎么把一次班费收支算清楚并公示」——你有流程；
- 「怎么在开学第一周立规矩」——你有整套经验。

这些一旦写成 Skill，任何人（包括 AI）拿到就能复现你的水平。

## 实操：把一个 Prompt 升级成 Skill

先看一份真实的 Skill 固化记录（WorkBuddy 实机）：AI 确认固化后，会列出技能的完整内容和存放位置。

![Skill 固化真实记录](/images/demos/wb2-f1.webp)

1. 把你最近一次用得特别顺的对话整理出来；
2. 按上面的五件套补全（流程、标准、经验、资源）；
3. 存成一个 `SKILL.md` 文件，放进你的 Agent 技能目录（WorkBuddy / Hermes 等都支持）；
4. 下次只说一句「用我的XX技能」——全自动。

具体的固化案例见下一课 [实战案例](/modules/creation/case-study/)；想看「一个 Skill 完整的诞生过程」→ [亲手固化一个 Skill](/modules/creation/skill-born/)。
