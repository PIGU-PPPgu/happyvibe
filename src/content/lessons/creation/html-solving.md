> **一句话结论：把「一道题、一个流程、一个小工具」做成单文件 HTML，是见效最快、风险最低的 Vibe Coding 练手方式。**

## 案例一：教师吐槽抽签系统

给 DeepSeek 一段完整需求，让它做成一个 57 条内容的随机抽签网页：

![提示词：把内容做成随机抽签的 html](/images/lessons/luckdraw-prompt.webp)

提示词要点（照抄结构）：「我想把以下内容进行随机抽签，不能写一个抽签的 html 给我，一共 57 条内容……」然后贴上全部内容。产出：

![生成的抽签系统页面](/images/lessons/luckdraw-output.webp)

一个带「开始抽签 / 重置结果 / 历史记录」的完整网页——这就是「输出 html 版本给我即可」的力量。

## 案例二：深圳中考志愿智能推荐系统

把录取分数线规则写成网页：考生信息录入 → 批次与梯度 → 靠前志愿与保底建议，一页跑通。

![中考志愿智能推荐系统](/images/lessons/volunteer-system.webp)

## 案例三：把中考题变成交互解析

2023 年广州中考的乒乓球发射机抛物线问题，变成可调参数的交互页面：

![抛物线问题交互解析](/images/lessons/projectile-interactive.webp)

矩形区域、入射角度、水平距离、GED 全部可调——**学生在页面上自己试，比听三遍讲义都明白**。这类「解题型页面」的提示词套路：

```
把下面这道中考题做成一个交互式讲解网页：
1. 题目原文：……
2. 已知量可调（滑块），图形实时更新
3. 分步骤展示解析，先让学生试着作答
输出 html 版本给我即可
```

## 练手清单（由易到难）

1. 随机点名 / 抽签器
2. 计时器 + 小组积分板
3. 一道数学/物理题的交互解析
4. 班级值日表生成器
5. 成绩录入与简单分析页

全部只需要：一个对话框 + 一句口诀。做完五个，你就是科组里的「技术担当」。
