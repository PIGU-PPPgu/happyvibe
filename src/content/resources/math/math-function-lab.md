## 教学设计

**学习目标**

1. 经历拖动 k、b 观察图像变化的过程，能说出一次函数图像的增减性与 b 的几何意义。
2. 类比迁移到反比例函数，能说出 k 的符号与双曲线所在象限的关系，知道 k = 0 时无图像的原因。

**易错点预设**

- 把「k < 0 时 y 随 x 增大而减小」记成图像「下降」——图像是直线，是倾斜方向变缓。
- 以为反比例函数 k = 0 只是「图像看不见」，说不出「y = k/x 分母无意义」的原因。
- 混淆 b 的符号与交点横坐标——b 是与 y 轴交点的纵坐标。

**环节设计**

| 环节 | 学生活动 | 教师提问 | 资源状态 |
|---|---|---|---|
| 读一读（约 4 分） | 读出 y = 2x + 1 与两轴交点，指出式子中 1 对应的位置 | 「式子里的 1 写到了图像的哪个位置？」 | 一次函数 k=2, b=1 标准视图 |
| 变 k（约 6 分） | 先预测 k 变负后直线的转向，再拖 k 验证，对照性质表增减性 | 「k 从 2 拖到 -2，直线怎么转？增减性换了什么说法？」 | 一次函数 k=-2, b=1 |
| 变 b（约 6 分） | 拖 b 从 1 到 -3，观察平移与交点移动，说 b 的几何意义 | 「直线往哪边平移？谁用一句话说 b 的意义？」 | 一次函数 k=2, b=-3 |
| 反比例（约 8 分） | 换 y = 6/x 观察象限，拖 k 过零，解释无图像 | 「k 为正时两支在哪个象限？拖到 0 为什么不见了？」 | 反比例函数 invK=6 标准视图 |

**板书式小结**

一次函数 y = kx + b（k ≠ 0）：k > 0 时 y 随 x 增大而增大，k < 0 时减小；b 是直线与 y 轴交点的纵坐标，改变 b 直线上下平移；b = 0 时为正比例函数，图像过原点。反比例函数 y = k/x（k ≠ 0）：k > 0 两支在一、三象限，k < 0 在二、四象限；同支内 k > 0 时 y 随 x 增大而减小，k < 0 时增大；k = 0 时分母无意义，无图像。

**随堂检测（5 题，答完即出解析与得分）**

| 题号 | 考查点 | 选项设计 |
|---|---|---|
| 1 | k、b 符号与象限判断 | 四选一：y = -2x+1 过哪三个象限，干扰项覆盖符号漏判 |
| 2 | 概念辨析：正比例函数条件 | 干扰项 k = 0 直击「一次与正比例混淆」 |
| 3 | b 的几何意义应用 | 干扰项「旋转」「变陡」检验平移与倾斜是否混淆 |
| 4 | 反比例象限与 k 符号 | 干扰项含「|k| 决定象限」的误判 |
| 5 | k = 0 无图像的说理 | 干扰项「显示问题」检验是否理解分母无意义 |

## 课堂用法

1. 全屏打开，默认一次函数 y = 2x + 1。请学生先预测「k 变小、变成负数时直线怎么转」，再拖 k 滑杆验证；拖 b 滑杆观察直线平移，读出蓝点标出的与 y 轴交点。
2. 每个环节配了「讲解」弹层：引导语抛问题，讲解词给结论，生讲生评时点开对照。
3. 滚轮缩放、拖动平移图面，找到直线与 x 轴的交点，对照性质表里的分数坐标；点复位按钮回到标准视图，把 b 拖到 0，看性质表换成正比例函数的结论。
4. 点反比例函数按钮，拖 k 从正到负，看两支双曲线交换象限；把 k 拖到 0，让学生解释为什么此时无图像；最后点「检测」做 5 题，逐题出解析，得分低时回看「变 k」「反比例」两个环节。
