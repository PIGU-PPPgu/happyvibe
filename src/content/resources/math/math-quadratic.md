## 教学设计

**学习目标**

1. 通过拖动 a、b、c，说出各系数对抛物线开口、对称轴、与坐标轴交点的影响。
2. 会由图像读出对称轴 x = -b/2a 与顶点坐标，并能反推系数符号。

**易错点预设**

- 认为 a 决定「上下平移」——a 决定开口方向与宽窄，c 才是与 y 轴交点。
- 对称轴公式 x = -b/2a 里 a、b 异号时轴在 y 轴右侧，容易弄反。

**环节设计**

| 环节 | 学生活动 | 教师提问 | 资源状态 |
|---|---|---|---|
| 看开口（约 5 分） | 观察 y = x² - 2x - 3，拖 a 从 1 到 -1 看开口翻转 | 「a 从正变负，图像怎么变？开口宽窄谁说了算？」 | a=-1→1 过渡，b=-2, c=-3 |
| 找顶点（约 6 分） | 拖 b 改变对称轴位置，读出紫色虚线与顶点坐标 | 「b 变大对称轴往哪边跑？x = -b/2a 验证一下。」 | a=1, b=2, c=-3 |
| 数交点（约 6 分） | 拖 c 上下平移，数与 x 轴交点个数，读 Δ 与两根 | 「c 从 -3 拖到 1，交点少了几个？Δ 谁决定的？」 | a=1, b=-2, c=1（Δ=0 相切） |

**板书式小结**

y = ax² + bx + c（a ≠ 0）：a 定开口方向与宽窄，c 定与 y 轴交点 (0, c)；对称轴 x = -b/2a，顶点 (-b/2a, (4ac-b²)/4a)；Δ = b² - 4ac 定与 x 轴交点个数：Δ > 0 两个、Δ = 0 一个（相切）、Δ < 0 无。

**随堂检测（5 题，答完即出解析与得分）**

| 题号 | 考查点 | 选项设计 |
|---|---|---|
| 1 | a 管开口、c 管交点的分工 | 干扰项把两个系数的职责对调 |
| 2 | 对称轴公式记忆 | 干扰项含漏负号版本 |
| 3 | 「左同右异」规律应用 | 干扰项直击 a、b 位置关系易错点 |
| 4 | 判别式与交点个数 | 三种 Δ 情况辨析 |
| 5 | c 的平移效应 | 干扰项「交点数不变」检验平移影响交点的理解 |

## 课堂用法

1. 全屏打开，默认 y = x² - 2x - 3。请学生先预测 a 从 1 拖到 -1、|a| 变大时开口怎么变，再拖 a 滑杆验证；观察金色抛物线随 c 滑杆上下平移，读出与 y 轴交点恒为 (0, c)。
2. 拖 b 滑杆，对照紫色虚线对称轴与顶点标注读出 h、k，看右侧顶点式和三行配方推导如何跟着变；点复位回到标准视图再试一组。
3. 每个环节配了「讲解」弹层：引导语抛问题，讲解词给规律与口诀（左同右异、Δ 三情况）。
4. 只调 c 滑杆，观察性质表最后一行 Δ = b² - 4ac 从两个交点变到一个、再到没有，请学生用根的判别式解释；最后点「检测」做 5 题定讲练节奏。
