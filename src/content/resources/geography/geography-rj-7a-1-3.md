## 教学设计（handdrawn-25d）

**教材锚点**：人教版七年级上册第一章《地球和地图》第 3 节 地图的阅读

**问题世界**：转学生小满捡到学长的校园寻宝图，图在手却找不到社团活动室——缺的每一样正好是地图三要素。

**页面结构（10 页四幕）**：封面点亮藏宝点 → 航拍照片逐步符号化变身地图 → 现场投票暴露难点（本机存储） → 比例尺/指向标/图例逐件拼装 → 格网点放读位（方向键微调） → 拖图上距离实时换算实地（实地＝图上×比例尺分母） → 拖指向标判相对方位 → 输入判定（图上 3cm、1:5000，实地多少米） → 当堂检测（输入 2 题 + 选择 2 题，实时得分） → 板书逐条揭示、末条留白。

**易错点**：乘完比例尺分母忘记厘米换米；以为地图上方一定是北；忽略图例直接猜符号。

**教师备注**：每页六项（本页问题/教师开口/提问追问/点击顺序/关键困难/过渡）按 N 键查看，内存态不落盘。

**数学测试**：node src/interactives/geography/geography-rj-7a-1-3/tests/math.test.cjs（归一化映射表、换算往返、accepts 全过 rejects 全拒、格网往返一致、八方位正向输出、act 幕序与题库契约）。
