# 北师大版七年级数学 · 资源库设计全案

日期：2026-10-07。回答的问题：拿一本具体教材（北师大版七年级），资源库应该怎么设计才符合真实教学流程与环节。

## 设计原则（从教材出发，不是从动画出发）

1. **环节名用教材固有栏目动词**。北师大初中数学每节固定设「问题情境 → 做一做 → 想一想 → 议一议 → 随堂练习 → 习题」栏目。资源的环节条必须复用这些名字，老师一看环节条就知道课件推进到教材哪一步，备课不用翻译。已落地样例：`math-cube-nets` 环节改为「想一想 / 做一做 / 议一议」，随堂检测对应「随堂练习」。
2. **一个资源对一个课时（§x.y），不做一个大而全的章资源**。课时是老师排课的最小单位，也是国家平台资源组织的单位。
3. **每个资源六件套齐全**（对应智慧教育平台课时资源的构成）：环节预设（≈教学设计）、讲解弹层（≈教案要点）、随堂检测（≈课堂练习）、板书式小结（≈板书）、实拍卡片（≈课件封面）、教材锚点（≈目录定位）。
4. **外链补位，不自建重复轮子**：名师课堂视频、电子教材页、完整教案文档外链到 smartedu，自产资源只做平台没有的东西——可投屏、可操作的交互演示。

## 每课时的标准交付流（与真实课堂环节对齐）

```
课前备课：条目 md「教学设计」（学习目标/易错点预设/环节设计表/板书式小结）+ 教材锚点定位行
课堂投屏：环节条按教材栏目推进（←/→ 键翻环节）→ 每环节「讲解」弹层 → 学生活动后点「检测」
课后巩固：检测错题回看对应环节讲解；下载单文件断网可用
```

## 闸门 v2（今日已上线，全部硬性）

## 与国家智慧教育平台的分工

平台提供：名师课堂视频、电子教材、完整教案文档、官方试卷——全部外链收录。
我们提供：平台没有的**可操作交互演示** + 面向投屏的环节化设计 + 断网单文件。检索路径：课程教学 → 初中数学 → 北师大版 → 七年级上册 → 章 → 节。
