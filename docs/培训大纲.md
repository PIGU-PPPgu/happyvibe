# 周五培训 PPT 大纲（2 小时 + 加时 1 小时）

> 用法：每页大标题 + 少量大字，细节全部切网站演示。标了「切网站」的页，PPT 上只留一句话当底。
> 情绪主线：让他们疼 → 让他们馋 → 让他们动手 → 让他们带走。

---

**P1 封面**
- 标题：让每位老师都能用好 AI
- 副标题：集团教师 AI 赋能培训 · 两小时 · 吴林璋
- 底部：happyvibe.intelliedu.cc

**P2 今天的承诺**
- 一句话大字：两小时后，你手里会多一个自己做的课堂工具
- 小字：不用会代码 · 不用记笔记 · 网站随时回看

**P3 全场流程**（时间轴一页）
- 认痛点 10' → 见作品 10' → 装软件 15' → 干一单 25' → 领材料 15' → 做作品 30' → 晒作品 10' → 出路 5'（+自愿加时 60'）

---

## 第一幕 · 痛（00:00-10）

**P4 你每天被什么折磨**
- 上页内容：6-8 条痛点大字（错题统计两个晚上 / 六班成绩表合并 / 期末 45 份评语 / 出事当晚四份材料 / 排座位全班挪 / 班会主题每周一换）
- 口播：被这条折磨过的举个手。记住你举手的那条——今天只解决它
- 切网站：/pains/ 痛点页逐条举手（投票结果对照你的底牌）

**P5 什么活能交出去：三问**
- 大字三条：大量重复？有固定流程？要当面人情？
- 口播：前两问是、第三问否的活，交出去；要判断要分寸的，永远留给自己

---

## 第二幕 · 见（10-20）

**P6 这些都是一句话做出来的**
- 上页内容：太阳系 / 钢琴 / 会朗读的课文 三张成品截图拼一页
- 口播：先自己玩两分钟（让大家手机打开任务库）
- 切网站：任务库炫技区

**P7 但作品不是重点**
- 大字：智能体谁都能调，一句话出页面的工具一大把
- 第二行：值钱的是你亲手跟 AI 磨出作品的过程——AI 在幕后，不在讲台表演
- 口播：这是今天最重要的一页，讲慢一点

---

## 第三幕 · 装（20-35）

**P8 全场唯一要装的软件**
- 上页内容：WorkBuddy 界面截图 + 「三分钟」大字
- 口播：装不上别慌，跟邻座拼一台，课后有排错手册
- 切网站：第 1 课，一步一等，80% 举手才走下一步

**P9 卡住了怎么办**
- 两条大字：积分不够 → 换免费档（30 秒）｜网络慢 → 3-4 人拼一台
- 口播：绝不能让装软件吃掉这节课

---

## 第四幕 · 干（35-60，全场核心）

**P10 第一单：把一晚上的统计交给 AI**
- 上页内容：话术原文放大铺满整页（第 3 课的六要素话术）
- 口播：一个字一个字抄，抄完发出去
- 切网站：第 3 课；带真成绩表的老师用自己的化名数据

**P11 验收：AI 干活，事实层在老师**
- 大字：抽一个数，自己算
- 口播：对上了继续用；对不上正好——所以每一步都要抽查

**P12 全场最重要的一问**
- 大字：刚才这三分钟，替代了你平时多久的手工活？
- 口播：问完闭嘴，静默三秒，让他们自己算。有人报数就重复他的数

---

**P13 休息 + 领材料（60-75）**
- 上页内容：材料包二维码大图
- 口播：扫你自己学科的，看看里面有什么
- 切网站：材料包页

---

## 第五幕 · 做（75-105）

**P14 二选一**
- 左半：A 线 · 点名器（零基础，明天就能用）成品截图
- 右半：B 线 · 学科网站（进阶，做出你的主页）成品截图
- 口播：半小时，每人做出一个；做完的就是你自己的
- 切网站：任务三 / 任务一

**P15 卡住了这样问 AI**
- 上页内容：求助话术模板（我做到第几步 / 屏幕显示什么 / 想做什么）
- 口播：把这三行填了发给 AI 或发到群里，比说「不能用」快十倍

---

## 第六幕 · 晒（105-115）

**P16 作品墙**
- 大字：截图 + 一句话发群里——给谁用的、解决什么
- 口播：投屏轮播，点评两三个：一个好细节 + 一个别人能搬走的点
- 结尾：打磨好的可署名收进站里任务库

---

## 第七幕 · 路（115-120）

**P17 做完之后呢：五步**
- 上页内容：用 → 改 → 给人用 → 固化成 Skill → 数据回流（五步台阶图）
- 口播：别急着做下一个，先给你做的东西找一个用户

**P18 三个去处**
- 三格：路线图七站 / 21 天挑战（每天 15 分钟）/ 比赛专区（10.15 截止 · 赛道④是我们的主场）
- 口播：参不比赛没关系，今天做的东西就是起跑线
- 切网站：路线图 / 挑战 / 比赛专区

**P19 结束页**
- 大字：AI 在幕后——省下来的时间，还给学生，也还给自己
- 底部：答疑群二维码 + 网站地址

## 加时 · 自愿留下（60 分钟）

- 口播：你只需要买机器和把信息交给 AI，剩下 AI 指挥你
- 切网站：/modules/software/deploy-server/（五张示意图 + 六步流程全在里面）
