# 一对一家长沟通（edupi--02-parent-1on1-message）

读的是 free-tier-edupi--02-parent-1on1-message-HS-1-1（正文 376 字，77 秒）。技能说明全文带进。风格文件没有带进会话。

- 这个技能是写给单个家长的沟通消息，先说观察到的事实再给建议。任务是要给全班家长的信，所以它的长处用不上。说明段自己写了：「本次任务是要发给全班家长的信（技能默认场景是一对一沟通），按班级群发信格式撰写」。
- 出的信本身没有毛病：称呼、整体情况、三条建议、家长会通知、致谢都有。
- 三条建议是通用的话：「每天固定时间先完成作业，再安排其他活动」「保证睡眠和运动」。
- 落款是占位：「班主任 ×老师」「×月×日」。
- 有一句写得得体：「成绩只反映这一阶段的情况。我们不排名、不公布分数对比」。
