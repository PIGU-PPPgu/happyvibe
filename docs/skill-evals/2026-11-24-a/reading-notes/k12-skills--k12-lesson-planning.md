# K-12 课时教案规划（中国本土化）（k12-skills--k12-lesson-planning）

读的是 free-tier-k12-skills--k12-lesson-planning-LP-1-1（正文 2792 字，220 秒）。技能说明被截断，只带进前 3 万字。

- 一份产出有三样：教案、学习任务单（含课堂小测）、听课记录表。听课记录表里有空表格和「（横线8行）」「（横线5行）」这样的排版说明。
- 教案里每个环节有一段「口述脚本」，是给老师照着说的话，如「画一条水平直线。任取一点作原点，标上0。向右为正方向，画上箭头。」
- 五个环节 5、20、10、7、3 分钟，合计 45。新授里三个活动 8、7、5。
- 重点难点写得极简，字与字之间没有空格：「重点：三要素。数与点一一对应。」「难点：负数标点的方向。单位长度统一。」没有突破办法。
- 板书的数轴图两端都画了箭头：「←──┼──┼──┼──┼──┼──┼──┼──┼──→」。任务单和小测里的数轴图也是这样，一共五处。数轴只在右端画箭头。
- 「常见错例」列了四条，写得具体，如「-1.5贴着-1标，没有取-1与-2的正中」。只有错在哪儿，没有原因和应对。
- 作业分了基础型必做、拓展型、弹性型选做三类。
- 全部答案只写在末尾的说明段里：「全部答案已逐题验算（任务三A=4、B=1、C=-2、D=-4，任务四最大数3，任务五答案2，任务六6格6个单位，小测4排序-4＜0.5＜2）」。我对照任务单上的图核过，都对。教案和任务单正文里没有答案。
- 设计说明里引了课标的核心素养说法「三会」，课标锚点一栏引了「能用数轴上的点表示有理数，能比较有理数的大小。」
- 这一课把「右边的点表示的数大」也讲了，这批里别的教案多把比较大小留到后面的课时。
