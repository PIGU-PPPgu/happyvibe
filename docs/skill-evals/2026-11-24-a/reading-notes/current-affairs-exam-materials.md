# 高中时政命题素材（current-affairs-exam-materials）

读的是 free-tier-current-affairs-exam-materials-EX-1-1（正文 386 字，101 秒）。技能说明全文带进。它带的脚本和参考文件没有取回。

- 这是一份拒绝出卷的答复，全篇三段，没有任何题目。开头写：「这份请求我不能直接交付：《一次函数》单元测试卷（满分 100 分、45 分钟，附答案解析与双向细目表）属于成套试卷，而本工具的边界是不生成成套试卷、不替代教师的专业判断，只提供命题参考。」
- 它还指出了第二层不对口：「本工具面向高中九学科，素材来源是近 7 天的时政新闻，对接课程标准与高考评价体系；八年级数学的常规单元测评不涉及时政素材」。
- 提了两类替代帮助，但这一轮都只是说要给，没有真的给：单元命题参考、时政命题素材。
- 第 2 轮 1093 字、第 3 轮 1568 字，比这一轮多出了一些命题参考，还没有读。
- 结论性的事实：固定任务是人教版八年级下册《一次函数》的单元测试卷，这个技能是给高中各科找时政命题素材的。它在这个任务上的分数说明的是不对口。

## 补读第 3 轮（1568 字，532 秒）
