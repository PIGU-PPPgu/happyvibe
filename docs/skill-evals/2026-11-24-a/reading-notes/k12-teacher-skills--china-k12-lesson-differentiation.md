# 中国 K-12 差异化教学（k12-teacher-skills--china-k12-lesson-differentiation）

读的是 free-tier-k12-teacher-skills--china-k12-lesson-differentiation-LP-1-1（正文 5372 字，455 秒）。技能说明全文带进。

- 一份产出有两部分：教师方案，加学生任务单 Group A、Group B、Group C 三张。三张任务单的任务 1、任务 2、课堂检测完全相同，差别在 A 单多一张「定位小表」和动笔前的三个问题，C 单多一节「进一步思考」。
- 有一处事实错误。课题信息表里写「学段与年级 | 义务教育第三学段，七年级」。七年级属于第四学段，第三学段是五、六年级。
- 八个时间段首尾相接：0–5、5–13、13–15、15–24、24–27、27–35、35–41、41–45，合计 45 分钟。
- 分组的写法很谨慎：「本课分组是暂定学习路径，不是能力定论，课中凭作品随时调整」「换组只依据本课作品证据，随时可换，不当众宣布名单」。没有学情数据时的预案是「全班先发 B 单，A 单、C 单各备 8 份放讲台，检查点 1 后凭作品换发」。
- 设了两个课中检查点，写明第几分钟、看什么、标准是什么、怎么处理。
- 有「不可降低项」一节：「A 组不删去负方向判断和非整数定位；C 组拓展是新增思维，不是多做同类题。」
- 没有教学重点和难点这一栏，只有「原课目标与不可降低项」和「设计理由」。
- 易错点只在检查点里点到：「负方向画反」「非整数点位于相邻两整数刻度正中」，没有写原因，应对是换任务单和教师小组指导。
- 「Group A」「Group B」「Group C」是英文夹在中文里。
- 任务单里的题都没有给答案。我算过：M 是 −4，N 是 2，P 是 3，1 格表示 100 时 300 离原点 3 个格。
- 没有课后作业。
