# K12 教案与材料（k12-lesson-plan-creation）

读的是 free-tier-k12-lesson-plan-creation-LP-1-1（正文 3252 字，253 秒）。技能说明被截断，只带进前 3 万字。

- 一份产出里有三份东西：教案、学案、听课观察表。学案带「班级＿＿＿＿　姓名＿＿＿＿」和作图区，末尾有一张「当堂检测（小条，剪下使用）」。观察表是给听课的人用的，有「当堂检测分档统计（45 人）：全部掌握＿＿人　接近掌握＿＿人　需再教＿＿人」。
- 教案开头是「课前速览」，一行写完本课走向：「情境引入 5 分钟 → 建构数轴 10 分钟 → 例题示范 8 分钟 → 分层练习 12 分钟 → 课堂小结 4 分钟 → 当堂检测 6 分钟」，合计 45。
- 易错点写得最全。小节叫「预期困难」，每条按「学生怎么做 / 为什么 / 教师对策」三段写，例如「把负数标到原点右侧 / 对"负方向"未建立，仍按数的大小排 / 回温"从 0 出发，负数向左数"，让出错学生先指出 0 的位置再动手」。
- 每个阶段除了教师活动、学生活动、设计意图，还多一项「观察要点」，如「读 -3℃ 是否误读成 3℃」。
- 没有「教学重点」「教学难点」这两个叫法的栏目，难点写在「预期困难」里，重点没有单独点明。
- 分层练习分 A 组必做、B 组选做，当堂检测三题写了分档：「3 题全对，全部掌握；对 2 题，接近掌握；对 1 题及以下，需再教。」没有布置课后作业。
- 练习题都没有给答案。我算过：A4 是 −1，B1 是 2 和 −2 两个点，B2 重合，例 3 是 −4、−1、2.5，题目本身没有问题。
- 课标写的是「课标依据（大意）」，末尾说明「课标条目按《义务教育数学课程标准（2022 年版）》相关要求的大意书写，未逐字引用」。
- 另有一节「改编提示」，如「若压缩到 40 分钟，删 B 组并把互批缩为 1 分钟」。
- 篇幅超过两页，多出来的主要是学案和观察表。
