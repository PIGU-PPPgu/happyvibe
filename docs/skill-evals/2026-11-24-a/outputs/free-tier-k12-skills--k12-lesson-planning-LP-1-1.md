# 一、教案｜2.2 数轴（第1课时）

基本信息：七年级数学，北师大版七年级上册第二章，课时45分钟，班额45人，课型：新授课。

**课标锚点**
> 义务教育数学课程标准（2022年版）第四学段·数与代数：“能用数轴上的点表示有理数，能比较有理数的大小。”

**设计说明**
本课落实“三会”核心素养：用数学的眼光把温度计简化成直线模型，用数学的语言说清三要素。学生经历画轴、标点、读点三步，建立数与点的一一对应。前承2.1有理数，后为2.3绝对值铺垫“点到原点的距离”。

**教学目标**
- 素养目标：用直线上的点表示有理数，体会数形结合。
- 知识目标：说出三要素。会画数轴。会标点读点。
- 能力目标：借助数轴比较两个有理数的大小。

**教学重难点**
- 重点：三要素。数与点一一对应。
- 难点：负数标点的方向。单位长度统一。

**材料清单**（全部为教室常备，与环节对应）

| 素材 | 数量 | 使用环节 |
|---|---|---|
| 学生直尺 | 每生1把 | 画轴、标点 |
| 教师大三角板 | 1把 | 示范画轴 |
| 黑板、白粉笔、彩色粉笔 | 常备 | 全程板书 |
| 学习任务单（含小测页） | 45套 | 巩固、小测 |

**教学过程**（合计45分钟）

环节一 情境导入（5分钟）
- 口述脚本：「看黑板上这支温度计的示意图。零上5℃在哪儿，零下3℃在哪儿？把温度计放平，刻度拉直，它就成了一条能表示数的直线。」
- 板书：温度计竖放改横放，画出直线雏形。
- 提问：这条直线要有哪些固定标记，才能表示所有的数？

> 重点：本环节只提问题，不先讲三要素。

环节二 新授（20分钟）

活动1 认识三要素（8分钟）
- 口述脚本：「画一条水平直线。任取一点作原点，标上0。向右为正方向，画上箭头。取相同长度作单位长度，从0起逐格标数。」
- 教师用大三角板示范，学生同步在任务单任务一处画。
- 归纳板书：原点、正方向、单位长度，缺一不可。
- 同位互查三要素是否齐全。

活动2 用点表示数（7分钟）
- 口述脚本：「表示3，从0向右数3格。表示-2，从0向左数2格。每个数在这条直线上只有一个点。」
- 教师示范标出3、-2、0。
- 学生完成任务二：在数轴上标出 -3、-1、2、4。
- 教师巡视，重点看负数方向。

活动3 读点找规律（5分钟）
- 学生完成任务三：读出A、B、C、D表示的数。
- 追问：数轴上，右边的点和左边的点，谁表示的数大？
- 归纳板书：右边的点表示的数大。

环节三 巩固练习（10分钟）
- 学生独立完成，同桌互批，教师巡视。
- 任务四基础练习，任务五提升练习，任务六挑战练习。

> 重点：挑战任务当堂只巡视指导，不集体讲评。
> 重点：巡视优先看负数标点的方向。

环节四 课堂小测与小结（7分钟）
- 发小测页，独立完成，限时5分钟。
- 同桌交换，对照答案分类订正2分钟。
- 小结提问：这节课记住哪三样？数轴上怎么比较大小？

环节五 作业布置（3分钟）
- 基础型（必做）：订正任务四、任务五。
- 拓展型：在同一条数轴上表示 -5、-1.5、2.5、5，按从小到大排列。
- 弹性型（选做）：找一个生活中能用数轴描述的例子，画图标出两个数。

**板书设计**

```
2.2 数轴
三要素：原点 · 正方向 · 单位长度
←──┼──┼──┼──┼──┼──┼──┼──┼──→
  -4 -3 -2 -1  0  1  2  3  4
规律：右边的点表示的数大
```

**常见错例**（含学生真实错误表现）
- 把-2画在原点右侧，点落在0与3之间。
- 漏画箭头或漏标0，数轴没有正方向。
- 单位长度不统一，前三格是1，第四格是2。
- -1.5贴着-1标，没有取-1与-2的正中。

**巡视观察点**
- 画轴：三要素是否齐全。
- 标点：负数方向是否正确。
- 读点：能否一次读对。
- 比较：能否用“右边的点表示的数大”说理。

**课后反思**
- 统计负数标点错误人数。
- 检查单位长度统一的落实。
- 按需重教人数定下节课起点。

页脚：本设计依据义务教育课程标准（2022年版）数学核心素养与内容要求。
