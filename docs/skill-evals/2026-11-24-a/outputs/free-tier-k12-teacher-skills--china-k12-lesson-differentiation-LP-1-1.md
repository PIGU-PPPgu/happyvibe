# 第一部分　教师方案

## 《数轴》第1课时差异化教学方案（教师用）

### 一、课程依据与课题信息

| 项目 | 内容 |
|---|---|
| 课题 | 北师大版《数学》七年级上册 第二章 有理数及其运算 · 2.2 数轴（第1课时） |
| 学段与年级 | 义务教育第三学段，七年级 |
| 课程标准 | 《义务教育数学课程标准（2022年版）》"数与代数"领域"数与式"主题 |
| 内容要求（依据课标概括，待教师核对） | 理解有理数的意义，能用数轴上的点表示有理数 |
| 核心素养指向 | 数感、几何直观、推理能力 |
| 课时与班额 | 45 分钟，45 人 |
| 教材页码与版次 | 待教师核对 |

### 二、原课目标与不可降低项

1. 知道数轴的定义，说出并辨认数轴的三要素（原点、正方向、单位长度），能正确画出一条数轴；
2. 能把给定的有理数（含负数、非整数）用数轴上的点表示出来，能读出数轴上给定点所表示的数；
3. 初步体会数与形的对应：知道任何有理数都可以用数轴上的点表示，感受数轴把"数"变成"看得见的点"。

不可降低项：三组都必须经历"从温度计情境抽象出数轴"这一概念生成过程，都完成双向表示（给数描点＋给点读数），都在共同检测中独立达标；A 组不删去负方向判断和非整数定位；C 组拓展是新增思维，不是多做同类题。

### 三、学情与暂定分组

教师未提供前测或学情数据，采用以下暂定规则，本课分组是暂定学习路径，不是能力定论，课中凭作品随时调整：

- 课前暂发依据：最近一次 2.1《有理数》作业中"负号书写、负数意义"的出错情况（可公开使用的作业证据）。
- 无数据预案：全班先发 B 单，A 单、C 单各备 8 份放讲台，检查点 1 后凭作品换发。
- 有数据预案：作业中符号错误较多者发 A 单（预计 12–15 人），作业全对且完成快者发 C 单（预计 6–8 人），其余发 B 单。

### 四、教学流程与时间（三组共同开始、共同收束）

| 时间 | 环节 | 形式 |
|---|---|---|
| 0–5 分 | 温度计情境导入，提出本课问题 | 全班共同 |
| 5–13 分 | 任务1：从温度计到数轴 | 三组同步，A 单带"定向三问"支架 |
| 13–15 分 | 全班交流任务1，教师板书归纳三要素 | 全班共同 |
| 15–24 分 | 任务2：描点与读数 | 三组同步 |
| 24–27 分 | 同桌互检任务2＋教师抽查 4–6 份 | 同桌互检 |
| 27–35 分 | 分流：A 组教师小组指导；B 组订正后做"完成后继续"；C 组做"进一步思考" | 分组 |
| 35–41 分 | 共同课堂检测（独立完成） | 全班共同 |
| 41–45 分 | 回顾一问＋收束，预告第2课时 | 全班共同 |

交流环节板书要点：原点是记数起点；正方向是规定数增大的方向（本课统一取向右），用箭头标出；单位长度是相邻刻度间的距离，同一数轴上必须均匀。追问全班："温度计有头有尾，数轴要不要画出头和尾？"（数轴是可以无限延伸的直线。）

### 五、三组任务、支架、教师追问、预期表现对照表

| 项目 | Group A 路径 | Group B 路径 | Group C 路径 |
|---|---|---|---|
| 学习入口 | 在"定向三问"引导下抽象出三要素并画轴；任务2用"定位小表"先定侧、再数格 | 独立从情境抽象出数轴，独立完成双向表示 | 与 B 相同入口完成任务1、2，中段进入"进一步思考" |
| 任务清单 | 定向三问→任务1→定位小表→任务2→课堂检测→完成后继续→回顾 | 任务1→任务2→课堂检测→完成后继续→回顾 | 任务1→任务2→进一步思考→课堂检测→完成后继续→回顾 |
| 教师追问 | 0℃ 为什么标在这里？正方向朝哪边，你是怎么从温度计知道的？-2.5 在哪两个刻度之间？ | 没有箭头还是数轴吗？3.5 这个点你是怎么找到的？-1 和 -2.5 谁离 0 远？ | 单位长度实际规定了什么？改成 1 格表示 100 后，哪个点动了？你构造的例子里缺了哪个要素？ |
| 预期表现 | 画出三要素齐全的数轴，整数点定位正确，非整数点在定位小表帮助下定位 | 独立画出合格数轴，双向表示全对 | 在 B 的基础上，能说明单位长度的规定性，或在新条件下完成定位并说清理由 |

### 六、课中形成性检查与换组规则

- 检查点 1（第 13–15 分钟，任务1交流时）。看什么：每人所画数轴实物。标准：三要素齐全，负半轴刻度方向与正方向一致。处理：达标且完成快的 A、B 组学生可领 C 单准备中段"进一步思考"；缺要素或负方向画反者换发 A 单，第 27 分钟起加入教师小组指导。
- 检查点 2（第 24–27 分钟，任务2互检后）。看什么：抽查 4–6 份描点作品＋互检记录。标准：符号定侧正确，非整数点位于相邻两整数刻度正中。处理：错侧或错距两处以上者留入 A 组教师指导圈；全部正确且提前完成者做"完成后继续"。
- 换组只依据本课作品证据，随时可换，不当众宣布名单。

同桌互检三条成功标准（印在检测栏上方）：负数都在原点左侧；3.5 和 -2.5 都落在相邻两个整数刻度的正中间；每条数轴三要素齐全。互查只指出问题，不评等级。

### 七、共同课堂检测与分流后的下一步

检测任务见三份任务单"课堂检测"栏（三组完全相同，第 35 分钟起独立完成，约 6 分钟）。

- 达标（4 个点位置全对、P 读数正确、第 3 问说理成立）：下一课时进入 2.2 第 2 课时（相反数）；第 3 问说理完整者记为下节课 C 路径依据。
- 接近（错 1–2 处，集中在非整数定位）：下节课开始用 3 分钟"刻度均分"小练（把 1.5、-2.5 定位到整数刻度之间）。
- 未达标（负数方向画反或数轴缺要素）：教师用温度计实物重做一次抽象过程，下一课时先随 A 路径起步。

### 八、设计理由

- 三组共用温度计情境和相同任务顺序，核心思维不降级：A 组用"定向三问"和"定位小表"把抽象与定位过程外化，到课堂检测处全部撤除支架；B 组独立完成；C 组转向单位长度的规定性、反例辨析和非标准条件下的定位，增加的是概括、评价与迁移，不是题量。
- 检测三组共同独立完成，保证下一课分流的证据可比。

### 九、大班（45 人）实施说明

- 三种任务单按"三、学情与暂定分组"的预案发放，讲台常备各 8 份用于课中换单。
- 三组任务顺序与口令相同，教师只在中段集中指导 A 组一处，B、C 组以互检和自主任务为主。
- 支架全部印在 A 单上，课堂无需额外材料（温度计实物可选）。
- 共同开始、共同收束，中段走不同路径。

**概念工具（先读懂再用）**

| 词 | 意思 |
|---|---|
| 数轴 | 规定了原点、正方向、单位长度的直线 |
| 原点 | 数轴上表示 0 的点，记数的起点 |
| 正方向 | 规定为数增大的方向，用箭头标出（本课统一取向右） |
| 单位长度 | 相邻两条刻度线之间的距离，代表 1，同一数轴上必须均匀 |

**任务1　从温度计到数轴**（约 8 分钟）

动笔前，先把下面三个问题各用一句话写在旁边：
① 0℃ 应该标在直线的哪个位置？为什么选它？
② 朝哪边读数越来越大？你从温度计上是怎么知道的？
③ 每一格代表多少？

一支温度计竖着挂在墙上：0℃ 是它读数的分界点，越往上温度越高，每个小格表示 1℃。把它放平、拉直，就变成了一条直线。请把这条直线画出来，并在这条直线上标出表示 0℃、5℃ 和零下 3℃ 的点，在点旁写上对应的数。想一想：要把"温度"放到这条直线上，你先规定了什么？温度计有头有尾，你画的这条直线要不要画出头和尾？把你的想法写一句话。

（画在下方空白处）

**任务2　把数放到直线上**（约 9 分钟）

另画一条数轴（或接着用上面那条），完成两件事：
(1) 在数轴上标出表示 2、-1、0、3.5、-2.5 的点，在点旁写上对应的数；
(2) 点 M 在原点左侧 4 个单位长度处，点 N 在原点右侧 2 个单位长度处——写出 M、N 各表示什么数。

每描一个点，先在定位小表里填一行，再落点：

| 数 | 符号是 ＋ 还是 － | 该在原点的哪一侧 | 离原点几个格 |
|---|---|---|---|
| 2 |  |  |  |
| -1 |  |  |  |
| 3.5 |  |  |  |
| -2.5 |  |  |  |

（画在下方空白处）

**课堂检测**（第 35 分钟开始，独立完成，不看同伴的单子）

互检三条标准：负数都在原点左侧；3.5 和 -2.5 都落在相邻两个整数刻度的正中间；每条数轴三要素齐全。

画一条数轴：(1) 在上面标出表示 -2、0、1.5、4 的点；(2) 点 P 在原点右侧 3 个单位长度处，写出 P 表示的数；(3) 用一句话回答：是不是任何有理数都可以用数轴上的点表示？说说理由。

**完成后继续**（先完成任务可做）

在数轴上找出表示 -3 和 3 的点，数一数它们到原点的距离各是几个单位长度；再估计：表示 100 和 -100 的点会离原点多远？这两个数的关系，下一课时会给它正式的名字。

**回顾**（下课前完成）
