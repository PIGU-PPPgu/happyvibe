# 人教版八年级下册《一次函数》单元测试卷

满分：100 分　时间：45 分钟
命题范围：第十九章 19.1 变量与函数、19.2 一次函数、19.3 课题学习 选择方案

## 一、选择题（每小题 3 分，共 24 分）

**1.** 下列各点中，在直线 y = 2x - 3 上的是（　）
A. (0, 3)　　B. (-1, -1)　　C. (2, 1)　　D. (2, 5)

**2.** 一次函数 y = -2x + 3 的图象不经过（　）
A. 第一象限　　B. 第二象限　　C. 第三象限　　D. 第四象限

**3.** 直线 y = 3x - 2 与 y 轴的交点坐标是（　）
A. (0, -2)　　B. (-2, 0)　　C. (0, 2)　　D. (2, 0)

**4.** 将直线 y = 2x 向上平移 3 个单位长度，所得直线的解析式是（　）
A. y = 2x + 3　　B. y = 2x - 3　　C. y = 3x + 2　　D. y = 3x - 2

**5.** 一次函数 y = kx + b 中，若 y 随 x 的增大而减小，且图象与 y 轴交于正半轴，则（　）
A. k > 0，b > 0　　B. k > 0，b < 0　　C. k < 0，b > 0　　D. k < 0，b < 0

**6.** 下列函数中，是一次函数但不是正比例函数的是（　）
A. y = -2x　　B. y = x/2　　C. y = 3x + 1　　D. y = x² + 1

**7.** 直线 y = -2x + 4 与 x 轴交于点 A(2, 0)，则不等式 -2x + 4 > 0 的解集是（　）
A. x < 2　　B. x > 2　　C. x < 4　　D. x > 0

**8.** 一支蜡烛原长 20 cm，点燃后每小时缩短 2 cm，则剩余长度 y（cm）与燃烧时间 x（小时）之间的函数关系式及自变量取值范围是（　）
A. y = 20 - 2x（0 ≤ x ≤ 10）　　B. y = 20 + 2x（x ≥ 0）　　C. y = 2x - 20（0 ≤ x ≤ 10）　　D. y = 20 - 2x（x ≥ 0）

## 二、填空题（每小题 3 分，共 18 分）

**9.** 函数 y = √(x - 1) 中，自变量 x 的取值范围是________。

**10.** 正比例函数 y = (m - 2)x 中，若 y 随 x 的增大而增大，则 m 的取值范围是________。

**11.** 直线 y = -3x + 6 与 x 轴的交点坐标是________。

**12.** 若直线 y = 3x + b 经过点 (2, -1)，则 b = ________。

**13.** 已知一次函数 y = -x + 5，若 x₁ > x₂，则 y₁________y₂（填 ">"、"<" 或 "="）。

**14.** 直线 y = 2x - 4 与两坐标轴围成的三角形的面积是________。

## 三、解答题（共 6 小题，共 58 分）

**15.（8 分）** 已知一个一次函数的图象经过点 (0, -2) 和 (2, 2)。
（1）求这个一次函数的解析式；（5 分）
（2）判断点 (-1, -4) 是否在这个函数的图象上，并说明理由。（3 分）

**16.（8 分）** 已知一次函数 y = -2x + 4。
（1）完成下表，并在平面直角坐标系中画出该函数的图象；（5 分）

| x | -1 | 0 | 1 |
|---|----|---|---|
| y |    |   |   |

（2）结合图象回答：当 -1 ≤ x ≤ 1 时，y 的取值范围。（3 分）

**17.（10 分）** 在同一平面直角坐标系中，直线 l₁：y = x + 1 与直线 l₂：y = -x + 3 相交于点 P。
（1）求点 P 的坐标；（5 分）
（2）直接写出不等式 x + 1 > -x + 3 的解集，并结合图象说明理由。（5 分）

**18.（10 分）** 某通信公司有两种话费套餐：A 套餐每月月租 18 元，通话每分钟另收 0.1 元；B 套餐无月租，通话每分钟收 0.25 元。设某月通话时间为 x 分钟。
（1）分别写出两种套餐的月缴费 y₁、y₂（元）与 x（分钟）之间的函数关系式；（4 分）
（2）当月通话时间是多少分钟时，两种套餐缴费相同？（3 分）
（3）王老师每月通话 150 分钟，选哪种套餐更合算？通过计算说明。（3 分）

**19.（10 分）** 李老师从家步行去学校：先以 80 米/分的速度匀速步行 5 分钟，然后在路口等红灯停留 2 分钟，最后以 100 米/分的速度又步行 6 分钟到达学校。设 t 为从家出发起经过的时间（分），s 为李老师离家的距离（米）。
（1）分别写出这三个阶段中 s 与 t 的函数关系式，并注明每个关系式中 t 的取值范围；（8 分）
（2）求李老师家到学校的距离。（2 分）

**20.（12 分）** 学校要购买 A、B 两种奖品共 30 件（A、B 两种都要购买），A 种每件 8 元，B 种每件 5 元。设购买 A 种奖品 x 件，购买总费用为 y 元。
（1）写出 y 与 x 之间的函数关系式；（4 分）
（2）若购买总费用不超过 170 元，共有哪几种购买方案？（6 分）
（3）哪种方案费用最低？最低费用是多少元？（2 分）

## 参考答案与解析

### 选择题

**1. C**
把 x = 2 代入：2×2 - 3 = 1，与纵坐标一致，点 (2, 1) 在直线上。
- 误选 A (0, 3)：把常数项 b = -3 当成 +3，以为图象过 (0, 3)。
- 误选 B (-1, -1)：负数乘法丢符号，把 2×(-1) - 3 算成 2 - 3 = -1。
- 误选 D (2, 5)：按 y = 2x + 3 计算，同样是 b 的符号错。
读数：A、D 错误集中说明 b 的符号意义未建立；B 说明负数运算薄弱。

**2. C**
k = -2 < 0，直线从左到右下降，经过第二、四象限；b = 3 > 0，与 y 轴交于 (0, 3) 正半轴，故图象过第一、二、四象限，不过第三象限。
- 误选 A：以为 k < 0 的直线只在二、四象限，忽略 b 决定与 y 轴的交点位置。
- 误选 B、D：把 k、b 的作用记反。
读数：错误集中在象限与 k、b 的关系时，用“先画一条下降直线、再标 y 轴交点”重建，不靠背口诀。

**3. A**
令 x = 0，得 y = -2，交点为 (0, -2)。
- 误选 B (-2, 0)：把 y 轴交点写成 (b, 0)，混淆了“x 轴上的点纵坐标为 0、y 轴上的点横坐标为 0”。
- 误选 C：常数项符号错。
读数：选 B 的学生先补坐标轴定位，再回到令 x = 0 求交点。

**4. A**
直线上下平移时 k 不变、b 加减：向上平移 3 个单位即 b 由 0 变 3。
- 误选 B：把“向上”对应成减。
- 误选 C、D：把平移量加到了 k 上。
读数：选 C、D 说明 k（决定方向）与 b（决定截距）的分工混淆，用同一图象先平移、再读新交点验证。

**5. C**
y 随 x 增大而减小对应 k < 0；与 y 轴交于正半轴对应 b > 0。
- 误选 A、B：增减性与 k 的符号对应错。
- 误选 D：截距位置与 b 的符号对应错。

**6. C**
一次函数形如 y = kx + b（k ≠ 0），正比例函数 y = kx 是 b = 0 的特殊一次函数。C 中 b = 1 ≠ 0，是一次函数但不是正比例函数；A、B 是正比例函数；D 是二次函数。
- 误选 A、B：认为系数为负数或分数就“不算”正比例函数。
- 误选 D：只看到“有常数项”就判为一次函数。
读数：选 D 说明概念辨析停留在“外形”，逐项核对 y = kx + b 中 k ≠ 0、b 取任意值。

**7. A**
k = -2 < 0，y 随 x 增大而减小；x = 2 时 y = 0，所以 x < 2 时图象在 x 轴上方，即 y > 0。
- 误选 B：记住了交点没看方向。
- 误选 C：直接拿 b = 4 当分界。
- 误选 D：把“图象在 x 轴上方”当成“x 是正数”。
读数：让学生口头讲清“图象哪一段在 x 轴上方、对应哪些 x”，再动笔解不等式。

**8. A**
每小时烧 2 cm，x 小时烧 2x cm，剩余 y = 20 - 2x；烧完即停：20 - 2x = 0 得 x = 10，故 0 ≤ x ≤ 10。
- 误选 B：剩余与燃烧的关系建反。
- 误选 C：移项符号错。
- 误选 D：漏掉自变量上限。
读数：选 D 说明建模后没有回到实际情境检查自变量范围。

### 填空题

**9.** x ≥ 1。被开方数非负：x - 1 ≥ 0。误 x > 1：漏了 x = 1 时 y = 0 有意义；误 x ≤ 1：不等号方向反。

**10.** m > 2。k = m - 2 > 0 时 y 随 x 增大而增大。误 m < 2：不等号方向反；误 m ≥ 2：忽略了 k = 0 时不是一次函数。

**11.** (2, 0)。令 y = 0：-3x + 6 = 0，x = 2。误 (0, 6)：与 y 轴交点混淆；误 (-2, 0)：移项不变号。

**12.** b = -7。代入：3×2 + b = -1，b = -7。误 b = 5：移项没变号（写成 -1 + 6）。

**13.** <。k = -1 < 0，y 随 x 增大而减小，x₁ > x₂ 时 y₁ < y₂。误 ">"：只看 x 的大小，没看 k 的符号。

**14.** 4。与 x 轴交于 (2, 0)，与 y 轴交于 (0, -4)，S = ½ × 2 × 4 = 4。误 8：忘乘 ½；误 -4：距离忘取绝对值。

### 解答题

**15.**
（1）设 y = kx + b（1 分）。图象过 (0, -2)，得 b = -2（2 分）；过 (2, 2)：2k + b = 2，2k = 4，k = 2（2 分）。解析式为 **y = 2x - 2**。
（2）把 x = -1 代入：2×(-1) - 2 = -4，与点的纵坐标相等，所以点 (-1, -4) **在**函数图象上（代入 2 分，结论 1 分）。
常见错：由 (0, -2) 求出 b 后把另一条件代成 2k - 2 = 2 时符号算错，得 k = 0（此时应自查 k ≠ 0）。

**16.**
（1）x = -1 时 y = 6；x = 0 时 y = 4；x = 1 时 y = 2（每空 1 分）。过 (-1, 6)、(0, 4)、(1, 2) 三点画一条直线（2 分）。
（2）k = -2 < 0，y 随 x 增大而减小：x = -1 时 y 最大为 6，x = 1 时 y 最小为 2，所以 **2 ≤ y ≤ 6**（3 分）。
常见错：把范围写成 6 ≤ y ≤ 2，或只代端点忘了结合增减性说明。

**17.**
（1）联立 x + 1 = -x + 3（1 分），2x = 2，x = 1（2 分），代入得 y = 2，所以 **P(1, 2)**（2 分）。
（2）解集为 **x > 1**（2 分）。理由：两直线交点是分界，当 x > 1 时，直线 l₁ 的图象在 l₂ 的上方，即 x + 1 > -x + 3（3 分）。
常见错：解集写成 x < 1——只会代数移项、不会从“哪条线在上面”读方向。

**18.**
（1）y₁ = 0.1x + 18；y₂ = 0.25x（各 2 分）。
（2）令 0.1x + 18 = 0.25x（1 分），0.15x = 18，**x = 120**（2 分）。
（3）y₁ = 0.1×150 + 18 = 33（元），y₂ = 0.25×150 = 37.5（元）（2 分），33 < 37.5，选 **A 套餐**更合算（1 分）。
常见错：（3）只算一种套餐就下结论，缺少比较。

**19.**
（1）
- 阶段一：s = 80t（0 ≤ t ≤ 5），t = 5 时 s = 400（式 2 分，范围 1 分）；
- 阶段二：s = 400（5 < t ≤ 7）（2 分）；
- 阶段三：s = 400 + 100(t - 7) = 100t - 300（7 < t ≤ 13）（式 2 分，范围 1 分）。
（2）t = 13 时 s = 100×13 - 300 = **1000**（米），李老师家到学校 1000 米（2 分）。
常见错：等红灯阶段写成继续前进的式子；阶段三忘了减去前 7 分钟已走的 400 米（写成 100t）。

**20.**
（1）y = 8x + 5(30 - x) = **3x + 150**，其中 x 为正整数且 1 ≤ x ≤ 29（化简 2 分，注明取值 2 分）。
（2）由 3x + 150 ≤ 170（2 分），3x ≤ 20，x ≤ 20/3 ≈ 6.7（2 分），又 x 为正整数，故 x = 1, 2, 3, 4, 5, 6，共 **6 种方案**：A 种 1~6 件、B 种对应 29~24 件（2 分）。
（3）k = 3 > 0，y 随 x 增大而增大，x 取最小值 1 时费用最低（1 分）：y = 3×1 + 150 = **153 元**，即 A 种 1 件、B 种 29 件（1 分）。
常见错：（2）漏掉 x ≥ 1 的约束把 x = 0 算进方案；（3）不说明增减性直接取端点。

## 教师读数速查

| 学生普遍表现 | 反映的思维 | 下一步教学动作 |
|---|---|---|
| 选1 错选 A 或 D | 常数项 b 的符号与意义没建立 | 令 x = 0 找 y 轴交点，用几条不同 b 的直线对照重画 |
| 选2、选5 错误集中 | 把 k、b 的作用记成孤立口诀，未结合图象 | 现场画草图：先定方向（k），再标 y 轴交点（b） |
| 选4 错选 C、D | 把平移量加到 k 上，k 与 b 分工混淆 | 同一图象先平移、再读新交点，验证 b 的变化 |
| 选7、解17 方向错 | 会解不等式但不会从图象读方向 | 追问“图象哪段在 x 轴上方、对应哪些 x”，先说后写 |
| 填9 写 x > 1、填13 答反 | 边界与不等号方向的意识弱 | 用 x = 1 代入检验边界，练“取等代入验证” |
| 填12 得 5、解15 符号错 | 移项不变号 | 三道一步方程限时小练，只订正符号 |
| 选8 选 D、解19 范围漏 | 建模后没有回到实际情境检查自变量 | 凡建模题固定追问“x 能取到多少？为什么？” |
| 解20 把 x = 0 算入方案 | 约束条件只解不回代检查 | 要求每种方案回代验证费用并核对“两种都买” |
