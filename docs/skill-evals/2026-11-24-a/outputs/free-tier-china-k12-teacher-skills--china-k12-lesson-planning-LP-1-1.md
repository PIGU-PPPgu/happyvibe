# 《2.2 数轴（第 1 课时）》教案

**教材**：北师大版七年级上册 第二章「有理数及其运算」
**课时**：第 1 课时（45 分钟）　**班额**：45 人（预设 9 组、每组 5 人）
**课型**：新授课　**环境**：普通教室（黑板＋学案，不依赖专用设备）

## 一、学情与前置知识

学生已学 2.1 有理数，能区分正负数、会用正负数表示相反意义的量，但还没有“把数安到一条直线上”的系统经验。全班都见过温度计，这是从“竖直刻度”过渡到“水平数轴”的现成桥。开学不久，学生动手意愿强、画图规范意识弱，预计高频错误：漏箭头、刻度不匀、负数定位反。

## 二、教学目标与学习证据

1. 能说出数轴的三要素（原点、正方向、单位长度），并独立画出一条合格的数轴。
   证据：同桌“三要素体检”互查记录；Exit Ticket 第 1 题。
2. 能用数轴上的点表示给定的有理数（含 0、负数、小数），并能读出数轴上已知点表示的数。
   证据：标数任务、读点快问快答；Exit Ticket 第 2 题。
3. 能把温度、收支等真实情境里的量放到数轴上，并说清“为什么画在这个位置”。
   证据：收支情境同桌说理；找错环节说理；三星挑战题。

**课标与素养锚定**：参照《义务教育数学课程标准（2022 年版）》“数与代数”主题中用数轴直观表示有理数的内容要求；锚定 2 项素养——数感（在直线上感知数的相对位置）、几何直观（以形助数，为绝对值、不等式铺路）。

## 三、重点难点

- 重点：数轴三要素；规范画数轴；用数轴上的点表示有理数。
- 难点：①非整数（1.5、-3.5）的定位；②负数段顺序（越往左越小）；③体会“每个有理数都能找到对应的点”。

## 四、教学准备

- 教师：直尺、三角板、彩色粉笔；温度计实物或大图；找错图 3 张（缺箭头 / 刻度不匀 / 漏标原点）。
- 学生：直尺、铅笔、学案 1 份（空白画图区、标数题、三星练习、Exit Ticket 栏）。
- 可选：地面数轴贴纸（-4 到 4 共 9 张）＋数字卡 9 张，课前贴在教室前部空地，供“人体数轴”用。

## 五、课堂流程（共 45 分钟）

### 环节 1：情境与预测（0–5 分钟）
出示天气预报：白天最高 6℃，夜间最低 -3℃。学案任务（学生语言）：
「这支温度计是竖着刻度的。请你把它‘放倒’画成一条线，把 6 和 -3 标在合适的位置——先别讨论，自己画。」
学生独立试画约 2 分钟，教师巡视收 2–3 份画法不同的（漏 0 的、方向不同的、间距不匀的）。
设计意图：先“裸画”暴露真实起点——多数人能画出带刻度的线但约定不统一，这些半成品是下一环节提炼三要素的最好素材。

### 环节 2：对比与冲突（5–11 分钟）
投影展示作品（隐去姓名），全班当“读者”：「这三张图，你能看懂每张上的 6 和 -3 在哪儿吗？哪张别人一眼就懂？」
引导发现：要让所有人看懂同一张图，必须约定三件事——0 画在哪、往哪边越数越大、每格代表多少。学生用自己的话说，教师暂不给名词。
设计意图：“图别人看不懂”是学生自己撞上的问题，三要素的必要性由冲突自然产生，而不是被告知。

### 环节 3：提炼概念（11–16 分钟）
正式命名并板书：数轴是规定了原点、正方向和单位长度的直线。
三要素：①原点（表示 0 的点，零上零下的分界）；②正方向（向哪边越数越大，习惯向右，画箭头）；③单位长度（每格代表同样多，本课每格代表 1）。
回到学生作品逐条“体检”：各缺哪一条、补上会怎样。顺带指出：温度计就是竖起来的数轴。
设计意图：命名放在冲突解决之后，学生是“给刚才的约定起名字”，不是听新名词。

### 环节 4：示范与互查（16–22 分钟）
教师黑板示范，边画边念口诀：「直线出头、原点标零、箭头向右、刻度等距。」（两端出头＝无限延伸；等距标 …-2, -1, 1, 2…）
学生学案同步画一条，画完与同桌做“三要素体检”：对照口诀逐条打勾，问题当场补。
设计意图：示范＋立即模仿＋同伴互查，把“画规范”落在第一支笔上；口诀同时是后面找错的检查清单。

### 环节 5：表示数与读数（22–30 分钟）
任务 A：在刚画的数轴上标出 3、-2、0、1.5、-3.5。
任务 B：教师指点学生快答报数；再教师报数、学生上台指认。
关键追问：「1.5 夹在哪两个数之间？怎么找到它？」「-3.5 和 -3 谁更靠左？零下 3.5 度比零下 3 度更冷还是更暖？」「0 左边能一直标下去吗？标得完吗？」
可选（约 2 分钟）：人体数轴——请 1 组 5 名学生持数字卡站上地面刻度，全班当裁判：1.5 没有现成刻度，该站哪？
设计意图：非整数用“先夹在相邻两个整数之间再取位置”化解；负数顺序用冷热锚定；人体数轴把“数与点一一对应”变成全身记忆。

### 环节 6：辨析与迁移（30–37 分钟）
活动 A（小组抢答找错）：3 张问题数轴（缺箭头 / 刻度一长一短 / 漏标原点），说出缺哪个要素、用哪句口诀查出来的。
活动 B（新情境）：小明本周零花钱收支：周一 +5 元、周二 -3 元、周三 0 元、周四 +2 元、周五 -4 元。把 5 个数画在同一条数轴上，并回答：「-4 为什么画在 -3 的左边？说给同桌听。」
设计意图：“给别人挑错”比再做一遍更能暴露三要素理解；收支情境把 2.1 的正负数意义与本课的定位接上。

### 环节 7：分层练习（37–42 分钟）
学案三星题，从上往下做，做完一层可向同桌讲解：
- ★ 基础：画一条数轴，标出 -4、-1、0、2、3。
- ★★ 进阶：在数轴上表示 -1.5 和 2.5；写出学案上 A、B、C 三点表示的数。
- ★★★ 挑战：小明说：“0 和 1 之间只有一个数。”你同意吗？在数轴 0 和 1 之间标出两个不同的数说明你的看法。
教师巡看 ★、★★，重点帮扶负数定位出错的学生。
设计意图：三层同一核心任务（在数轴上安置数），只调起点支架与开放度；星级不是能力标签；★★★直击“整数之间还有无数个数”这一常见想错点。

### 环节 8：Exit Ticket 与小结（42–45 分钟）
Exit Ticket 3 题（学案末栏，下课前交）：
1. 画一条数轴。
2. 在你的数轴上标出 -2 和 1.5。
3. 这幅图（缺箭头）不是数轴，缺了什么？加上它后图会有什么变化？
小结 30 秒（学生一句话）：今天“数的家”叫什么？搬家三件套是什么？预告：下节课用数轴研究相反数。
设计意图：三题分别对准三条目标，当堂数据直接决定下节课开头是否补 3 分钟画图。

## 六、教师关键提问（汇总）

1. 引入：「温度计放倒后，你会先确定什么？」
2. 对比：「这张图别人看得懂吗？差的是什么？」
3. 概念：「没有箭头，别人知道往哪边越数越大吗？」「刻度一长一短，量出的‘温度’会怎样？」
4. 表示数：「1.5 夹在哪两个数之间？」「-3.5 为什么比 -3 更靠左？」「0 是正数还是负数？它在数轴上是什么角色？」
5. 辨析：「缺哪个要素？你怎么检查出来的？」
6. 迁移：「-4 画在 -3 左边，理由是什么？」

## 七、常见误解与教师应对

| 误解 | 应对 |
|---|---|
| 漏箭头 / 两端不出头 | 追问「别人知道往哪边越数越大吗」；口诀第三条互查；两端出头表示无限延伸 |
| 刻度间距不匀 | 比方：用一格大一格小的尺子量体温，读数忽大忽小；示范“先定单位长度，再逐格标数” |
| 1.5、-3.5「没有格子放」 | 教“先夹在相邻两个整数之间，再取中间位置”；对折格子演示 |
| 负数顺序反 | 回温度：「零下 3.5 度比零下 3 度更冷，更冷离 0 更远还是更近？」 |
| 0 当普通刻度、可画可不画 | 原点是“零上零下的分界”，没有 0 就分不清正负 |
| 画成射线或线段 | 追问「温度有没有头？」——两端都到不了头，所以画直线、两端出头 |
| 以为单位长度必须是 1 厘米 | 单位长度指“每格代表同样多”；本课一格代表 1，温度计一格代表 1℃ |

## 八、形成性理解检测

- 过程性：同桌三要素体检（环节 4）；读点快答正确率（环节 5）；找错抢答说理（环节 6）。
- 终结性：Exit Ticket 对准目标 1/2/3，课间只批第 3 题并统计正确率；低于三分之二则下节课开头重讲“箭头”3 分钟。

## 九、时间与设备 Plan B

- 无投影：作品贴黑板展示；温度计用实物或手绘大图。
- 引入超时超 2 分钟：取消人体数轴；环节 7 只做 ★、★★，★★★改课后思考。
- 学案未印：黑板出题，学生画在练习本上。
- 地面贴纸未备：人体数轴直接取消，主线不受影响。

## 十、板书设计

```
                2.2 数轴
   ［规范数轴图：—|—|—|—|—|—|—→
       -3  -2  -1  0  1  2  3］
   数轴：规定了原点、正方向、单位长度的直线
   三要素：原点（标 0）｜正方向（箭头向右）｜单位长度（每格一样多）
   口诀：直线出头 · 原点标零 · 箭头向右 · 刻度等距

```

1. Exit Ticket 第 3 题正确率如何？三要素是否立住了？
2. 1.5、-3.5 定位错误集中在哪些学生？下节课开头是否补 3 分钟？
3. “试画—找错”这条线有没有让平时不开口的学生动了手、发了言？记 2–3 个需重点关注名单。
