# 2.2 数轴（第 1 课时）教案

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 教材 | 北师大版七年级上册 第二章 有理数及其运算 |
| 课题 | 2.2 数轴（第 1 课时：数轴的概念与用数轴表示有理数） |
| 课型 | 新授课 |
| 课时 | 45 分钟 |
| 班级 | 45 人 |
| 课标依据 | 《义务教育数学课程标准（2022 年版）》：能用数轴上的点表示有理数，能用数轴比较有理数的大小。本课时落实"数轴的概念"与“能用数轴上的点表示有理数”，“比较大小”为第 2 课时内容 |

## 二、教学目标

1. 通过温度计模型抽象出数轴，说出数轴的三要素（原点、正方向、单位长度），能按步骤正确画出数轴。（抽象能力、几何直观）
2. 能用数轴上的点表示给定的有理数（含负整数、分数、小数），能读出数轴上给定位置的点所表示的数。（几何直观）
3. 初步体会数与形的对应关系，感受数形结合思想：任何一个有理数都可以在数轴上找到对应的点。

## 三、教学重点与难点

- **重点**：数轴的三要素；用数轴上的点表示有理数。
- **难点**：单位长度必须全轴统一的理解；负数与分数、小数在数轴上的定位。

## 四、学情与前置知识

- 学生已学 2.1 有理数：会用正负数表示具有相反意义的量，会按定义给有理数分类。
- 小学阶段用过直尺、温度计，见过“直线上的点表示数”，但未把方向、单位长度作为定义要素。
- 预计障碍：把数轴画成普通线段（缺要素）、负数部分标错位置、认为小数分数在数轴上“找不到点”。

## 五、教学准备

直尺（每人一把，画图必需）、刻度教具或画好刻度的黑板、学生学案（见后文）、课堂观察记录表（见后文）。无实物温度计时可用图片或口述情境。

## 六、教学过程

### 环节一 情境引入（5 分钟）

**教师活动**：出示温度计（或口述）：零上 5℃ 的刻度在 0 上面 5 格，零下 3℃ 在 0 下面 3 格。提问：温度计靠什么表示正数和负数？（一个 0 点、一个方向、均匀的刻度）追问：能不能用一条直线，把所有有理数像温度计这样表示出来？

**学生活动**：口答温度计的“三样东西”；带着问题进入新课。

**观察要点**：能说出“0 点、上下方向、刻度均匀”的学生比例——这是三要素的原型，答不出的班级在环节二先回到温度计再看一遍。

### 环节二 概念建构：三要素与画法（12 分钟）

**活动 1：从温度计到直线，抽象定义（教师引导 + 学生模仿画）**

定义：规定了**原点**（表示 0 的点）、**正方向**（用箭头表示，通常取向右）、**单位长度**（全轴统一的长度）的直线叫作数轴。

画法口诀（板书）：**一画线，二定点，三定向，四定单位。**

学生用直尺模仿画一条数轴，同桌互查四步是否齐全。

**活动 2：辨析纠错（同桌两人一组）**

教师给出四条“伪数轴”的文字描述，学生判断并补正：
- 甲：均匀标有 …,-1,0,1,…，但没画箭头。（缺正方向）
- 乙：有原点和箭头，但 0 到 1 的距离和 1 到 2 的距离不相等。（单位长度不统一）
- 丙：有箭头和均匀刻度，但 -1 标在原点右侧。（正负方向弄反）
- 丁：原点、箭头、均匀刻度齐全。（是数轴）

**活动 3：在数轴上表示数**

示范：把 -3、-1.5、0、2、3.5 标到同一条数轴上。强调 -1.5 在表示 -1 与 -2 的两点正中间——点不只在整数刻度上。

**观察要点（每条均含行为、原因、应对）**：
1. 学生按“线—原点—箭头—单位”顺序作图——顺序反映三要素意识，是本课核心定义。缺要素的，让他对照口诀逐步自查，不直接代改。
2. 用直尺取格、四格等距——单位长度统一才能保证“数”与“距离”对应。不均匀的追问：“0 到 1 和 1 到 2 的距离一样吗？不一样，凭什么说那是 1 和 2？”
3. 负数从原点向左依次标 -1、-2、-3——检验方向表象。标反的回到温度计类比：“越往下越冷，数越往左越小。”
4. 辨析时能用术语说出“缺什么”（如“这条没有正方向”），而不只说“不对”——概念语言内化的证据；只会说“不对”的，追问“对照三要素，缺哪条？”

### 环节三 例题与练习（12 分钟）

**例 1**：画一条数轴，并用点表示 -3、-1.5、0、2、3.5。学生独立画，教师巡视，取两份投影对比点评（重点看三要素与 -1.5 的位置）。

**例 2**：读点。数轴上：点 A 在原点右侧 4 个单位长度处；点 B 在原点左侧 2 个单位长度处；点 C 在表示 2 的点左侧 3 个单位长度处；点 D 在表示 -1 的点左侧 2 个单位长度处。分别写出各点表示的数。（A=4，B=-2，C=-1，D=-3）

**练习**：画一条数轴，并用点表示 -4、2.5、3。完成后同桌互查三要素。

**观察要点（巡视）**：
1. 2.5、3.5 等小数落在两整数刻度正中——等分意识；标歪的追问“2 和 3 的中点表示几”。
2. 标点用实心点并紧挨刻度写数——作图规范，为后续几何直观打基础。
3. 完成后主动对照口诀自查三要素——习惯养成；没有自查习惯的，抽查时先问“四步齐了吗”。

### 环节四 深化与课堂小结（6 分钟）

**深化提问**（先独立想，再同桌说，最后全班交流）：
1. 分数、小数在数轴上找得到对应的点吗？为什么？（能——在相邻整数刻度之间按份等分）
2. 有理数有无穷多个，一条数轴够它们用吗？（够——直线上点无穷多）

**小结**（学生说，教师补）：数轴三要素；画法四步；任何有理数都能用数轴上的点表示。预告下一课时：表示 2 与 -2 的点到原点距离有什么关系？——带着问题进入相反数。

### 环节五 当堂检测与反馈（8 分钟）

全班独立完成学案“当堂检测”（题目见学案，答案与分档标准见后文），完成后同桌交换，按参考答案互批，教师收齐统计举手表数，标记需再教名单。

### 环节六 作业布置（2 分钟）

- **必做**：课本 2.2 节随堂练习及习题 2.2 中“画数轴、用数轴上的点表示有理数”类基础题。
- **选做思考**：数轴上表示 2 与 -2 的两个点，到原点的距离有什么关系？（下一课时的入口）

## 七、易错预设与应对

| 学生表现 | 成因 | 教师应对 |
|---|---|---|
| 直线无箭头、无原点，只标一串数字 | 把数轴当普通线段，只关注数 | 用口诀四步全班齐查；让他重画并在四步旁打钩 |
| 单位长度不均匀（徒手随手取格） | 未建立“距离与数对应”的观念 | 强制直尺作图；示范“先取 4 个整数格，再细分半格” |
| 负数部分标错：-2 挤在原点与 -1 之间，或顺序混乱 | 对“越往左数越小”无表象 | 温度计类比 + 先标 -1，再依次向左 |
| 认为 -1.5、2.5 “没有点可标” | 只在整数刻度上找点 | 追问中点：“-1 和 -2 的正中间表示几？”明确点可取在刻度之间 |

## 八、板书设计

```
2.2 数轴
一、三要素：原点(0) · 正方向(箭头，通常向右) · 单位长度(全轴统一)
二、画法：一画线 → 二定点 → 三定向 → 四定单位
三、例1： -3  -1.5  0  2  3.5
   （板书一条标准数轴，标出五个点）
结论：任何有理数都能用数轴上的点表示
```

## 九、参考答案与当堂检测分档

- 练习（-4、2.5、3）：三点位置正确、三要素齐全为达标。
- 检测 T1：只有①正确。
- 检测 T2：-2、0、1.5、4 定位准确，三要素齐全。
- 检测 T3：A=-3，B=5。
- 分档：三题全对——达标；三要素缺一或 T3 错一空——接近达标；缺原点/方向/单位不均且 T3 两空皆错——需再教（记录名单，下节课前用 3 分钟小组重过画法口诀）。
