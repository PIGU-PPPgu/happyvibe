# 2.2 数轴（第1课时）分层教案

| 项目 | 内容 |
|---|---|
| 学科·年级 | 数学 · 七年级上册 |
| 教材 | 北师大版 第二章 有理数及其运算 · 2.2 数轴 |
| 课时 | 第1课时 · 45分钟 · 班额45人 |
| 课型 | 概念新授课 |

**课标依据**
《义务教育数学课程标准（2022年版）》数与代数·数与式·有理数：了解数轴，能用数轴上的点表示有理数。核心素养指向：数感、几何直观、抽象能力。

## 教学目标（分层）

| 层级 | 目标 |
|---|---|
| 基础层（A组） | 说出数轴三要素；按步骤画出数轴；在数轴上表示整数与0；写出简单有理数的相反数 |
| 提高层（B组） | 独立画出规范数轴；表示整数、分数、小数；借助数轴说明相反数两点关于原点对称 |
| 拓展层（C组） | 解决由点间距离确定数的逆向问题；用数轴处理温差等实际问题；辨析并改正不规范数轴 |

## 重点难点

- 重点：数轴的三要素；用数轴上的点表示有理数
- 难点：画数轴的规范性；数与点的对应及相反数的对称性

## 词汇表

| 术语 | 释义 |
|---|---|
| 数轴 | 规定了原点、正方向和单位长度的直线 |
| 原点 | 数轴上表示0的点 |
| 正方向 | 数轴上规定的正数方向，通常向右 |
| 单位长度 | 数轴上相邻两条刻度线之间的距离，全轴统一 |
| 相反数 | 只有符号不同的两个数互为相反数；0的相反数是0 |

## 灵活分组

- 依据：默认画像——本课未提供诊断数据。可参考上节课（2.1 有理数）作业中正负数书写的正确率：稳定的倾向提高层、拓展层，波动大的倾向基础层。
- 可调整：层级仅在本课有效。按例2完成情况与当堂检测重新分配——基础层学生若独立完成例1、例2，下节课上调；反之同理。

## 教学过程

**导入（5分钟）**
情境：温度计。提问：零上5℃、零下3℃怎么记？温度计的刻度有什么特点（有0点、分上下、刻度均匀）？
引出：把温度计放平、拉直，就是今天的工具——数轴。

**新授（12分钟）**
1. 数轴定义与三要素：原点、正方向、单位长度，对照温度计逐一对应，板书。
2. 画数轴四步示范：画一条水平直线 → 取一点表示0 → 向右画箭头规定正方向 → 选统一单位长度，向右标1、2、3…，向左标-1、-2、-3…
3. 用数轴表示数：正数在原点右侧，负数在原点左侧，0是原点本身。
4. 相反数初步：只有符号不同的两个数互为相反数；0的相反数是0；互为相反数的两点到原点距离相等，关于原点对称。
5. 反例辨析：缺箭头、刻度不均、无原点——三要素缺一不可。

**分层练习（15分钟）**——同一题干三层执行

| 阶段 | 基础层（A组） | 提高层（B组） | 拓展层（C组） |
|---|---|---|---|
| 例1 画数轴描点：-3、-1、0、2 | 四步填空支架引导完成 | 独立画轴，加描-1.5、3.5 | 独立完成后自查三要素 |
| 例2 数轴辨析（图形甲乙丙） | 判断是否数轴，说出缺什么 | 判断并写出完整理由 | 找错、改正，补画规范数轴 |
| 例3 相反数 | 直接写出-5、8、0的相反数 | 写出并说明3.5与-3.5的位置关系 | 加做：+5与-2两点相距几个单位 |

巡视要点：基础层优先看负数方向——发现把-2标在原点右侧的，回到正方向提问，不直接代改。

**当堂检测（6分钟）**
题目：在数轴上画出表示 -2、0、1.5、3 的点，并写出 +4 的相反数。
分类标准：掌握——三要素齐全、四点位置正确、相反数为-4；接近——缺一个要素，或1.5位置估错，或相反数写成4；需重教——不会起笔画数轴，或负数标在原点右侧。

**小结与反思（4分钟）**
口诀：原点、正方向、单位长度，缺一不可。
反思问题（印在练习单末）：数轴的三要素是什么？画数轴时你最容易漏掉哪一步？

**分层作业（3分钟）**

| 层 | 作业 | 用时 |
|---|---|---|
| 基础层 | 2.2节练习中的描点题与相反数题 | 约10分钟 |
| 提高层 | 2.2节练习＋用数轴说明+3.5与-3.5的位置关系 | 约15分钟 |
| 拓展层 | 2.2节练习＋选做题逆向问题（选做部分不计入书面作业） | 约15分钟 |

## 常见错误诊断

| 学生表现 | 原因 | 教师应对 |
|---|---|---|
| 画完数轴忘画正方向箭头 | 把数轴当普通刻度线 | 追问：三要素还缺哪个？对照温度计找对应 |
| 相邻刻度间距明显不等 | 未先定单位长度就随手标数 | 要求先取一段定为单位长度，再逐一标数 |
| 负数标在原点右侧 | 对正方向理解不到位 | 提问：哪边是正方向？负数应该在原点的哪一侧 |
| 认为0没有相反数 | 把相反数等同于“变号” | 回到定义：只有符号不同；0与0只有符号相同，规定0的相反数是0 |

## 为什么有效（1）

基础层的例1保留与提高层相同的题干，只增加四步填空支架——降低的是画图规范这一操作难度，不缩小内容范围。到例2时支架已消退为“判断＋说理由”，学生仍走向独立。

## 为什么有效（2）

拓展层的选做题是逆向问题：从“给定数找点”反转为“由两点距离确定数”，要求考虑A点两侧两种情况。这是新的认知方向，不是同类题加量。

## 锚点活动（选做题，三层练习单均印）

数轴上点A表示-2，点B与A相距5个单位长度。点B表示什么数？（提示：点B可能在点A的哪一侧？两种情况都要考虑。）
