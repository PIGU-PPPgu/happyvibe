## 二、学情分析

学生已学习正数、负数与零，能对有理数按整数、分数分类，有温度计读数的日常生活经验。常见困难：把数轴当成普通刻度线，画图时遗漏原点或箭头；负数定位时方向混乱；误以为数轴只能表示整数。班级 45 人，按四人小组分组（11 组），便于互查画图。

## 三、学习目标

1. 能说出数轴的三要素，并画出包含原点、正方向、单位长度的数轴。
2. 能用数轴上的点表示给定的有理数（含负整数、正分数、小数），能读出数轴上已知点表示的数。
3. 能结合实例说明“任何一个有理数都可以用数轴上的一个点表示”，初步体会数与形的对应。

## 四、重点、难点及依据

- 重点：数轴的三要素与画法；用数轴上的点表示有理数。依据：本节是后续相反数、绝对值、大小比较的共同图形基础。
- 难点：负数的定位（理解负方向与单位长度的对应）；任意有理数与数轴上点的对应关系。依据：学生第一次把“数”放到带方向的直线上，负方向容易与正方向混淆，分数小数易被排除在“数轴上的数”之外。

## 五、评价任务与成功标准

| 评价任务 | 成功标准 |
|---|---|
| 独立画一条表示 -3 和 2 的数轴 | 三要素齐全，-3 在原点左侧第 3 格，2 在原点右侧第 2 格，每格等长 |
| 在给定数轴上标出 -3, 2, 0.5, -1.5 | 四点位置正确，0.5 在 0 与 1 中间，-1.5 在 -1 与 -2 中间 |
| 读出 A、B、C、D 四点表示的数 | A=-2，B=1.5，C=-0.5，D=3（印刷位置：A 左侧 2 格，B 右侧 1.5 格，C 左侧 0.5 格，D 右侧 3 格） |
| 出口任务三小题 | 独立完成，负数方向正确，能用例子说明对应关系 |

## 六、教学过程

### 环节 1：从温度计到直线（5 分钟）
- 学习任务：观察温度计（实物、图片或口述），回答：0℃ 刻度在哪里？零上 5℃、零下 3℃ 各在 0 的哪一边？温度计怎样把数排成一条线？
- 教师支持：追问“温度计上刻度越往上，数越大，那能不能画一条水平直线，也把数这样排起来？”
- 学生表现与应对：若学生只答“零上在上面”，追问“0 这条刻度起什么作用”，引向“从 0 出发定位置”。
- 评价证据：能指出 0 的位置，能说明零上、零下分别在 0 的两侧。

### 环节 2：建构概念——三要素与画法（10 分钟）
- 学习任务：独立尝试画一条“能同时表示 -3 和 2”的直线（2 分钟）；同桌按“原点、正方向、单位长度”三项互查。
- 教师支持：巡视收集两三份典型作品投影对比；给出三条反例线（缺原点、无方向、刻度间距不均匀），让学生指出各缺什么并修正。
- 学生表现与应对：出现“刻度一格长一格短”时追问“这样每个 1 还一样长吗？-3 的位置还能确定吗”；出现漏原点时追问“-1 和 1 从哪里数起”。
- 评价证据：能指出每条反例缺哪个要素并说出理由；修正后的数轴三要素齐全。

### 环节 3：独立尝试——用数轴表示数（10 分钟）
- 学习任务：在自己画的数轴上标出 -3, 2, 0.5, -1.5 四个数对应的位置。
- 教师支持：提示顺序“先定原点和单位长度，正数往右数，负数往左数”；关注 0.5 与 -1.5 的定位，请一名学生板演 -1.5。
- 学生表现与应对：把 0.5 画在 0 的左侧时，追问“0.5 比 0 大还是小？大的数应往哪边”；认为“小数不能标”时，用“0 和 1 正中间的点”引导。
- 评价证据：四点定位正确，尤其 -1.5 位于 -1 与 -2 的正中间。

### 环节 4：交流辨析——读点与对应（8 分钟）
- 学习任务：读出印刷数轴上 A、B、C、D 四点表示的数；讨论两个问题：0 和 1 之间的一个点表示什么数？数轴上的点能不能表示分数和小数？
- 教师支持：公布答案要点 A=-2，B=1.5，C=-0.5，D=3，请读错的学生对照自己的数轴复核；用“任何一个有理数，都能在这条直线上找到它的位置”收拢到目标 3。
- 学生表现与应对：只报答案说不出理由时，追问“B 在原点哪一侧、几个单位长度”。
- 评价证据：能正确读出 1.5 和 -0.5，能举例说明分数小数也可表示。

### 环节 5：变式应用（7 分钟）
- 学习任务：
  1. 点 M 在原点左侧 4 个单位长度处，M 表示的数是什么？
  2. 点 N 表示 3，N 在原点哪一侧、几个单位长度处？
  3. （教师演示）同一条直线，把每一格改当作 0.5，原来在第 4 格的点现在表示什么数？
- 教师支持：第 3 题板演 4×0.5=2，说明“单位长度变了，同一个位置表示的数跟着变”，强调单位长度必须标明。
- 学生表现与应对：第 1 题答 +4 时，追问“左侧是比 0 大还是比 0 小的一侧”。
- 评价证据：M=-4；N 在原点右侧 3 个单位长度处；第 3 题答 2 并能说明理由。

### 环节 6：课堂检测与收束（5 分钟）
- 学习任务：独立完成出口任务（见学习单第 7–9 题）。
- 教师支持：收卷前口头回顾三要素；预告“下节课我们用数轴继续研究数的新性质”。
- 评价证据：出口任务按“三要素齐全且负数定位正确 / 定位正确但解释不完整 / 缺要素或负数方向错”三类记录。

**常见错误预判与应对**

| 具体表现 | 可能原因 | 教师追问 |
|---|---|---|
| 负数标在原点右侧 | 只按格数数，未建立负方向 | -3 应该从 0 往哪边数？为什么？ |
| 刻度间距不均匀 | 未意识到单位长度须处处相等 | 这样每个 1 还一样长吗？ |
| 漏画原点或方向箭头 | 把数轴当成普通刻度线 | 没有原点，各数从哪里数起？ |
| 认为分数、小数不能表示 | 误以为数轴只能标整数 | 0 和 1 正中间的点表示几？ |

**时间核对**：5+10+10+8+7+5=45 分钟，含学习单发放与收卷。

## 七、板书设计

- 主图（板书中央）：一条完整数轴，标注原点 O、正方向箭头、单位长度，图上标出 -3、-1.5、0、0.5、2。
- 左侧：三要素——原点、正方向、单位长度。
- 右侧：任何一个有理数 → 数轴上的一个点。

## 八、作业

- 基础（必做）：画一条数轴，标出 -4、-1、0、2.5 四个数。
- 变式（必做）：判断三条给定的直线中哪一条是数轴（一条缺原点、一条刻度间距不均匀、一条正确），对不是数轴的说明缺了什么。
- 开放（选做）：找一个生活中的“数轴”（温度计、直尺、电梯楼层、海拔高度等），说明它的原点、正方向、单位长度各是什么。

教材对应练习页待教师核对后补充。

## 九、课后反思观察点

- 画数轴时学生最常遗漏的要素是哪一个？
- 负数定位错误集中在整数还是分数、小数？
- 变式第 3 题有多少学生能说清“为什么”，而非只报结果？

## 十、可调整项与不可削弱的设计

- 可调整：温度计可用图片或口述替代实物；反例辨析可由三条减为两条；四人小组可改为同桌两人。
- 不可轻易削弱：学生亲手独立画数轴并完成负数定位；反例辨析；出口任务的独立检测。
