# 教案：19.1.1 变量与函数（第1课时：常量与变量）

**教材**：人教版八年级下册第十九章
**课时**：45分钟　**课型**：新授（含分层任务）

## 不变的核心目标与共同任务

**核心目标（全班一致）**
1. 在具体变化过程中，能指出哪些量在变化、哪些量始终不变，说出变量与常量的含义。
2. 能用含一个变量的式子表示另一个变量，初步体会两个变量之间的相依关系。
3. 知道变量与常量是相对于具体变化过程而言的。

**重点**：变量与常量的识别；用关系式表示两个变量的关系。
**难点**：判断前先确定变化过程；理解同一个量在不同过程中角色可以不同。

**共同核心任务（三层都要完成）**：出租车计费——起步价8元（3 km以内），超过3 km后每千米1.5元，行驶x km（x＞3），车费y元。写出y与x的关系式，指出其中的变量与常量。

## 教学过程

### 环节一　情境引入（5分钟）
黑板出示三个情境：
1. 汽车以60 km/h匀速行驶，行驶时间t（小时），路程s（千米）。
2. 每张电影票10元，售出x张，票房收入y元。
3. 弹簧原长12 cm，每挂1 kg重物伸长0.5 cm，挂重m kg后长度L cm。

提问：每个情境里，哪些数量在变，哪些数量始终不变？
学生先独立观察1分钟，再同桌交流。教师把学生的答案按“变/不变”分两栏板书，暂不给名词。

### 环节二　概念形成（10分钟）
1. 从板书归纳：数值发生变化的量叫**变量**；数值始终不变的量叫**常量**。
2. 师生共同写出三个情境的关系式：s＝60t；y＝10x；L＝12＋0.5m。逐式回指板书，确认字母各代表什么。
3. 辨析讨论：
   - 圆面积S＝πr²中，π是常量，r、S是变量；
   - 汽车匀速行驶时60 km/h是常量；若汽车变速行驶，速度就成了变量——变量与常量是相对“这个过程”说的。
4. 小结判断顺序：**先确定变化过程，再找变与不变**。（板书中栏保留）

### 环节三　分层任务（18分钟）
任务单同一版面印三种任务卡，学生自选入口，教师可建议调整；三层完成同一个核心任务。

**任务卡A（基础）**——入口更清晰，支架多
- 附“四步工作卡”：①找出变化过程　②圈出数值变化的量　③圈出数值不变的量　④用式子把两个量连起来。
- 附半成品表格（第一行已填好作示例）：

| 情境 | 变量 | 常量 | 关系式 |
|---|---|---|---|
| 弹簧（示例） | m，L | 12，0.5 | L＝12＋0.5m |
| 电影票 |  |  |  |
| 行驶 |  |  |  |
| 出租车（核心任务） |  |  |  |

- 出租车情境附句式支架：“车费＝起步价＋每千米单价×（行驶路程－3）”，学生代入数字成式。
- 中途检查点：填完表格前三行举手，教师面批确认后再做出租车题。
- 独立程度：在支架下完成，可与同桌讨论。

**任务卡B（提升）**——独立完成核心任务，只留少量支架
- 直接独立完成出租车核心任务（不给句式支架，四步工作卡只在卡住超过3分钟时由教师递给）。
- 附加：若收费政策改为“起步价6元”，关系式中哪些数变了、哪些没变？据此说明常量指的是“这个过程中的数值”还是“某个字母”。
- 独立程度：独立完成，只在求助时给提示。

**任务卡C（挑战）**——无支架，加大比较与构造要求
- 独立完成出租车核心任务。
- 附加一（构造）：自己编一个生活中含两个变量的过程，写出关系式，说明谁是变量、谁是常量、常量为什么不变；向同桌口头讲一遍，对方听懂才算完成。
- 附加二（比较）：情境1中速度60 km/h是常量；若汽车从甲地到乙地实际是变速行驶，“平均速度”还是常量吗？时间还是变量吗？写出判断和理由。
- 独立程度：完全独立。

### 环节四　共同的理解检测（7分钟）
全员统一完成，不分层，同桌互批后教师报答案与理由：
1. 声音在空气中传播速度约340 m/s，传播路程s（m）与时间t（s）的关系式是＿＿；其中变量是＿＿，常量是＿＿。
2. 判断并说理由：有人说“π会跟着面积公式变化，所以π是变量”。

### 环节五　小结与作业（5分钟）
小结提问：什么叫变量、常量？判断之前要先确定什么？

作业（全员同一核心，支架不同）：
- 核心作业：①水池每分钟注水2 m³，注水t分钟，水量V m³——写关系式，指出变量与常量；②一本笔记本5元，买x本付款y元——同上。
- 基础层：另附一份不同情境的完整示例供对照模仿。
- 提升层：独立完成，无附加材料。
- 挑战层附加：把①改为“池中先有10 m³水再开始注水”，关系式怎么变？哪个量的数值因此改变了角色？说明理由。

## 教师巡视观察点

- 基础层：是否按四步工作卡逐条执行；圈“变量”时是否把单位（km/h、元）当成量；面批出错集中在四步中的哪一步。
- 提升层：出租车情境里对“3 km以内”的处理是否含糊；写完关系式能否口头说出每个字母的含义（防止照抄句式不理解）。
- 挑战层：构造的情境是否真的含两个变量（有的学生编出只含一个量的“过程”）；“平均速度”的辨析是否说到位；同桌互讲是否真的发生。

## 支架的增撤时机

- 增：基础层中途检查点连续出错，教师当面示范出租车情境的第一步；提升层卡住超过3分钟，只递四步工作卡，不讲答案。
- 撤：基础层连续两次面批全对，收回句式支架，剩余独立完成；提升层开始附加题前撤掉全部提示；挑战层全程无支架。
- 收口：本课结束时任何一层都不保留未撤支架；下一课时不再提供四步工作卡与半成品表格。

## 板书设计

- 左栏：三个情境的关系式，变量下加“△”、常量下加"○"标注
- 中栏：变量、常量定义；“先确定变化过程，再找变与不变”
- 右栏：y＝8＋1.5(x－3)（x＞3），变量x、y，常量8、1.5、3
