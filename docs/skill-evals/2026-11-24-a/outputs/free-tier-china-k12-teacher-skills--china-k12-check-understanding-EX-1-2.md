## 第二部分 参考答案与解析（教师用）

每题给出：参考答案；理想回答中的关键证据；主要错误回答反映的思维；下一步教学动作（追问、重新表示、小任务或演示）。

### 选择题

**1. B（3 分）**
解析：一次函数形如 y = kx + b（k、b 为常数，k ≠ 0）；正比例函数 y = kx 是 b = 0 的特例。A 是正比例函数（b = 0）；B 中 k = 1/3 ≠ 0、b = -1 ≠ 0，是一次函数且不是正比例函数；C、D 不符合 y = kx + b 的形式。
典型错误：
- 选 A：把“正比例函数是一次函数的特例”与题干“但不是正比例函数”的排除条件冲突处理，或读题漏掉“但不是”三个字。
- 选 D：用“式子里带一个字母加一个常数”的结构特征匹配，没有检验 x 的次数。
下一步：小任务——给 6 个解析式，让学生按“正比例函数 / 一次函数但非正比例 / 不是一次函数”分三类；分类后追问“B 为什么同时满足‘是’和‘不是正比例’”。
说明：选 C 的学生可能说出“反比例函数”，八年级下册未学该名词，讲评时只按“y 与 x 的积是定值、不符合 y = kx + b 形式”判断即可。

**2. C（3 分）**
解析：y 随 x 增大而减小 → k < 0；b = 3 > 0，图象与 y 轴交于正半轴。k < 0 时 x < 0 必有 y > 3 > 0，图象上不存在“x < 0 且 y < 0”的点，故不经过第三象限；x > 0 段先在上方（第一象限）后跌破 x 轴（第四象限）。
关键证据：学生能同时用 k 的符号定方向、用截距点 (0, 3) 定位置。
典型错误：
- 选 A：由“减小”联想到“图象朝右下”，推出“朝下的线不过第一象限”，没有用截距 (0, 3) 定位。
- 选 B：认为“交 y 轴正半轴的直线不经过第二象限”，截距信息与象限判断脱节。
- 选 D：只记 b > 0 抬高图象，忘了 k < 0 使右支进入第四象限。
下一步：演示——先画点 (0, 3)，过它作一条左高右低的直线，让学生报出直线穿过的象限；追问“x = 0 时 y 是几？x 很大时 y 是正是负？”

**3. A（3 分）**
解析：图象过 (0, 4) 得 b = 4；过 (1, 2) 得 2 = k + 4，k = -2。解析式 y = -2x + 4。代回两点均满足。
典型错误：
- 选 B（y = 2x + 4）：解 2 = k + 4 时移项不变号，得 k = 2 + 4。
- 选 C（y = -0.5x + 4）：斜率用横坐标差除以纵坐标差，k = (1 - 0)/(2 - 4)。
- 选 D（y = 4x - 2）：求出 k = -2、b = 4 后把两个系数的位置写反。
下一步：小任务——要求学生把所得解析式代回两个已知点逐一检验；追问“k = -0.5 意味着 x 每加 1，y 变多少？和图象上 (0, 4) 到 (1, 2) 的实际变化一致吗？”

**4. A（3 分）**
解析：2x + 4 > 0 即函数值 y > 0，对应图象在 x 轴上方的部分。分界点是交点 A(-2, 0)；k = 2 > 0，图象从左到右上升，交点右侧在 x 轴上方，解集 x > -2。
典型错误：
- 选 C：把 A(-2, 0) 读成 (2, 0)，符号丢失。
- 选 B：知道看交点两侧，但“上升”方向或上下位置判断反了。
- 选 D：把"y > 0"与"x > 0"混为一谈。
下一步：重新表示——让学生在草图上标出 A，沿图象指出“哪一段在 x 轴上方”，再读出对应的 x 范围；追问“x = -3 时 y 是多少？这个点在 x 轴上方还是下方？”

**5. B（3 分）**
解析：向左平移 2 个单位，自变量替换 x → x + 2，得 y = 2(x + 2) = 2x + 4。用点检验：原直线过 (0, 0)，左移后为 (-2, 0)，代入 y = 2x + 4 成立。
典型错误：
- 选 A：知道“左加”，但只给常数项加 2，没有乘 k。
- 选 C：方向记反（左减右加），但乘了 k。
- 选 D：方向记反且没有乘 k。
下一步：追问“平移时直线上的每个点都在动，(0, 0) 移到了哪？把它代进你选的解析式”——用点的平移重新表示直线的平移。

**6. C（3 分）**
解析：k = -3 < 0，y 随 x 增大而减小，图象过一、二、四象限；令 x = 0 得 y 轴交点 (0, 1)；令 y = 0 得 x = 1/3，x 轴交点 (1/3, 0)。
典型错误：
- 选 A：把“k < 0 过二、四象限”与“b > 0 过一、二象限”两条口诀机械叠加，没有合并排除。
- 选 B：把 b = 1 > 0 当成“函数在增大”的依据。
- 选 D：x 轴交点的坐标顺序写反，写成 (0, 1/3)。
下一步：演示两类点的求法对照——求 y 轴交点令 x = 0，求 x 轴交点令 y = 0；追问“x 轴上的点，纵坐标是几？”

**7. C（3 分）**
解析：蜡烛每小时缩短 4 cm，剩余长度 y 随 x 增大而减小 4，故 C 错误。A：y = 20 - 4x 正确；B：x = 3 时 y = 20 - 12 = 8 正确；D：y = 0 时 x = 5 正确。
典型错误：选了 A、B、D 之一或认为四项都对：把“每小时缩短 4 cm”读成“y 的变化量是 4”，没有确认变化方向——烧掉的长度不会回来，y 只能减小。
下一步：追问“x = 4 时 y 是多少？x = 5 时呢？y 在变大还是变小？”用两个具体值对冲击散的口头判断。

**8. A（3 分）**
解析：向下平移 3 个单位，b 减 3：y = 3x + 2 - 3 = 3x - 1，与直线 y = 3x - 1 完全相同，位置关系是重合。
典型错误：
- 选 B：知道“k 相同的两条直线平行”，但没有先完成平移，或认为“两条不同的直线只能平行”。
- 选 C：在“k 相同必平行”与“平移会改变直线”两条结论之间冲突，选了中间答案。
下一步：小任务——先把平移后的解析式写出来，再比较 k、b；追问“两条直线什么时候平行？什么时候重合？”

**9. A（3 分）**
解析：交点同时满足两条直线的解析式，即同时满足方程组的两个方程，所以交点坐标 (1, 3) 就是方程组的解：x = 1，y = 3。
典型错误：
- 选 B：坐标 (1, 3) 与"x = ?, y = ?"的对应顺序颠倒。
- 选 D：把“两条不同的直线”当成“平行”，推出无解。
下一步：追问“把 x = 1, y = 3 代回两个方程是否都成立？再代 B 试试？”用代回检验建立“解 ↔ 交点”的双向对应。

**10. A（3 分）**
解析：y₁ = 0.2x，y₂ = 0.1x + 10。令 0.2x = 0.1x + 10，得 x = 100，此时话费均为 20 元。x < 100 时 y₁ < y₂，甲公司低；x > 100 时 y₁ > y₂，乙公司低。故 B、C 方向均反；差值 y₁ - y₂ = 0.1x - 10 随 x 增大而减小，乙公司优势随通话时间扩大，D 错。
典型错误：
- 选 B 或 C：解出临界点 100 分钟后，两侧“谁便宜”的方向写反。
- 选 D：按“乙公司每分钟单价低”的直觉外推，忽略月租 10 元要在长时间内摊薄。
下一步：追问“通话 50 分钟、150 分钟时各算一遍总费用再比”，用两个具体值校验方向。

### 填空题

**11. m = -1（3 分）**
解析：一次函数要求 x 的次数为 1 且系数不为 0：m² = 1 得 m = ±1；m - 1 ≠ 0 排除 m = 1。所以 m = -1。
典型错误：
- 答 m = ±1：只考虑“次数为 1”，漏掉“系数不为 0”。
- 答 m = 1：只取正根且没检验系数，此时 y = 0·x + 2 是常函数。
下一步：追问“如果 m = 1，解析式变成什么？还是一次函数吗？”让学生把候选值代回，按“次数为 1”“k ≠ 0”两个条件逐条核对。

**12. y = 2x + 6（3 分）**
解析：y 与 x + 3 成正比例，设 y = k(x + 3)。代 x = 1：k(1 + 3) = 8，k = 2，展开得 y = 2x + 6。
典型错误：设 y = kx + 3，把"x + 3"当成常数项，得 y = 5x + 3。这个错解代 x = 1 也得 8，单点检验发现不了，需换第二个点（如 x = -2：正解 y = 2，错解 y = -7）。
下一步：重新表示——追问“‘与 x + 3 成正比例’，把 x + 3 看成一个整体，y 和它是什么关系？”先写 y = k(x + 3) 再展开；小任务：代 x = -2 检验两种设法谁对。

**13. (0, 2)；(-2/3, 0)（各 1.5 分）**
解析：y 轴交点令 x = 0，y = 2；x 轴交点令 y = 0，3x + 2 = 0，x = -2/3。
典型错误：x 轴交点写成 2/3（移项不变号）；坐标顺序写反成 (0, -2/3)。
下一步：用对照表训练“求哪个轴的交点，就令哪个字母为 0”；追问“x 轴上的点纵坐标是几？y 轴上的点横坐标是几？”

**14. 4（3 分）**
解析：与 x 轴交点 (2, 0)，与 y 轴交点 (0, 4)，两条直角边长分别为 2 和 4，面积 = (1/2) × 2 × 4 = 4。
典型错误：答 8——底乘高后漏乘 1/2。
下一步：演示——在图上标出两个交点，让学生指认三角形的“底”和“高”各是哪条线段，再套公式。

**15. 答案不唯一（3 分）：满足 k < 0 且 b < 0 即可，如 y = -x - 1、y = -2x - 3。**
解析：过二、三、四象限 ↔ 图象下降（k < 0）且与 y 轴交于负半轴（b < 0）。
典型错误：写出 k < 0、b > 0 的解析式（如 y = -x + 1）：图象过一、二、四象限，缺第三象限——只关注下降方向，忽略截距；写出 y = -x（b = 0）：只过二、四象限和原点。
下一步：追问“你写的函数与 y 轴交在哪？这个交点在 x 轴上方还是下方？”让学生用截距自检。

**16. 答案不唯一（3 分）：k < 0 且 k + b = 2，如 k = -1，b = 3（y = -x + 3）。**
解析：递减 → k < 0；过 (1, 2) → k + b = 2，b = 2 - k。任取一个负的 k，算出 b。
典型错误：k 取正值，忽略增减性条件；b = 2 + k（移项不变号，代回 (1, 2) 不满足，可自检）。
下一步：小任务——把自己写的解析式代回 (1, 2)，并检查 k 的符号，两步都通过才算完成。

### 解答题

**17.（8 分）**
参考答案：
作图（2 分）：取 x = 0、x = 2，得点 (0, 2)、(2, 0)，过两点画直线并向两端延伸，标注坐标轴。
（1）（2 分）在图象上。把 x = 4 代入：y = -4 + 2 = -2，与该点纵坐标一致。
（2）（2 分）x < 2。图象与 x 轴交于 (2, 0)，k = -1 < 0 图象从左到右下降，交点左侧在 x 轴上方。
（3）（2 分）直线与 x 轴、y 轴交于 (2, 0)、(0, 2)，直角边长均为 2，面积 = (1/2) × 2 × 2 = 2。
典型错误与下一步：
- 只描一个点就画“直线”：一个点不能确定直线。追问“过一点能画几条直线？”
- （2）写 x > 2：方向反。让学生沿图象从交点向两侧走，先指出 y > 0 的一段，再读 x 范围。
- （3）答 4：漏乘 1/2。演示底与高的标注。

**18.（8 分）**
参考答案：
（1）（5 分）设 y = kx + b。代入两点：k + b = -1，2k + b = 1。两式相减得 k = 2，回代得 b = -3。解析式 y = 2x - 3。
（2）（3 分）令 y = 0：2x - 3 = 0，x = 3/2，与 x 轴交点 (3/2, 0)；令 x = 0：y = -3，与 y 轴交点 (0, -3)。
关键证据：学生列两个方程、消元求 k 与 b、并回代检验。
典型错误与下一步：
- 解方程组时移项不变号：把求出的 k、b 代回两个已知点，一步即可发现。追问“你算的直线真的过这两个点吗？”
- 只解出 k 没回代求 b（答案写成 y = 2x + b）：演示“两个未知数需要两个方程，各解一次”。
- 交点坐标符号或顺序错：追问“x 轴上的点纵坐标是几？”

**19.（8 分）**
参考答案：
（1）（2 分）步行速度 1200 ÷ 15 = 80（米/分），y = 80x（0 ≤ x ≤ 15）。
（2）（4 分）骑车速度 1200 ÷ 5 = 240（米/分）。返程从 x = 20 开始，y = 1200 - 240(x - 20) = -240x + 6000（20 ≤ x ≤ 25）。检验：x = 20 时 y = 1200，x = 25 时 y = 0，均与情境一致。
（3）（2 分）240 ÷ 80 = 3 倍。
典型错误与下一步：
- （2）写成 y = 1200 - 240x：没有处理“第 20 分钟才开始返程”的时间差。让学生代 x = 25 自检——得 y = 600 ≠ 0，而人应到家。追问“x = 20 时人在哪？代进你的式子，y 等于多少？”
- 位移写成 -240(x + 20) 等变式：演示“把返程那 5 分钟单独计时 t = x - 20”，先对 t 写解析式再换回 x。
- 讲评补问：15 ≤ x ≤ 20 期间 y 是多少（y = 1200），为完整分段图象做铺垫。

**20.（10 分）**
参考答案：
（1）（3 分）y₁ = 0.1x + 15，y₂ = 0.25x（x ≥ 0）。
（2）（3 分）0.1x + 15 = 0.25x，0.15x = 15，x = 100。每月通话 100 分钟时两类卡话费相同，均为 35 元。
（3）（4 分）小李 80 分钟：y₁ = 23，y₂ = 20，y₁ > y₂，选 B 类卡更合算（2 分）。小王 150 分钟：y₁ = 30，y₂ = 37.5，y₁ < y₂，选 A 类卡更合算（2 分）。结合（2）：临界点是 100 分钟，低于它 B 类低，高于它 A 类低，80 与 150 恰在两侧。
典型错误与下一步：
- （3）结论方向反：先解临界点，再在两侧各代一个值校验。追问“通话 50 分钟时两张卡各花多少钱？”
- 只比单价（0.1 < 0.25 → 直接选 A 类）：忽略月租 15 元。演示：把“总费用 = 月租 + 通话费”拆成两段分别列出再比较。

**21.（10 分）**
参考答案：
（1）（3 分）过 (0, 2) 得 b = 2；过 (2, -2)：2k + 2 = -2，k = -2。解析式 y = -2x + 2。
（2）（2 分）图象是过 (0, 2) 与 (1, 0) 的直线，描两点后向两端延伸。
（3）（2 分）x < 1。图象与 x 轴交于 (1, 0)，其左侧图象在 x 轴上方。
（4）（3 分）-2x + 2 = x + 5，-3x = 3，x = -1，y = 4，P(-1, 4)（2 分）。两直线与 y 轴交点为 (0, 2)、(0, 5)，底边长 3；P 到 y 轴的距离 |-1| = 1 为高；面积 = (1/2) × 3 × 1 = 3/2（1 分）。
典型错误与下一步：
- （3）写 x > 1：方向反。回到图象指认 x 轴上方的一段。
- （4）高忘取绝对值（x = -1，距离为 1）：演示“点到 y 轴的距离 = |横坐标|”。
- 解出 x = -1 后代错直线求 y：把 x = -1 代回两个解析式各算一遍，结果应同为 4，不一致即出错。

**22.（8 分）**
参考答案：
（1）（2 分）过原点 → m - 3 = 0，m = 3（此时 2m + 1 = 7 ≠ 0，仍是一次函数）。
（2）（3 分）2m + 1 < 0，m < -1/2。
（3）（3 分）-1/2 < m ≤ 3。不经过第二象限需 k > 0 且 b ≤ 0：k > 0，b < 0 时过一、三、四象限；k > 0，b = 0 时过原点、过一、三象限。由 2m + 1 > 0 得 m > -1/2，由 m - 3 ≤ 0 得 m ≤ 3。
典型错误与下一步：
- （1）不检验 2m + 1 ≠ 0：本题 m = 3 恰好安全。追问“如果解出的 m 让 2m + 1 = 0，结论还成立吗？”
- （3）漏 m = 3（b = 0 的端点）：让学生分别画出 b > 0、b = 0、b < 0 三种 k > 0 的图象，逐一核对是否经过第二象限。
- （3）只约束 b ≤ 0、漏 k > 0（答 m ≤ 3）：把“k > 0”与“b ≤ 0”两个条件并列写出，再求交集。
- （3）认为 k < 0、b < 0 也行：画出该情形图象（过二、三、四象限），指出其中的第二象限部分。
