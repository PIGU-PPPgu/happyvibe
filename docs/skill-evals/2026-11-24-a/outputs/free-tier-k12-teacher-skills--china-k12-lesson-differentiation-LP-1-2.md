# 材料一 教师方案

北师大版《数学》七年级上册 第二章 2.2 数轴 · 第1课时 · 45 分钟 · 班额 45 人

## 一、课程依据与共同目标

| 项目 | 记录 |
|---|---|
| 学段与年级 | 初中，七年级（义务教育第三学段） |
| 学科 | 数学 |
| 课程标准 | 《义务教育数学课程标准（2022年版）》 |
| 核心素养 | 几何直观、抽象能力（数形结合意识） |
| 课程内容主题 | 数与代数 · 数与式 · 有理数 |
| 学业要求 | 能用数轴上的点表示有理数，理解数轴的三要素（依据课标概括，待教师核对） |
| 教材 | 北师大版七年级上册第二章 2.2 数轴第1课时（教师提供；版次与页码待核对） |

本课共同目标（三组不降级）：
1. 能说出数轴的三要素（原点、正方向、单位长度），并独立画出一条规范的数轴；
2. 能用数轴上的点表示给定的有理数，能读出数轴上一点所表示的数；
3. 初步建立数与点的对应意识，感受数形结合。

不可降低项：三组都必须完成画数轴、负数描点和读图写数；A 组不删减负数任务，只增加过程支持。
关键难点：负数在原点左侧的定位；数与点的双向对应；单位长度的统一。

## 二、学情证据与暂定分组

- 未提供前测或作业证据，采用暂定学习起点：多数学生认识温度计、知道正负数，但尚未把“数与点的对应”外化出来；画图程序和负数方向是本课最可能卡点。
- Group A（起点支持路径）：暂定给在“画数轴步骤”或“负数方向”上需要过程支持的学生；任务1互检后按作品证据调整。
- Group B（目标达成路径）：暂定按本课目标独立完成的学生。
- Group C（深化迁移路径）：暂定能独立画、读且提前完成任务的学生；名额课中动态发放。
- 分组是本课暂定路径，不是能力等级；学生页不出现路径名称与分组理由。

## 三、共同内容（三组逐字一致）

**核心任务1（学生文本）**：画一条数轴：确定原点，规定向右为正方向，选定单位长度（每格表示 1），然后在数轴上表示出 3、0、-2、-4 这四个数，并用点标出每个数的位置。

**核心任务2（学生文本）**：读黑板上的图①，写出 A、B、C、D 四点表示的数。图①说明：一条水平数轴，原点标 0，右端画箭头表示正方向，从 -4 到 4 每格表示 1 个单位长度；点 A 在原点左侧第 3 格，点 B 在原点右侧第 1 格，点 C 在原点右侧第 2 格与第 3 格的正中间，点 D 在原点左侧第 1 格。
（答案供教师：A＝-3，B＝1，C＝2.5，D＝-1。）

**课堂检测（独立 5 分钟）**：独立完成，不讨论。画一条数轴，三要素齐全，在上面表示 -2 和 1.5；再用一句话写清：判断 -2 的位置时，先看什么，再做什么。

**完成后继续（早完成）**：画一条每格表示 10 的数轴，标出 -30、20 和 50。再回答：一条直线如果没有标出原点，能不能确定表示 -3 的点的位置？写一句话说明理由。

**回顾**：今天画数轴时，哪一步最容易出错？你用什么方法检查出来的？写一两句。

**词汇表（三组共享）**

| 词 | 意思 |
|---|---|
| 原点 | 数轴上表示 0 的点 |
| 正方向 | 从原点出发规定的正数方向，通常向右，箭头画在直线右端 |
| 单位长度 | 每一格代表的长度，同一条数轴上必须一致 |
| 描点 | 在数轴上用点标出表示某个数的位置 |

**同桌互检三条（三组同）**：三要素齐全；每格长度相同；右正左负。

## 四、三组设计对照

| 项目 | Group A | Group B | Group C |
|---|---|---|---|
| 学习入口 | 步骤自检表外化画图程序；三步定位框架＋证据表读图 | 独立画、独立读 | 同 B，另加“进一步思考”两项 |
| 支架 | 画图自检表＋读图三步框架（互检后撤除） | 无（仅共享词汇表） | 无 |
| 教师追问 | 0 在哪？-2 从 0 往哪边数格子？这个点在 0 的哪一侧？ | 每格长度一样吗？-4 和 -2 哪个离 0 远？ | 单位长度改成每格 10，图哪里变了？表示 5 和 -5 的点到原点的距离有什么关系？ |
| 预期表现 | 独立画出三要素齐全的数轴，负数描点方向正确 | 全对并说清定位依据 | 全对，并完成单位长度建模与“到原点距离”的规律概括 |
| 打印内容 | 词汇表、任务一（带自检表）、任务二（带框架）、课堂检测、完成后继续、回顾 | 词汇表、任务一、任务二、课堂检测、完成后继续、回顾 | 词汇表、任务一、任务二、进一步思考、课堂检测、完成后继续、回顾 |

## 五、课堂流程（45 分钟）

| 时间 | 环节 | 组织 |
|---|---|---|
| 0–5 | 情境导入（共同） | 出示温度计，三问：0 刻度在哪里？零上、零下各朝哪边？每一小格表示多少？把温度计横放（0 居中、零上朝右），指出横过来就是今天要研究的图 |
| 5–13 | 概念与示范（共同） | 给出数轴定义与三要素；教师在黑板边说边示范画一条完整数轴（画直线→取点标 0→右端箭头→定单位长度→两边依次标数）；全班口头复述三要素 |
| 13–26 | 核心任务1 | 学生独立画数轴并描点，画完执行同桌互检三条；A 组先读步骤自检表再动笔；教师巡视顺序为先看 A 再抽 B/C |
| 26–34 | 核心任务2 | 全班读图①写数；A 组按三步定位框架逐点完成；完成后同桌互检；教师对 A 组集中指导不超过 5 分钟 |
| 34–39 | 课堂检测 | 独立完成，本环节不互检，收回后批改 |
| 39–45 | 回顾与收束 | 全班写回顾两问；早完成学生做“完成后继续”；请 1 名学生口述“画数轴先做什么”；预告下节课在数轴上研究数到原点的距离 |

## 六、课中形成性检查与换组规则

**检查点1**（任务1互检后，约第 24 分钟）：看互检结果与抽看作品——三要素是否齐全；-2、-4 是否在原点左侧；每格是否等长。
- 换 A：漏箭头或漏 0、负数画到原点右侧者 → 换用 A 组任务单重画一条，进入教师小组指导（5 分钟内，只讲这一种卡点）。
- 加 C：任务1全对且提前完成者 → 发放“进一步思考”，加入 C 路径。

**检查点2**（任务2互检后，约第 33 分钟）：看读图错误模式——左右侧判反者，教师在旁带做一遍三步定位；2.5 这类半格定位错者，提示“先数整格，再取正中间”。

**检测后分流（安排下一课）**：
- 达标：三要素齐全、-2 在原点左侧第 2 格、1.5 位于 1 与 2 之间、方向依据写清 → 下一课正常进入 2.3 绝对值。
- 部分达标：三要素缺一（常见漏箭头、漏 0）或 1.5 位置错 → 下一课前 5 分钟用步骤自检表重画一条。
- 未达标：-2 画到原点右侧或大面积空缺 → 下一课开始重做核心任务1，教师小组指导，通过后再进新课。

换组原则：依据本课两个检查点的作品证据，同课内即可换单；不以一次检测定长期组别；下一课起点以共同检测为准。

## 七、设计理由

- A 组保留同一核心任务：仍要独立画数轴、描负数点，自检表只把程序外化，互检后撤除（任务单末尾有撤除提醒）。
- C 组不加题量：单位长度建模与“到原点距离”的规律概括是新增思维，后者直接为 2.3 绝对值铺路。
- 三组共享同一情境、同一图①、同一检测，教师只用一套口令；支架印在任务单上，教师只处理关键卡点。
- 同桌互检承担第一轮核对，适配 45 人班额。

## 八、大班实施说明（45 人）

- 任务单课前印好，正面朝下按暂定分组分发，先独立作答再互检。
- 同一时间只有一处需要教师集中指导（A 组小组），其余巡视抽看。
- 共同开始、共同收束，中段分组走三条路径；早完成统一领“完成后继续”，不发临时任务。
- 互检按同桌一对一进行，只核对三条标准，不评等级。
