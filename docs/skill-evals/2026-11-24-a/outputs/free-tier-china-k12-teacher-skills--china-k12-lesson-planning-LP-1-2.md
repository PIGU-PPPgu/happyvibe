# 2.2 数轴（第 1 课时）教案

- 教材：北师大版七年级上册 第二章 有理数及其运算
- 课时：第 1 课时（共 1 课时完成数轴概念与表示）｜ 45 分钟 ｜ 45 人
- 课标锚定（只锚 2 项）：几何直观、抽象能力（体会数与点的对应）

## 一、学情与前置知识

已学：正数与负数、相反意义的量、有理数分类（2.1），能用正负数记录温度、收支等。有温度计、东西方向走路的生活经验。
未学：相反数、绝对值，本课不引入这两个术语。
预判困难：负数往哪边放、分数（小数）在数轴上怎么定位、单位长度“统一”的意识弱。

## 二、教学目标与学习证据

| 目标（可观察行为） | 学习证据 |
|---|---|
| 1. 能说出数轴的三要素，并画出一条合格的数轴 | 每人交 1 条数轴，同桌按 4 条标准互查通过 |
| 2. 能用数轴上的点表示给定的有理数（含分数），能读出数轴上点所表示的数 | 任务单第 1、2 题正确标注与作答 |
| 3. 能发现并改正不含全部要素的“假数轴”，说出理由 | 辨析题口头作答 + Exit Ticket 第 3 题 |

设计意图：三条目标分别对应“会画、会用、会辨”，每条都有当场可收的作品或作答，不以“掌握数轴概念”这类无法检查的说法代替。

## 三、重点难点

- 重点：数轴三要素；用数轴上的点表示有理数。
- 难点：①理解为什么三个要素缺一不可；②-2.5 这类数在原点左侧的准确定位。

## 四、教学准备

- 直尺（人手一把，数学课自带，不需额外采购）
- 任务单 1 张/人（A4 半张：画线体验区 + 标数题 + 辨析题；若未打印，全部改在练习本上，见 Plan B）
- 磁贴小黑板或投影（用于展示学生作品，可选）
- 红蓝粉笔各一支（红笔专标负数方向，形成“左边=负”的视觉固定）

## 五、课堂流程（45 分钟）

**0–3 分钟｜情境引入**
口述：今天清晨气温是 -3℃，中午升到 5℃。
提问：“你在温度计上是怎么看出 -3 的？温度计上必须有哪几样东西，你才能读数？”
学生答：要有 0（零上零下的分界）、往上往上数、每一格一样大。
过渡语：“温度计其实就是一条竖着的'数线’。今天我们把它放平，搬到纸上。”
（设计意图：温度计是学生每天接触的“现成数轴”，把三要素的直觉先唤醒，再用走路情境抽象成水平直线，避免从定义硬讲。）

**3–10 分钟｜学生画线：让“缺要素”自己长出来**
任务（写在小黑板上）：“校门口记作 0。向东走 3 步是书店，向西走 2 步是文具店。在任务单上画一条线，让同桌不看你的文字说明，也能一眼看出三个地点的位置。”
学生独立画（3 分钟），教师巡视，挑出三类典型作品：
- A 类：只画了线段、写了三个名字（没有方向、没定起点、格不均匀）
- B 类：有方向有起点但每格长短不一
- C 类：合格
同桌互看（1 分钟），再全班对比展示（3 分钟），逐条追问：
- “只看 A 的图，你知道哪边是东吗？校门口在哪？”→ 缺方向和起点说不清
- “B 的图里，走 3 步真比走 2 步远吗？格子不一样大就看不出长短关系”
（设计意图：不直接给定义，让学生在“画不出来、说不清楚”里体会三要素分别管什么，困难来自自己的作品，纠正时才服气。）

**10–17 分钟｜提炼定义与三要素**
结合对比结果，师生共同得出：规定了**原点**、**正方向**、**单位长度**的直线叫做数轴。
逐条落实：
- 原点：表示 0 的点，先定 0 才有“零上零下”“东西”的分界
- 正方向：箭头，本题规定向东为正（与温度计"向上"对应）
- 单位长度：每格代表 1 步，同一数轴上每格必须一样大；格画多大可以自己定，但整条数轴要统一
追问两个理解性问题：
- "数轴是一条线段吗？1000 在哪？-1000 在哪？"→ 是直线，两端无限延伸
- "0 算正数吗？"→ 0 既不是正数也不是负数，它是分界点

**17–23 分钟｜人人画一条合格的数轴**
教师在黑板上示范一遍（边画边说四步）：①画一条直线（两端出头）→ ②右端加箭头 → ③取一点标 0 → ④从 0 向右依次标 1、2、3，向左用红笔标 -1、-2、-3，每格用直尺量着画。
学生各自在任务单画一条，同桌互查 4 条标准：①是直线 ②有箭头 ③有 0 ④每格一样大。不合格当场改。
教师快速巡视，数出“四条全过”的人数，记下来供课后反思用。
（设计意图：第 1 个目标当场收口，互查标准就是评分标准，45 人的班用同桌互查才能人人过一遍。）

**23–33 分钟｜用数轴表示有理数**
第 1 组例题（师生同做，黑板上共用一条大数轴）：标出 2、-3、1.5、-2.5。
- 2、-3 快速过；重点停在 1.5 和 -2.5：
  - 追问"1.5 放哪？"→ 1 和 2 正中间
  - 追问"-2.5 放哪？"→ 先到 -2，再往左走半格。身体经验锚定：向正方向走 2 步半是 2.5，向反方向走 2 步半就是 -2.5
  - 明确：数轴上不只能放整数，分数、小数都有位置
第 2 组（学生做，任务单）：在你刚画的数轴上标出 -4、0、3、-1.5。同桌交换检查，重点看 -1.5 是否落在 -1 和 -2 之间。
第 3 组（反向）：黑板上已标好点 A（在 -2 处）、B（在 1 处）、C（在 -0.5 处），请学生读出表示的数。
（设计意图：正反两个方向各做一遍——“给数找点”和“看点说数”——对应才算双向建立；分数故意安排在第一组例题里，让学生第一次画时就遇到，不留到课后。）

**33–39 分钟｜辨析：抓假数轴**
黑板出示 3 幅图（教师提前画好），学生逐幅判断并说理由：
1. 画了箭头和 0，但左边每格明显比右边大 → 单位长度不统一，不能比较大小
2. 有 0 有刻度，没有箭头 → 没有正方向，说不清 -3 在哪边
3. 一条从 0 出发只向右的射线，标了 1、2、3 → 负数没地方放，数轴必须两边都有
组织方式：先同桌 30 秒讨论，再随机点名 3 人各说一幅（用班级随机点名或按列轮流，保证不是固定几个活跃学生）。
（设计意图：辨析题让第 3 个目标落地，也暴露刚才互查里没抓出来的漏洞；让学生说理由而不是老师宣布对错。）

**39–43 分钟｜Exit Ticket（每人一张小纸条，3 题，限时 3 分钟）**
1. 数轴的三要素是＿＿＿＿、＿＿＿＿、＿＿＿＿。
2. 在给出的数轴上（纸条已印好一条合格数轴）标出 -1.5 和 3。
3. 判断对错：小明画的“数轴”有 0、有均匀刻度、右边有箭头，但只画到 5 就停了。对不对？为什么？
做完按列往后传，教师课间快速批：全对为通过；第 2 题错的人名单记下，下节课开头 5 分钟针对性处理；第 3 题集中错则下节课重讲“直线”。
（设计意图：3 题分别测三要素记忆、含分数的定位、对“直线”的理解，错误类型直接决定下节课起点，这是本课最重要的形成性证据。）

**43–45 分钟｜小结与反思**
两个问题收尾，学生口头回答：
- “今天画数轴，最先定的三样东西是什么？少一样会发生什么？”（对应引入时的缺失体验）
- “数轴上的点和我们学的数是什么关系？”（预期回答方向：每个数都能在线上找到自己的位置；不必展开“一一对应”术语）
布置预习：想一想，+3 和 -3 这两个点，到 0 的距离有什么关系？（为下一节相反数埋伏笔）

## 六、常见误解与教师应对

| 误解 | 应对 |
|---|---|
| 数轴画成线段或射线 | 用"1000 在哪”追问，逼出"两端无限延伸" |
| 忘画箭头或没标 0 | 回到画线体验：缺方向/起点时同桌为什么看不懂 |
| 单位长度不统一 | 用 B 类作品对比：格子不齐，2 步和 3 步比不出长短 |
| 认为 0 是正数 | 提问澄清，回扣 2.1 已学的"0 既不是正数也不是负数" |
| -2.5 标到 -2 再往左整整一格 | 用"向反方向走 2 步半"的身体经验重演；让做对的学生演示半格怎么占 |
| 认为数轴只能表示整数 | 已由例题 1.5、-2.5 直接打破，课后练习再各出现一次 |

## 七、技术/材料/时间 Plan B

- 无投影/多媒体：全程黑板画大数轴（配直尺），学生作品用磁贴上墙对比，不影响任何环节。
- 任务单没打印：画线体验、标数题全改在练习本；Exit Ticket 改为口头 3 问 + 手势作答（手指 1 根/2 根/3 根表示选择题选项），教师目测统计举手比例。
- 前面讨论超时：辨析题砍到 2 幅（保留单位长度不统一、无箭头两幅），Exit Ticket 三题必保；第 3 组反向读数移作课后作业。
- 有学生直尺忘带：同桌共用，或用课本边棱代替。

## 八、教学反思提示（上完课后 5 分钟填）

1. 互查环节“四条全过”的人数是多少？没过的集中在哪一条？
2. Exit Ticket 第 2 题的错误集中在整数定位还是分数定位？决定下节课前 5 分钟补什么。
3. “数与点对应”这句话是学生自己说出来的，还是我替他们总结的？下节课设计一个必须用数轴说理的问题来检验。
