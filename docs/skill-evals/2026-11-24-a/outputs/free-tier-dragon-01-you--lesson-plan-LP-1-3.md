# 2.2 数轴（第 1 课时）教案

## 基本信息
- **学科：** 数学
- **年级：** 初一（7年级）
- **课时：** 45分钟（第二章 2.2 数轴，第 1 课时）
- **班级人数：** 45人
- **教材：** 北师大版七年级上册第二章《有理数及其运算》
- **教学方法：** 渐进式释放（I Do → We Do → You Do）
- **课程标准：** 《义务教育数学课程标准（2022年版）》第三学段“数与代数”：能用数轴上的点表示有理数，能比较有理数的大小

## 教学目标
学生能够：
1. **说出** 数轴的三要素：原点、正方向、单位长度（记忆）
2. **画出** 一条要素齐全、标数规范的数轴（应用）
3. **用数轴上的点表示** 给定的有理数（含整数、分数、小数），并**读出** 数轴上已知点所表示的数（应用）
4. **判断** 所给图形是否为数轴，并**说明** 理由（分析）

## 学习周期

### 周期1：导入——从温度计到数轴（5分钟）

**讲解（I Do）：**
出示温度计（实物或图片），提问：温度计上哪个数表示零上、哪个表示零下？它是怎么做到的？
观察要点板书出来：有一个 0 的位置；零上刻度朝一个方向；每个刻度之间的间隔相等。
提出任务：如果把温度计“横过来放平”，这三样东西搬到一条直线上，就得到数学里的一个新工具——数轴。

**检查理解（We Do）：**
- 问题1：温度计上的 0℃ 表示没有温度吗？（预期：不是，0℃ 是一个确定的温度，是零上零下的分界）
- 问题2：-3℃ 在 0℃ 的哪一边？（预期：零下方向那一侧）

**练习：**
同桌互相说出温度计上“三样必需品”各是什么。

**反馈：**
教师用一句话收口：一个分界点（0）、一个方向、相等的间隔——这就是画数轴要准备的三样东西。

### 周期2：新授——数轴的定义、画法与表示（20分钟）

**环节1：数轴的定义与三要素（5分钟）**

**讲解（I Do）：**
定义：**规定了原点、正方向、单位长度的直线叫做数轴。**
- **原点：** 数轴上表示 0 的点
- **正方向：** 通常规定原点向右为正，用箭头标出
- **单位长度：** 从原点开始，选取适当长度作为一个单位，同一条数轴上单位长度必须统一

**检查理解（We Do）：**
- 问题1：数轴三要素是哪三个？（预期：原点、正方向、单位长度）
- 问题2：一条画了箭头的直线是不是一定是数轴？（预期：不一定，还要看有没有原点和统一的单位长度）

**环节2：画数轴“四步法”（8分钟）**

**教师示范（I Do）：**（黑板边讲边画）
1. **画：** 用直尺画一条水平直线，两端向外延伸、不截止
2. **定：** 在直线上取一点作原点，下方标"0"
3. **向：** 在右端画箭头，表示正方向；右侧将标正数，左侧标负数
4. **量：** 取适当长度为单位长度，向右依次标 1、2、3，向左依次标 -1、-2、-3

**练习（You Do）：**
全班在练习本上按四步画一条数轴，标出 -3 到 3。教师巡视，挑两份投影展示，一份合格、一份有典型问题（如缺箭头或单位长度不匀），全班一起指出。

**反馈：**
对照四步法逐条核对；强调最常丢的两样：箭头、单位长度不均匀。

**环节3：用数轴上的点表示有理数（7分钟）**

**讲解（I Do）：**（接着黑板上的数轴示范）
- 0 就是原点
- 正数从原点向右数：+3 是从 0 向右数 3 个单位
- 负数从原点向左数：-2 是从 0 向左数 2 个单位
- 分数、小数取相应位置：+1.5 在表示 1 和 2 的两点正中间；-0.5 在 -1 和 0 正中间

**检查理解（We Do）：**
- 问题1：表示 -4 的点在原点哪一侧、距原点几个单位长度？（预期：左侧，4 个单位）
- 问题2：数轴上标着 A 的点位于 -2 和 -3 正中间，A 表示什么数？（预期：-2.5）
- 问题3：任何一个有理数，能不能都在数轴上找到一个点和它对应？（预期：能）

**反馈：**
随机点名回答，答错时回到“先看符号定左右、再看数值定距离”两步纠正。

### 周期3：练习与应用（15分钟）

**独立练习（8分钟，You Do）：**
完成练习纸 5 题：
1. 判断题：下面三条图形是不是数轴？（图 A 缺箭头；图 B 有箭头无原点；图 C 单位长度忽大忽小）——都不是，逐条说理由
2. 在自己画的数轴上标出：2、-3、0、+1.5、-2.5
3. 读数题：数轴上 A、B、C、D 四点（教师黑板上给定位置），说出各点表示的数
4. 画一条数轴，并用点表示 -1、0、3
5. 选做：表示 +4 的点在表示 -2 的点的哪一侧？相距几个单位长度？（预期：右侧，6 个单位）

**同伴互查（4分钟）：**
同桌交换，对照四步法和“左右看符号、距离看数值”逐题核对，用铅笔在错处做记号。

**全班讲评（3分钟，We Do）：**
教师公布答案，重点讲第 1 题的说理格式（指出缺了哪个要素）和第 5 题的数法（从 -2 到 +4 跨过原点：2 格 + 4 格）。

**反馈：**
错得集中的题当场在黑板上重画一遍；个别问题巡视时已面批。

### 总结（5分钟）

**学生总结（You Do）：**
用 1 分钟写下今天学到的 3 个要点。

**教师补充：**
1. 数轴三要素：原点、正方向、单位长度，缺一不可
2. 画数轴四步：画直线、定原点、标正方向、量单位长度
3. 任何有理数都能用数轴上的一个点表示；先看符号定左右，再看数值定距离

**课后作业：**
课本 2.2 节第 1 课时对应练习题；用今天的四步法给家人画一条数轴并标出 -5 到 5。

## 前置知识
- 正数、负数、0 的意义及表示（北师大版七上 2.1 有理数）
- 有理数的分类（整数、分数）
- 用直尺画直线、等分线段的基本操作

## 关键学习点
1. 数轴的定义：规定了原点、正方向、单位长度的直线
2. 三要素缺一不可，画图四步缺一步就会出错
3. 任何有理数都可以用数轴上的一个点表示；符号决定方向，数值决定距离

## 常见误解
1. **误解：** 一条带箭头的直线就是数轴
   **正确理解：** 必须同时具备原点、正方向、单位长度，缺一不可
2. **误解：** 数轴两端可以画上端点（画成线段或射线）
   **正确理解：** 数轴是向两端无限延伸的直线，画图时两端应留出延伸的余地
3. **误解：** 单位长度只能一格表示 1，一格稍长稍短没关系
   **正确理解：** 单位长度可以按需要选定（一格表示 1、0.5、10 都可以），但同一条数轴上必须完全统一

## 关键词
1. **数轴：** 规定了原点、正方向、单位长度的直线
2. **原点：** 数轴上表示 0 的点
3. **正方向：** 规定的表示正数的方向，通常取原点向右，用箭头标出
4. **单位长度：** 从原点起选取的、代表 1 的线段长度，同一条数轴上必须统一

## 课前测验（诊断性评估）
1. 什么是正数？什么是负数？0 属于哪一类？（预期答案：大于 0 的是正数，小于 0 的是负数；0 既不是正数也不是负数）
2. 说出两个正分数、两个负分数的例子
3. 用直尺画一条直线时要注意什么？（预期：两端延伸、尺子不移动）
4. 温度计上，比 0℃ 低 3 格是多少？（预期：-3℃）

## 课后测验（总结性评估）
1. 数轴的三要素是什么？（答案：原点、正方向、单位长度）
2. 判断：有箭头、有刻度但没有标 0 的直线是数轴吗？为什么？（答案：不是，缺原点）
3. 画一条数轴，并用点表示 -4、-1.5、0、2、+3.5（答案：负数在原点左侧按距离取点，分数小数取相应位置）
4. 数轴上表示 -2 的点在原点的哪一侧？表示 +3 的点呢？两点相距几个单位长度？（答案：左侧；右侧；5 个单位）
5. 数轴上的每一个有理数都有点和它对应吗？请举一个例子说明。（答案：有；如 -2.5 用 -2 与 -3 正中间的点表示）

## 差异化教学

### ELL（英语学习者）
**策略：**
- 提供中英双语术语卡：number line/数轴，origin/原点，positive direction/正方向，unit length/单位长度
- 画数轴四步法配简笔示意图，图文对照
- 允许先用母语说思路，再用数学用语复述结论

**材料：** 双语术语卡、四步法图文卡、简化版练习纸（每题只保留一个任务）

### 特殊需求（SPED）
**策略：**
- 提供画数轴步骤卡，一步一勾选
- 提供"描红版"练习纸：直线、箭头已印好，学生只需标 0、标数
- 独立练习只做第 1、2、4 题，延长作图时间
- 读数题允许口头回答代替书写

**材料：** 步骤卡、描红版练习纸、可擦写白板小尺

### 资优扩展（Gifted）
**策略：**
- 探究题：一格表示 10 的数轴上，如何标出 -25 和 +35？一格表示 0.5 呢？
- 辨析题：只规定原点和正方向、不选单位长度的直线，能不能表示数？为什么？
- 提前任务：找出数轴上到表示 +2 的点距离等于 3 个单位的点，有几个？分别表示什么数？（预期：2 个，+5 和 -1）

**材料：** 探究任务单、备用方格纸

## 附加说明
- 45 人按 9 组、每组 5 人预分好同伴互查对子，课前写在黑板角上，练习环节直接配对不耗时
- 板书设计：主板书左侧写定义与三要素，中间画标准数轴示范图；副板书写四步法口诀与例题；判断题三条图形画在右侧留批注位
- 画图规范全程示范：直线先于一切、箭头最后画在右端、标数写在直线下方
- 时间不够时优先压缩同伴互查，保留独立练习与讲评

## 评分标准（Rubric）

| 维度 | 优秀(4分) | 良好(3分) | 需改进(2分) | 不合格(1分) |
|------|----------|----------|------------|------------|
| **三要素识别** | 准确说出三要素并说明缺一不可 | 能说出三要素 | 说出两要素 | 说不全要素 |
| **数轴画法** | 四步齐全，要素规范、单位长度均匀 | 要素齐全，标数基本规范 | 缺一个要素或标数有误 | 缺两个及以上要素 |
| **数与点对应** | 整数、分数、小数全部标对、读对 | 有 1 处错 | 有 2-3 处错 | 大部分对应错误 |
| **判断与说理** | 判断正确并能指出所缺要素 | 判断正确，说理不完整 | 判断有误 | 无法判断 |

说明：假设班级已学完北师大版七上 2.1 有理数；第 1 课时只覆盖数轴概念、画法与用点表示有理数，相反数、绝对值及数轴上比大小留待后续课时；教室具备黑板与投影条件；同伴活动按 9 组×5 人组织。
