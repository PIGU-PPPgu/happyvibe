# 2.2 数轴（第1课时）教案

## 一、基本信息

- 教材：北师大版七年级上册 第二章 有理数及其运算
- 课题：2.2 数轴（第1课时）
- 课时：45分钟
- 班级人数：45人
- 课型：新授课

## 二、教学目标

1. 经历从温度计等实际情境中抽象出数轴的过程，能说出数轴的概念和三要素（原点、正方向、单位长度），能按步骤正确画出数轴。
2. 能用数轴上的点表示给定的有理数，能读出数轴上已知点表示的有理数，初步体会数与点的对应关系。
3. 在画图、互查、纠错的活动中，养成规范作图的习惯，感受数学与生活的联系。

## 三、教学重难点

- 重点：数轴的三要素；数轴的画法；用数轴上的点表示有理数。
- 难点：理解每个有理数在数轴上都有唯一确定的点与之对应；画数轴时全轴单位长度保持一致。

## 四、学情分析

学生在 2.1 节已认识正负数，能把有理数按符号和整数、分数分类；生活中见过温度计、刻度尺等带刻度的实物，具备从实物抽象出数学图形的直观经验。从“看得见的温度计”过渡到“画在纸上的数轴”，再过渡到“数与点的一一对应”，抽象程度逐级提高，是本课要跨越的台阶。

## 五、教学准备

- 教师：直尺、彩色粉笔、温度计图片或实物、课件（含判断题图示）。
- 学生：直尺、三角板、铅笔、练习本。
- 分组：同桌两人互查，前后每 5～6 人为一个小组，共约 8 组，用于练习环节的代表展示。

## 六、教学过程（共45分钟）

### 环节1 情境导入（5分钟）

1. 教师出示温度计图片，提问：怎样在温度计上找到 5℃、0℃、-3℃？
2. 学生观察并回答：先找到 0℃ 刻度线，0 以上往上升，0 以下往下降，每一格大小相同。
3. 教师追问：如果把这个“竖着的温度计”放平，用一个图形表示所有的数，应该具备什么条件？

设计意图：借助学生熟悉的实物，把“零基准点、方向、相同间隔”三个特征显性化，为数轴三要素的抽象做准备。

### 环节2 新知探究（12分钟）

1. 类比抽象（4分钟）：教师引导，把温度计放平成一条水平直线，得到数轴的三个条件，板书数轴的定义——规定了原点、正方向和单位长度的直线叫做数轴。
2. 归纳三要素（4分钟）：
   - 原点：直线上表示 0 的点；
   - 正方向：习惯上取向右为正（用箭头标出）；
   - 单位长度：全轴统一，从原点向右依次是 1、2、3……，向左依次是 -1、-2、-3……。
   提问检验：去掉其中一个要素还叫数轴吗？让学生各举一例说明“缺了会怎样”。
3. 教师示范画数轴（4分钟），板书四步：一画直线，二取原点，三标正方向，四定单位长度。边画边强调：直线两端要出头、箭头只画一个、每格长度用直尺量一致、正负数对称标注。

设计意图：由实物到图形完成第一次抽象；用“缺要素会怎样”的反例让学生主动建构三要素的必要性；教师规范示范对齐难点中的作图规范。

### 环节3 例题精讲（10分钟）

例1 画一条数轴，并在数轴上表示出 -4、-1.5、0、2、3。

师生共同完成：先按四步画轴，再逐个找点。重点讲两点：0 本身就是原点；-1.5 在 -1 和 -2 正中间，分数、小数同样有对应的点。

例2 指出数轴上 A、B、C、D 四点表示的数（教师事先在黑板上画好带四个点的数轴）。

请 4 名学生依次口答并说理由，教师追问：点 A 在原点左侧 2 个单位，为什么读作 -2 而不是 2？

设计意图：例1 由数找点、例2 由点读数，双向训练对应关系；追问直指“符号由方向决定”这一易错点。

### 环节4 分层练习（10分钟）

全体完成练习A（判断，3分钟）：
1. 数轴上原点表示的数是 0。（对）
2. 画数轴时正方向必须向右。（错，正方向可以规定，通常习惯向右）
3. 一条数轴上单位长度可以前密后疏。（错，全轴必须统一）
4. 每一个有理数都能在数轴上找到对应的点。（对）

全体完成练习B（作图，4分钟）：画数轴并表示 -2、0.5、3。同桌交换检查，检查清单：有没有原点、有没有正方向、每格是否一样长、点的位置是否准确。

先完成的学生做练习C（提升，3分钟）：在数轴上，到表示 2 的点距离为 3 个单位长度的点，表示什么数？（答案：5 或 -1）小组内核对后，由一组代表上台讲解。

设计意图：判断题集中暴露缺要素、单位不均等典型错误；互查清单把作图规范变成可操作的动作；练习C 为学有余力的学生留出空间，并渗透“数轴上一点到一个点的距离”的后续学习经验。

### 环节5 课堂小结（5分钟）

师生共同回答三个问题收束本课：
1. 数轴的三要素是什么？
2. 画数轴分哪四步？
3. 数与点是什么关系？（每个有理数对应数轴上一个确定的点；方向决定正负，距离决定大小）

设计意图：以问题链代替复述，把零散知识串成“要素—画法—对应”的结构。

### 环节6 作业布置（3分钟）

1. 必做：教材习题 2.2 第 1、2 题。
2. 选做：找一个生活中像数轴的实物（如温度计、楼层指示、刻度尺），写出它的“原点、正方向、单位长度”分别是什么，下节课交流。
3. 预习提示：观察数轴上表示 2 和 -2 的两个点，它们到原点的距离有什么关系？带着这个观察进入下一课时。

## 七、板书设计

```
2.2 数轴
一、定义：规定了原点、正方向、单位长度的直线
二、三要素：原点（表示0的点）｜正方向（箭头）｜单位长度（统一）
三、画法四步：画直线 → 取原点 → 标正方向 → 定单位长度
        ←———————o—————————→
  -4  -3  -2  -1  0  1  2  3  4
四、数与点：方向定正负，距离定大小
```

## 八、教学反思（课后填写）

记录学生练习中的典型错误（缺要素、单位不均、负数方向找反）及练习C的完成情况，作为第2课时（相反数）起点。

说明：本课时只覆盖数轴的概念、画法与用点表示有理数，教材 2.2 节中的相反数内容安排到第 2 课时；默认学生已完成 2.1 有理数的学习；默认教室具备黑板、直尺与多媒体条件；作业题号按北师大版现行教材编写，如所用版次不同，请以对应习题为准。
