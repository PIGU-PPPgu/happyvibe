# 2.2 数轴（第1课时）教学设计

教材：北师大版数学七年级上册 第二章 2.2 数轴
课型：新授课　课时：第1课时（45分钟）　班级：45人，分8组（每组5—6人）

---

## 第一部分　教案（教师用）

### 一、本节课一览

课程弧线：温度计引入（5′）→ 三要素建构与错例辨析（10′）→ 例题：用点表示数（10′）→ 分层练习（12′）→ 课堂小结（3′）→ 目标检测（4′）→ 作业布置（1′）

教法：情境探究 + 错例辨析 + 小组合作。
材料：直尺与铅笔（每生）、课堂练习单（每生一份，见第二部分）、温度计图片（课件或板画）、磁贴数卡（可选教具）。

### 二、课标依据与学习目标

课标原文（本设计唯一引用处，其余位置只写条目大意）：《义务教育数学课程标准（2022年版）》第四学段"数与式"内容要求——"能用数轴上的点表示有理数，理解相反数和绝对值的意义"。本课时落实前半句；相反数、绝对值由后续课时借助数轴落实。

大观念：数轴用"原点、正方向、单位长度"三个约定，把每一个有理数放到直线上的确定位置，让数看得见、比得了，是数形结合的第一块地基。

学习目标（SWBAT）：
1. 说出数轴的三要素，按四步画出合格的数轴；
2. 在同一条数轴上正确标出给定的有理数（含负小数），并读出已知点表示的数；
3. 能判断"缺要素的图不是数轴"，并用自己的话说出每个有理数对应数轴上唯一的点。

已有基础：2.1 节有理数的意义与分类；小学刻度尺、数线经验；温度计正负刻度的生活经验。

### 三、重点难点

重点：数轴的三要素与画法；用数轴上的点表示有理数。
难点：负数（尤其负小数）的定位；理解三要素缺一不可。

### 四、核心词与易错点

核心词：数轴、原点、正方向、单位长度；"数形结合"作为思想方法渗透即可。

易错点：

| # | 学生怎么做 | 为什么 | 教师对策 |
|---|---|---|---|
| 1 | 画数轴漏要素，最常见是忘标原点或忘画箭头 | 把数轴当成"标了数的直线"，没有理解它由三个约定共同定义 | 用错例辨析让残缺图"不能用"，追问"没有原点，-2 该画在哪？"让"缺一不可"由学生自己说出 |
| 2 | 标负数时把 0 所在位置也数进去，-2 落在 -1 的位置，或 -2、-3 左右颠倒 | 正向数数习惯（第 1 格是 1）向负方向迁移时没有先确定"第一格是 -1" | 统一口令"负数从 0 向左，第一格先标 -1"；巡视时先看每个学生的第一个负刻度 |
| 3 | 表示 -1.5 时犹豫、标在整数格上或方向出错 | 以为数轴只能表示整数，对"每段刻度可以再等分"不熟 | 回到温度计 -1.5℃：先找到 -1，再向 0 方向取半格；板演"先整数后等分"两步法 |

### 五、教学过程

#### 环节一　情境导入：温度计能变直线吗（5分钟）

师生活动：
1. 出示温度计图片，提问："零下 3℃ 在温度计哪里？谁能用一条直线把温度计上的数都搬过去？"
2. 学生独立在练习单"探究一"画一条自认为能表示 -3 的线（2分钟），同桌互看。
3. 收集两三份典型画法（有对的、有缺要素的）投影或板贴，不作对错定论，留到下一环节。

设计意图：从生活原型进入，先暴露原始想法，数轴的三个约定由"需要"产生，而不是教师直接宣布。

巡视观察要点：
- 有学生把 -3 写在 0 右边——负方向意识未建立，导入后个别提示；
- 有学生画了均匀刻度但没有 0 的位置感——追问"你的 0 在哪，为什么"；
- 全班是否都能动笔画——记录参与面。

#### 环节二　建构定义：三要素与画法（10分钟）

师生活动：
1. 对照学生作品，师生共同归纳：规定了原点、正方向和单位长度的直线叫数轴。
2. 板书三要素，逐条追问作用：原点定"数的家在哪"，正方向定"哪边是正"，单位长度定"一格代表多少"。
3. 错例辨析（练习单印有文字描述，教师同步板画三幅图）：
   - 甲图：直线上依次写着 -2、-1、0、1、2，无箭头，0 未特别标出；
   - 乙图：有原点有箭头，但 0 到 1 是一格宽，1 到 2 只有半格宽；
   - 丙图：三样都有，但 -1 标在原点右侧、1 标在原点左侧。
   学生逐图判断"是不是数轴、缺了什么"，小组内先说，再全班交流。
4. 归纳画法四步：画直线 → 定原点 → 定正方向（右端画箭头）→ 取单位长度并等距标数（向右 1、2、3…，向左 -1、-2、-3…）。
5. 每人按四步在练习单"探究二"画一条数轴（单位长度 1 格，范围 -4 到 4），同桌按三要素互检。

设计意图：概念由反例收紧边界，"缺一不可"在辨析中由学生说出，比正面讲授记得牢。

巡视观察要点：
- 辨析时能否说出甲缺"原点标记与正方向"、乙缺"单位长度统一"、丙"方向与符号矛盾"；
- 画轴时是否用尺、箭头是否在右端、刻度是否等距；
- 刻度不匀的，提示"先轻轻全部等分，再标数"。

#### 环节三　例题：把数放到数轴上（10分钟）

师生活动：
1. 例题板演：在数轴上表示 0、3、-2、-1.5、2.5。0 就是原点；3、2.5 在原点右侧；-2、-1.5 在原点左侧。重点示范 -1.5：先找到 -1，再向 0 方向取半格，两步法板书。
2. 追问一：表示 -1.5 的点在表示 -1 的点的哪一侧？（靠 0 一侧，学生指认）
3. 追问二：每一个有理数在数轴上有几个点与它对应？反过来，数轴上一个点表示几个数？先让学生用自己的话说，再收口到"一一对应"。
4. 学生在练习单例题区用自己画的数轴完成标注，两名学生板演，其中一名指定画 -1.5。

设计意图：例题覆盖正整数、负整数、正负小数全部定位类型；"一一对应"由追问生成，为第 2 课时比较大小和后续绝对值铺路。

巡视观察要点：
- 负数是否从 0 向左数格、第一个负刻度是不是 -1；
- -1.5 是否落在 -1 与 -2 正中而非整数格上；
- 板演讲解时其他学生是否在对照修改自己的图。

#### 环节四　分层练习（12分钟）

练习单呈现（A、B 必做，C 选做；8 组内互批互查）：
- A1　读点：点 A 在原点左侧 2 个单位长度处，A 表示____；点 B 在原点右侧 3 个单位长度处，B 表示____。
- A2　标点：在数轴上标出 +4、-3、0。
- A3　标点：在数轴上标出 -1.5。
- B1　改错：小华画的数轴有原点、刻度均匀，但箭头画在左端。错在哪？怎么改？
- B2　判断并说一句理由：任何一个有理数都能在数轴上找到表示它的点。
- B3　先标后答：表示 -2 的点与表示 -3 的点，哪个在左边？
- C（选做）：离开原点 3 个单位长度的点有几个？分别表示什么数？把发现写下来。

组织：前 6 分钟独立完成，后 4 分钟组内互批（对照板书答案），最后 2 分钟教师针对 C 题收口（两个点、3 和 -3，点到"下节课继续用数轴说话"即止，不提前上新概念）。

设计意图：A 层保底人人过关，B 层打三要素与一一对应，C 层埋相反数与绝对值的种子；45 人班靠组内互批让反馈落进课堂内。

巡视观察要点：
- A3 出错率高于 A2 时，小结前补一次半格示范；
- B1 只答"箭头错了"的，追问到"正方向应指向右边"的含义；
- C 题写出"3 和 -3"的小组，请其在小结时展示。

#### 环节五　课堂小结（3分钟）

学生先说，教师后补：
1. 两名学生各用一句话说今天学到什么（预期：三要素、四步画法、数与点一一对应）；
2. C 题发现展示：离开原点 3 个单位有两个点，表示 3 和 -3；
3. 教师收口：数轴让数搬到直线上，数形结合从这节课开始；下节课用数轴比大小。

#### 环节六　目标检测（4分钟，练习单末"检测区"，独立完成当堂收）

1. 判断改错：一条直线上，0 处标了原点，刻度均匀，但两端没有箭头。"这是一条数轴。"这话对吗？不对的话缺了什么？
2. 在数轴上标出表示 -2.5 和 +3 的点。
3. 点 M 在原点左侧 2 个单位长度处，M 表示的数是____；点 N 在原点右侧 4 个单位长度处，N 表示的数是____。

回收分栏（教师课后统计，记入第三部分观察表）：
- 已达标：3 题全对；
- 接近：仅第 1 题表述不全，或第 2 题 -2.5 位置差半格；
- 需重讲：第 2、3 题出错或空白，次日课前小灶，对齐三要素口令与两步法。

作业布置（1分钟，口头布置，练习单上有记录行）：
1. 教材 2.2 节随堂练习中第 1 课时的习题；
2. 实践：连续三天记录早上 8 点气温，画一条合适的数轴把三个温度标上去；
3. 想一想（不要求交）：数轴上，右边的点和左边的点表示的数，谁大？

### 七、如果你要改编这节课

这节课依赖三件事，改编时保住它们：
1. **温度计情境**——负数的方向感来自生活原型，换电梯楼层、海拔等情境时，保留"有零点、有方向、有等距刻度"三个特征；
2. **错例辨析**——"缺一不可"由反例界定，改编时保留三个错例各缺一种要素的结构；
3. **双向任务（标数与读数）**——先"数→点"再"点→数"，两个方向都打通，第 2 课时比较大小和后续绝对值才有根。
