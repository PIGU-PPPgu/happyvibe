# 19.1.1 变量与函数（第 1 课时）教案

**教材**：人教版八年级下册 第十九章 一次函数
**课时**：19.1.1 第 1 课时（常量与变量、函数概念）
**时长**：45 分钟

## 一、学情与前置知识

- 已学：用字母表示数、代数式与整式运算、方程；七年级学过平面直角坐标系，能读懂简单图象。
- 生活经验：大量“一个量随另一个量变”的例子（路程随时间、体温随时刻、弹簧长度随挂重）。
- 差异：部分学生会停在“代入算值”的操作层，对“对应关系”这种结构性理解需要活动支撑，不能靠听讲获得。

## 二、教学目标与学习证据

| 目标（可观察行为） | 学习证据 |
|---|---|
| 1. 在给定变化过程中指出常量与变量，并说明理由 | 「变化过程分析表」第三列填写；判断题说理 |
| 2. 说出函数概念的两个要点；判断“y 是不是 x 的函数”，并用“唯一确定”说理 | 判断站答题及理由；Exit Ticket 第 2 题 |
| 3. 在式子、表格、图象三种形式中识别同一对应结构 | 判断站第 ②⑤ 题；Exit Ticket 第 2 题 |

锚定素养：抽象能力（从三个不同背景的变化过程中抽出共同结构）、对应思想。

## 三、重点难点

- 重点：常量、变量与函数概念的形成过程。
- 难点：①理解“唯一确定”的含义；②在表格、图象（无公式）形式中识别函数关系；③明确“谁是谁的函数”的方向性。

## 四、教学准备

- 学案一张（变化过程分析表 + 判断站题目 + Exit Ticket）。
- 可选：弹簧一副、砝码若干（用于演示）；无投影教室全程可黑板完成。

## 五、课堂流程（45 分钟）

### 第 0–4 分钟：情境开场——找“变与不变”

教师演示：向水盆中心滴水（或描述涟漪扩散过程），提问：“这个过程里，什么变了？什么始终没变？”
学生口头回答，教师把学生的词写成两列：变化的量、不变的量。预告：今天给这两类量正式命名，并研究它们之间的关系。

**设计意图**：从看得见的现象入手，让“变与不变”成为学生自己的观察结果，名词是给观察结果贴标签，不是先抄后背。

### 第 4–16 分钟：活动一——变化过程分析表（小组，12 分钟）

三人一组，分析三个变化过程，每例填四栏：

| 栏目 | 例 1 | 例 2 | 例 3 |
|---|---|---|---|
| 背景 | 汽车以 60 km/h 匀速行驶，行驶 t 小时，路程 s 千米 | 弹簧原长 10 cm，每挂 1 kg 重物伸长 0.5 cm，挂 m kg 后长 L cm | 半径为 r 的圆，面积 S |
| 谁不变 | | | |
| 谁在变 | | | |
| 一个变量取定一个值，另一个变量能确定几个值 | | | |
| 能否用一个式子表示两者关系 | | | |

巡视重点：第三栏“能确定几个值”是否所有组都写出“1 个”——这是后续抽象的原料。
小组代表汇报后，教师把三个式子并排板书：s = 60t、L = 10 + 0.5m、S = πr²。

**设计意图**：三个情境背景不同、结构相同。填表迫使学生对每个过程完整执行“找常量→找变量→查对应”，为下一环节的抽象积累三个样本，而不是只看一个例子就下结论。

### 第 16–24 分钟：活动二——找共同点，提炼函数概念（8 分钟）

1. 每人独立写一句话：“这三个例子共同的地方是____”（2 分钟）。
2. 小组交流，合并成组里最满意的一句（2 分钟）。
3. 全班交流。教师顺着学生的表述补齐两个要点（4 分钟）：
   - 每个过程中有**两个变量**；
   - 一个变量每取一个**确定的值**，另一个变量都有**唯一确定的值**与它对应。
4. 给出规范定义与术语：前面的量叫自变量，后面对应的量是它的函数。板书三个方向：s 是 t 的函数，L 是 m 的函数，S 是 r 的函数——顺序不能反。

**设计意图**：定义由学生先说、教师后规范。“唯一确定”这个难点从学生自己的话里长出来，教师只做命名和补齐，而不是直接给出让他们背。

### 第 24–32 分钟：活动三——函数判断站（8 分钟）

学生独立判断并写理由，同桌互查后讲评：

1. y = 2x + 1（x > 0），y 是 x 的函数吗？
2. 某天气温记录表：8 时 12 ℃，12 时 25 ℃，16 时 23 ℃，20 时 15 ℃。气温 T 是时刻 t 的函数吗？
3. y² = x，y 是 x 的函数吗？
4. 跳远测试中每位同学有一个成绩。成绩是姓名的函数吗？姓名是成绩的函数吗？
5. 心电图记录了心脏电流 Y 随时间 t 的变化曲线。Y 是 t 的函数吗？

讲评重点：第 3 题让全班数“x = 4 时 y 有几个值”（±2，不唯一，不是）；第 4 题前半句是、后半句不是（两人同分时一个成绩对应两个姓名），板书标注方向；第 2、5 题确认没有式子、只有表格或图象，同样可以是函数。

**设计意图**：反例和方向反转迫使学生使用刚建立的“唯一对应”标准，同时暴露两个高频误解——“有两个变量就是函数”“函数必须有公式”。

### 第 32–40 分钟：分层巩固（8 分钟）

- 基础（必做）：电影院每张票 10 元，写出票房收入 y（元）与售票张数 x 的关系式，指出常量与变量，说明谁是谁的函数。
- 追问（讲评时全班讨论）：例 1 中 60 是常量；如果这辆车明天以 80 km/h 行驶，60 还是不变的吗？
- 挑战（学有余力先想）：y = 5 中，y 是 x 的函数吗？

**设计意图**：基础题检验定义的直接使用。追问点明常量与变量是相对具体变化过程而言的。挑战题触及“唯一对应”的边界——对应值不变化也是唯一对应，留给下一课时回味。

### 第 40–45 分钟：Exit Ticket 与小结（5 分钟）

Exit Ticket（独立完成，下课交）：

1. 某文具店每本笔记本 5 元。写出总价 w（元）与购买本数 n 的关系式；指出常量与变量；w 是 n 的函数吗？
2. 下面是某同学一天中几个时刻的体温记录：7 时 36.5 ℃，12 时 37.2 ℃，18 时 36.8 ℃。体温 T 是时刻 t 的函数吗？用一句理由说明。

教师用 30 秒回扣板书主线：变化过程 → 常量与变量 → 唯一确定对应 → 函数。

**时间合计**：4 + 12 + 8 + 8 + 8 + 5 = 45 分钟。

## 六、教师关键提问

- “这个过程里，什么变了？什么始终没变？”
- “t 取一个值，s 能确定几个值？”
- “三个例子背景完全不同，它们有什么共同的地方？”
- “x 取一个值，y 有两个值跟它对应，还能说 y 是 x 的函数吗？”
- “只有表格、没有式子，算不算函数？你的判断标准是什么？”

## 七、学生活动与任务单（学生用语）

**活动一 变化过程分析表**（三人一组，12 分钟）

把例 1、例 2、例 3 各分析一遍。每一例都要填：谁不变、谁在变、一个量取定后另一个量能确定几个值、能不能写出关系式。写“能确定几个值”这一栏时，举例说明你是怎么检查的。

**活动二 写共同点**（先自己写，再小组合并）

“这三个例子共同的地方是____________。”比一比哪组的话最接近数学书上的定义。

**活动三 函数判断站**（每题都要写理由，“是”或“不是”不给分，理由给分）

**Exit Ticket**（下课交）

## 八、常见误解与教师应对

| 误解 | 来源 | 应对 |
|---|---|---|
| 有两个变量就是函数 | 只注意到“变化”，没检查对应 | 回判断站第 3 题：x = 4 时 y = ±2，让学生自己数对应值个数 |
| 函数必须有公式 | 三个例子全是式子 | 用气温表、心电图：表格和图象同样给出唯一对应 |
| “谁是谁的函数”方向搞反 | 定义顺序感弱 | 跳远例：请成绩相同的两位同学起立，指出“一个成绩对应两个姓名” |
| 认为常量永远是常量 | 把 60 当成绝对常量 | 追问“明天以 80 km/h 行驶，60 变吗”，点明相对具体变化过程而言 |
| 把 π 当变量 | 见它带字母 | 问“π 会变吗”，判据是同一过程中取值是否固定 |

## 九、Plan B

- 无投影：三例板书表格呈现，滴水演示改为口头描述，流程不变。
- 无弹簧教具：例 2 改为“每本练习本 1.5 元，总价 y 元与本数 x 的关系”，结构与弹簧例相同。
- 时间不足：判断站减为第 1、3、4 题；分层巩固只做基础题，追问改口头一句带过。

## 十、教学反思提示

- 学生写出的“共同点”里有没有“唯一”？没有的话，问题出在分析表第三栏的设计还是讲评方式？
- 判断站哪道题错误最集中？记下来，作为第 2 课时（自变量取值范围、函数值）的起点素材。
- Exit Ticket 第 1 题里，学生的书写是否体现了方向（w 是 n 的函数）？
