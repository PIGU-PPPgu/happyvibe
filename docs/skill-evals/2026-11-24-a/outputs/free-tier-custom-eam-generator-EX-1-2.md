# 教师版答案与解析

**一、选择题**

1. D。解析：函数要求每一个 x 的值都有唯一的 y 值与之对应。D 中当 x > 0 时，y 有两个值（√x 与 −√x）与之对应，不满足唯一性，故 y 不是 x 的函数。

2. B。解析：二次根式有意义需被开方数非负：x − 2 ≥ 0，解得 x ≥ 2。

3. A。解析：正比例函数图象经过第二、四象限时 k < 0，即 m − 1 < 0，得 m < 1。

4. C。解析：k = −2 < 0，b = 3 > 0，图象经过第一、二、四象限，不经过第三象限。

5. A。解析：y 随 x 增大而减小需 k < 0，即 2m − 1 < 0，得 m < 1/2。

6. A。解析：令 y = 0 得 x = −2，图象与 x 轴交于 (−2, 0)；令 x = 0 得 y = 4，与 y 轴交于 (0, 4)。面积 = ½ × 2 × 4 = 4。

7. A。解析：与 y = 3x 平行则 k = 3；把 (1, 2) 代入得 3 + b = 2，b = −1，故 y = 3x − 1。C 虽经过该点但 k = −3，与 y = 3x 不平行，排除。

8. B。解析：t 小时行驶 80t km，距 B 地路程 = 总路程 − 已行驶路程 = 240 − 80t（0 ≤ t ≤ 3）。

**二、填空题**

9. x ≠ 3。解析：分式有意义需分母不为零：x − 3 ≠ 0，即 x ≠ 3。

10. m = 2。解析：正比例函数需 x 的次数为 1 且系数不为零：|m| − 1 = 1 得 m = ±2；又 m + 2 ≠ 0 排除 m = −2，故 m = 2。

11. y = 2x + 3。解析：直线向上平移 n 个单位，常数项加 n，故得 y = 2x + 3。

12. 如 y = x − 1（答案不唯一，需满足 k > 0、b = −1）。解析：图象过 (0, −1) 则 b = −1；y 随 x 增大而增大需 k > 0，任取一个正数作 k 即可。

13. x < 2。解析：由 (0, 2) 得 b = 2；把 (2, 0) 代入得 2k + 2 = 0，k = −1，故 y = −x + 2。y > 0 即 −x + 2 > 0，解得 x < 2。

14. 14。解析：超过 3 km 的部分为 3 km，每千米 2 元共 6 元，车费 = 8 + 6 = 14 元。（当 x > 3 时 y = 2x + 2，代入 x = 6 得 y = 14。）

**三、解答题**

15.（1）m ≠ −1/2；（2）m = 3。
解析：（1）一次函数要求 x 的一次项系数不为零：2m + 1 ≠ 0，得 m ≠ −1/2。
（2）正比例函数要求一次项系数不为零且常数项为零：2m + 1 ≠ 0 且 m − 3 = 0，得 m = 3。
评分参考：第(1)问列出条件 2 分、结论 1 分；第(2)问列出两个条件 2 分、结论 1 分。

16.（1）y = −2x + 3；（2）与 x 轴交点 (3/2, 0)，与 y 轴交点 (0, 3)；点 (2, −1) 在图象上。
解析：（1）设 y = kx + b。由题意得 k + b = 1，−k + b = 5。两式相加得 2b = 6，b = 3；代回得 k = −2。故 y = −2x + 3。
（2）令 y = 0 得 x = 3/2，图象与 x 轴交于 (3/2, 0)；令 x = 0 得 y = 3，与 y 轴交于 (0, 3)。把 x = 2 代入解析式，y = −2 × 2 + 3 = −1，与该点纵坐标相同，故点 (2, −1) 在该函数的图象上。
评分参考：(1) 设解析式 1 分、列方程组 1 分、解对 2 分；(2) 两个交点各 1 分、判断并说理 2 分。

17.（1）表中：x = 0 时 y = −4；x = 2 时 y = 0。过点 (0, −4) 与 (2, 0) 作直线，即为该函数的图象；（2）面积为 4；（3）x > 2。
解析：（2）图象与 x 轴交于 (2, 0)，与 y 轴交于 (0, −4)，与两坐标轴围成直角三角形，两条直角边长分别为 2 和 4，面积 = ½ × 2 × 4 = 4。
（3）由 2x − 4 > 0 得 x > 2；或由图象，x 轴上方的部分对应 x > 2。
评分参考：(1) 列表正确 2 分、画图正确 2 分；(2) 求出两个交点 1 分、面积 2 分；(3) 结论 3 分。

18.（1）A(2, 3)；（2）x > 2；（3）面积为 9。
解析：（1）联立 y = x + 1 与 y = −x + 5：x + 1 = −x + 5，解得 x = 2，代回得 y = 3，故 A(2, 3)。
（2）不等式 x + 1 > −x + 5 对应 l₁ 的图象位于 l₂ 上方的部分，交点横坐标为 2，故解集为 x > 2。
（3）l₁ 与 x 轴交于 (−1, 0)，l₂ 与 x 轴交于 (5, 0)，底边长 5 − (−1) = 6，高为点 A 的纵坐标 3，面积 = ½ × 6 × 3 = 9。
评分参考：(1) 列方程 2 分、求出坐标 2 分；(2) 结论 3 分；(3) 底边 1 分、高 1 分、面积 1 分。

19.（1）y₁ = 1.5x + 1000（x ≥ 0），y₂ = 2.5x（x ≥ 0）；（2）选乙公司；（3）x > 1000。
解析：（2）x = 800 时，y₁ = 1.5 × 800 + 1000 = 2200，y₂ = 2.5 × 800 = 2000。2200 > 2000，选乙公司更省钱。
（3）令 y₁ < y₂：1.5x + 1000 < 2.5x，解得 x > 1000。即月行驶里程超过 1000 km 时选甲公司合算；x = 1000 时两家费用相同，均为 2500 元。
评分参考：(1) 每个关系式各 2 分；(2) 代入求值 2 分、比较并结论 2 分；(3) 列不等式 2 分、解集 2 分。

20.（1）货车：s = 60x（0 ≤ x ≤ 5）；轿车：s = 90x − 90（1 ≤ x ≤ 13/3）；（2）轿车出发 2 小时后追上货车，此时离甲地 180 km；（3）早到 40 分钟（2/3 小时）。
解析：（1）货车全程需 300 ÷ 60 = 5（h），故 0 ≤ x ≤ 5；轿车比货车晚出发 1 h，行驶路程为 90(x − 1)，全程需 300 ÷ 90 = 10/3（h），故 1 ≤ x ≤ 1 + 10/3 = 13/3。
（2）令 60x = 90x − 90，解得 x = 3，此时距甲地 60 × 3 = 180（km）；轿车行驶时间为 3 − 1 = 2（h）。
（3）货车到达时刻 x = 5；轿车到达时刻 x = 1 + 10/3 = 13/3。5 − 13/3 = 2/3（h）= 40 分钟。
评分参考：(1) 两个关系式各 1 分、两个取值范围各 1 分；(2) 列方程 2 分、结论 2 分；(3) 求出两个时刻 2 分、时间差 2 分。
