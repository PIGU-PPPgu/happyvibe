# 数轴（第 1 课时）教案

**教材**：北师大版七年级上册第二章 2.2
**课时**：45 分钟 | **班级**：45 人 | **课型**：新授课

## 一、学情与前置知识

学生已学过正负数的意义（相反意义的量）和有理数的分类，会读温度计。欠缺的是：把“数”和“直线上的点”对应起来的经验——学生脑中的 -3 仍是“零下 3 度”，还没成为“0 左侧的一个位置”。本节课要完成这次抽象：从温度计的竖直刻度线，抽象出水平的、通用的数轴。

## 二、教学目标与学习证据

| 教学目标（可观察行为） | 学习证据 |
|---|---|
| 1. 能说出数轴的三要素（原点、正方向、单位长度），并独立画出规范的数轴 | 课堂画的数轴作品，Exit Ticket 第 1 题 |
| 2. 能在数轴上标出给定有理数对应的点，读出数轴上已知点表示的数 | 标点练习单，Exit Ticket 第 2 题 |
| 3. 能用数轴表示简单情境中的量，说出“哪个数在 0 的哪边、离 0 几个单位” | 情境题的口头解释与短回答 |

锚定课标（2022 版）“有理数”内容要求：能用数轴上的点表示有理数。核心素养锚定 2 项：**抽象能力**（温度计→数轴）、**几何直观**（数与点的对应）。

## 三、重点难点

- **重点**：数轴三要素；用数轴上的点表示有理数。
- **难点**：负数在原点左侧的定位；单位长度必须前后一致（学生常右边一格当 1、左边一格当 2）。

## 四、教学准备

三角板或直尺（每人）、学案（印有无刻度直线与半成品数轴各一条）、红色和蓝色笔（区分 0 右侧与 0 左侧的点）、温度计实物或放大图片一张。全程不依赖多媒体。

## 五、课堂流程（按分钟）

**1. 从温度计读起（0–5 分钟）**

黑板画出温度计简图，报三个数：上海 5℃、北京 -3℃、哈尔滨 -8℃。请三名学生上台在温度计上指出位置，全班核对。

> 设计意图：用学生已会读的实物做起点，让 0 的“分界”作用先在旧经验里出现，而不是从定义开始。

**2. 提出问题、学生预测（5–8 分钟）**

提问：“温度计能横过来放吗？如果把它放平成一条线，5、0、-3 各该画在哪？”学生先在学案的无刻度直线上尝试摆放这三个数，不要求正确，写下自己怎么想的。

> 设计意图：先暴露学生自己的摆法，后面的规范才有对照物；同时避免“教师先讲定义、学生照抄”。

**3. 动手画、暴露问题（8–15 分钟）**

学生用三角板把这条直线画完整，标出 5、0、-3，再尝试标 -8。教师巡视，挑 3–4 份作品拍照或请学生贴到黑板上，**故意选有代表性的问题作品**：缺箭头的、没标原点的、单位长度不统一的。

> 设计意图：错误作品是本课最重要的教学资源——三要素从“挑错”里长出来，比教师宣布定义记得牢。

**4. 对比讨论（15–22 分钟）**

全班围绕黑板作品逐一讨论三个问题：
① “往右数，数越来越大，那必须先固定什么？”（→ 方向，正方向，箭头表示）
② “0 画在哪，左边的数才说得清？”（→ 原点）
③ “这条线上每一格代表 1，左右两边的格能不能不一样长？”（→ 单位长度统一）

教师关键提问：
- “没有箭头，别人怎么知道右边的数比左边大？”
- “不标 0，你还能确定 -3 在哪儿吗？”
- “左边一格画 2 格长、右边一格画 1 格长，读出来会乱成什么样？”
- “-2 的点在 0 的哪边？-3 和 -1 谁离 0 更远？”

> 设计意图：三个问题恰好对应三要素，让学生用“不这样会乱”的理由自己得出结论，教师只负责收口命名。

**5. 正式定义与规范示范（22–28 分钟）**

板书数轴定义与三要素，教师在黑板规范示范画一条数轴（原点标 0、右端箭头、单位长度一致并标数）。强调两点：原点是“基准”，正方向是“约定”，单位长度可按需选定但画好后不再变。

学生对照示范，把自己刚才画的数轴修正一遍（用红笔在 0 右侧标数、蓝笔在 0 左侧标数）。

> 设计意图：学生先尝试、再对照规范修正，修正动作本身是一次自我检查；红蓝分色帮助学生把“0 右为正、0 左为负”视觉化。

**6. 练习与迁移（28–38 分钟）**

分层任务（同一核心：在数轴上表示数），学生自选起点，可逐层做：

| 层 | 任务 |
|---|---|
| 基础 | 用学案上的半成品数轴（已画好原点、箭头、刻度），补全标数：2、-1、3.5、-2.5，配步骤提示卡（第一步找 0 → 第二步数方向 → 第三步数格子） |
| 提升 | 从零开始画一条数轴，标出 4、-2、0.5、-3.5，并读出同桌所标两个点表示的数 |
| 挑战 | 小明从家出发，向东走 3 米记 +3 米，向西走 2 米记 -2 米。画数轴表示家、东 3 米处、西 2 米处，并向同桌解释 -2 的点为什么在 0 的左边 |

教师巡视记录：谁在标 -2.5 时数错方向、谁单位长度画歪。挑两名学生口头解释“-3.5 是怎么找到的”。

> 设计意图：三层同轴心，只是支架递减、情境递增；名称不用“差生/优生”类标签，起点自选减少心理分层。

**7. 形成性检测：Exit Ticket（38–43 分钟）**

每人一张小条，3 分钟内完成：
1. 画一条数轴（三要素齐全），在上面标出 2、-1、-2.5。
2. 看黑板上已画的数轴，读出点 A（在 0 左侧第 4 格）、点 B（在 0 右侧第 2 格）表示的数。
3. 判断并说理由：小华画的“数轴”没有标 0，只有箭头和几个数，它是不是数轴？为什么？

下课时收齐，逐条快判，明天课前 3 分钟针对第 3 题集中反馈。

> 设计意图：第 1 题对应目标 1、2，第 2 题对应目标 2，第 3 题直接检测“是否真懂原点的必要性”，而不是抄定义。

**8. 小结（43–45 分钟）**

两个问题收尾，学生口头回答：
- “一条数轴上必须有三样东西，缺一样会怎样？”
- “明天如果把 -4 和 4 都画上去，它们在 0 的两边各离 0 几格？先猜一猜。”（为下节课相反数埋一个观察点）

## 六、常见误解与教师应对

| 误解 | 应对 |
|---|---|
| 画数轴漏箭头或漏标 0 | 不直接判错，问“别人照你这条线找 -3，找得到吗”，让学生自己发现缺什么 |
| 0 左侧单位长度与右侧不一致 | 请该生按自己的线读出 -3 的位置，读数自相矛盾时自然暴露 |
| 认为负数“越小越靠右” | 用温度计回问：“-8℃ 比 -3℃ 冷还是暖？冷的在 0 的哪边？” |
| 读数不从原点起数，从最近的已知数乱数 | 板书示范时固定动作：先回到 0，再数方向、数格子 |
| 认为数轴上只能标整数 | 教师点一句：“3.5 也能找到位置——0 和 1 之间的格子还能再分”，不展开，留给后续课时 |

## 七、Plan B

- **温度计实物没带/找不到**：黑板手绘温度计简图，报数让学生上台指位，效果不受影响。
- **学案没印够或忘带**：学生在练习本上自画两条直线替代；半成品数轴改为同桌互画给对方“找茬”。
- **时间超支**（讨论超过 28 分钟）：练习压缩为基础层 1 组数 + 挑战层口头交流，Exit Ticket 减为第 1、3 题，第 2 题并入明日课前反馈。
- **投影设备故障**：本课全程以黑板和学案为载体，无备用需求。

## 八、教学反思提示

1. 全班画数轴时，三要素里缺得最多的是哪一样？把它记为下节课课前反馈的重点。
2. 基础层学生是否真正独立完成了标点，还是主要靠步骤提示卡走完全程？提示卡何时可以撤掉？
3. 第 3 题判断题的通过率：如果低于七成，说明“原点的必要性”还没立住，下节课需要回到温度计再走一遍“没有 0 会怎样”。
