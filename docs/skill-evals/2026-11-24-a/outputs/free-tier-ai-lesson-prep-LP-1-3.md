# 《数轴》教案（第1课时）

## 一、基本信息

- 课题：2.2 数轴（第1课时）
- 教材：北师大版《义务教育教科书·数学》七年级上册 第二章 有理数及其运算
- 课型：新授课 课时：1课时（45分钟） 班额：45人（4人一组，共11组，其中1组5人）

## 二、教材分析

本节是第二章“有理数及其运算”的第2节第1课时。在2.1节学生已认识负数与有理数，本节课借助温度计等生活实物，把“数”与“直线上的点”联系起来，抽象出数轴，是学生第一次系统接触“数形结合”的核心工具。数轴是后续学习相反数、绝对值、有理数加减运算的重要基础，也是初中代数“以形助数”思想的起点，在教材体系中处于承上启下的关键位置。第1课时限于数轴的概念、三要素、画法与用数轴上的点表示有理数；“利用数轴比较数的大小”留待第2课时。

## 三、学情分析

七年级学生已掌握正负数意义，能区分有理数类别，具备初步的观察归纳能力；但对“用直线上的点表示数”缺乏经验，画数轴时容易遗漏正方向、漏标刻度，或使单位长度不统一，对“单位长度可以自选但全轴必须一致”理解不到位。学生形象思维占主导，宜借助实物类比和动手操作降低抽象度。全班45人，基础大体中等，适合以4人小组开展纠错与互查。

## 四、课标要求

《义务教育数学课程标准（2022年版）》第三学段“数与代数”领域要求：理解有理数的意义，能用数轴上的点表示有理数；经历抽象过程，发展几何直观，初步形成数形结合的意识。本节直接对应“能用数轴上的点表示有理数”（课标原文条目请教师按手头文本核对）。

## 五、教学目标（三维）

1. 知识与技能：理解数轴的概念，掌握数轴的三要素；能按步骤正确画出数轴；能用数轴上的点表示给定的有理数，能读出数轴上的点所表示的数。
2. 过程与方法：经历从温度计等实物抽象出数轴的过程，体会由具体到抽象的方法；通过画数轴、辨错例发展几何直观，初步感知数形结合思想。
3. 情感态度与价值观：感受数学与现实生活的联系，体会数学表达的简洁之美；在纠错与互查中养成严谨规范的学习习惯。

## 六、教学重点

数轴的概念与三要素；正确画数轴；用数轴上的点表示有理数。

## 七、教学难点与突破策略

- 难点1：三要素缺一不可，“单位长度”必须全轴统一，学生易漏画或画得不一致。
  突破策略：出示四幅典型错误画法让学生当“医生”找病因；归纳画法口诀“画直线、定原点、定方向、标刻度”，同桌互查落实。
- 难点2：负数（尤其小数如 -2.5）在原点左侧的定位，学生易标错位置。
  突破策略：从温度计零下刻度类比迁移；先描整数点、再描小数点，用“距原点几个单位长度”逐步定位。

## 八、教学方法

情境教学、启发式讲授，结合动手操作与合作学习；以“观察—抽象—操作—辨析”为主线。

## 九、教学准备

- 教师：多媒体课件、温度计实物（或图片）、三角板直尺、四幅错误数轴图卡、学案。
- 学生：直尺、铅笔、练习本。

## 十、教学过程（45分钟）

### 环节一：情境导入（约5分钟）

- 教师活动：出示冬季城市气温预报“最高气温 5℃，最低气温 -5℃”和温度计实物（图片）。提问：温度计是怎样把 5℃ 和 -5℃ 同时表示出来的？温度计上有哪些共同特征？
- 学生活动：观察、交流，说出：有一个 0 刻度作为零上零下的分界；零上刻度朝上、零下刻度朝下（方向相反）；刻度间隔均匀相等。
- 设计意图：从学生熟悉的实物出发，为抽象出数轴三要素做直观铺垫，激发学习兴趣。

### 环节二：新知探究（约20分钟）

**探究一：由温度计抽象出数轴（约5分钟）**
- 教师活动：引导类比——把温度计“拉直”成一条直线，0℃ 对应哪个点？零上方向朝哪？每个刻度间隔表示什么？师生共同归纳：在一条直线上取一点表示 0（原点），规定一个正方向，选取适当长度作为单位长度，就得到一条数轴。
- 学生活动：在学案上尝试把温度计特征迁移到直线上，跟随归纳说出定义。
- 结论：规定了原点、正方向和单位长度的直线叫做数轴。三要素——原点、正方向、单位长度，缺一不可。
- 设计意图：经历“实物→图形→定义”的抽象过程，落实过程与方法目标。

**探究二：画数轴的方法（约6分钟）**
- 教师活动：黑板示范画数轴四步：①画一条水平直线；②在直线上取一点作原点，标"0"；③规定向右为正方向并画箭头；④从原点向右、向左每隔一个单位长度取一点，依次标 1、2、3…和 -1、-2、-3…。追问：单位长度必须等于几厘米吗？可以自选吗？
- 学生活动：跟随示范在学案上画数轴；讨论并回答“单位长度可自选，但同一条数轴上必须统一”。
- 归纳口诀：一画直线、二定原点、三定方向、四标刻度。
- 设计意图：通过示范与追问突破难点1。

**探究三：错例辨析（约5分钟）**
- 教师活动：投影四幅错误画法——A缺正方向、B缺原点、C缺单位长度刻度、D单位长度不一致。组织小组“当医生找病因”。
- 学生活动：4人小组讨论，指出每幅图缺了哪个要素，派代表上台修正。
- 设计意图：以错纠错，巩固“三要素缺一不可”，突出重点，训练严谨习惯。

**例题示范（约4分钟）**
- 例1：画一条数轴，并在数轴上表示出 3，-2，0，1.5，-2.5 这些数。
- 教师活动：示范描点：先描整数、再描小数；说明 -2.5 在原点左侧、距原点 2.5 个单位长度。追问：表示 -2 的点与表示 2 的点在位置上有什么关系？（此问只作观察，为后续相反数、绝对值学习埋伏笔，不下结论。）板书结论：任何有理数都可以用数轴上的一个点表示。
- 学生活动：在学案上独立完成，同桌互查；观察并说出位置关系。
- 设计意图：落实知识与技能目标，突破难点2。

### 环节三：巩固练习（约13分钟）

**基础练习（全体必做，约6分钟）**
1. 判断下列图形是否是数轴，并说明理由（学案附2幅缺要素图、1幅正确图）。
2. 画一条数轴，并在数轴上标出表示 -3，-1，0，2，4 的点。
3. 写出数轴上点 A、B、C、D 所表示的数（学案附图）。

**提升练习（小组合作，约5分钟）**
4. 数轴上表示 -2 的点在原点的哪一侧？距原点几个单位长度？
5. 点 A 表示 -1，点 B 与点 A 相距 3 个单位长度，点 B 表示什么数？（提示：B 可能在 A 的哪一侧？）

**拓展思考（机动，约2分钟）**
6. 找一找生活中还有哪些“像数轴”的东西（电梯楼层按钮、直尺、卷尺），说说它们的原点、正方向、单位长度分别是什么。

- 设计意图：基础题巩固画法与读数，提升题深化位置与距离理解，拓展题把数学拉回生活；分层设题，全员参与、各有所得。

### 环节四：课堂总结与作业布置（约7分钟）

- 课堂总结（约4分钟）：教师引导学生回答：①什么是数轴？三要素是什么？②画数轴分哪四步？③今天怎样用数轴表示一个有理数？师生共同提炼：数轴是数与形的第一次牵手，“数形结合”是我们今后学数学的重要思想。
- 作业布置（约3分钟）：宣布分层作业（见下），说明基础题必做、提升题选做、拓展题自愿挑战，次日课前小组内互查基础题。
- 设计意图：提问式总结让学生自己梳理知识结构；分层作业对应不同层次学生，落实分层推进。

## 十一、板书设计（图解式+提纲式）

```
                    2.2  数轴（第1课时）

 一、数轴的定义：规定了原点、正方向、单位长度的直线
 二、三要素：原点、正方向、单位长度（缺一不可）
 三、画数轴四步：画直线 → 定原点 → 定方向 → 标刻度
     （单位长度可自选，同一条数轴上必须统一）

 右侧配例1数轴图：
 ──┼───┼───┼───┼───┼───┼───┼───┼──→
  -3  -2  -1   0   1   2   3   4
       ●       ●      ● ●    ●     （依次为 -2，0，1，1.5，2，3 中的点）
 注：-2.5 在 -2 与 -1 正中间；1.5 在 1 与 2 正中间
```

呈现时机：定义与三要素在探究一、二时写出；四步口诀在示范时逐步写出；例1数轴图在例题示范时当场画出并描点。

## 十二、作业设计（分层）

**基础题（全员必做，约10分钟）**
1. 判断下列说法是否正确，并说明理由：
   ① 数轴是一条直线。（错——只有规定了三要素的直线才是数轴）
   ② 数轴上表示 0 的点叫原点。（对）
   ③ 画数轴时，单位长度必须是 1 厘米。（错——单位长度可适当选取，只需全轴统一）
2. 画一条数轴，并在数轴上标出表示下列各数的点：-4，-1，0，2，5。
3. 写出数轴上点 A、B、C、D、E 表示的数（教师课后在学案附图）。
（对应目标1）

**提升题（学有余力选做）**
4. 在数轴上，表示 -3 的点在原点的（ ）侧，距离原点（ ）个单位长度。（答案：左；3）
5. 点 P 表示 -1，与点 P 距离 2 个单位长度的点表示的数是______。（答案：1 或 -3，分左右两种情况讨论）
6. 把 -2，3，0，-1.5 按从小到大的顺序排列，并在同一条数轴上标出这些点，观察它们的位置与大小顺序有什么关系。（答案：-2 < -1.5 < 0 < 3；观察结论“越靠左的数越小”仅为铺垫，正式结论下节课给出）
（对应目标1、2）

**拓展题（自愿挑战）**
7. 小明家电梯按钮上有 -2，-1，1，2 层（没有 0 层）。如果把电梯井看作一条数轴，它的“原点”选在哪里合适？-2 层与 2 层按钮的间隔和 1 层与 2 层的间隔相同吗？写一写你的想法。（开放题，言之有理即可；引导发现实物未必严格满足三要素，加深对三要素必要性的理解）
（对应目标2、3）

**参考答案与解析要点**
1. 见各小题括注；2. 答案图略，各点距原点分别为相应个单位长度，负数在原点左侧；3. 依附图读数；4. 左，3；5. 1 或 -3；6. -2 < -1.5 < 0 < 3；7. 开放题。
教材“习题 2.2”配套题可替换或补充本题组（不同印刷年份题号可能不同，请按所用教材核对）。
