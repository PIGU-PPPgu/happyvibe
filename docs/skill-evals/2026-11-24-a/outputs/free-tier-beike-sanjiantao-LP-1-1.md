# 2.2 数轴（第1课时）教学设计

## 一、基本信息

| 项目 | 内容 |

| 学科 / 年级 | 数学 / 七年级上册 |

## 二、课标依据

《义务教育数学课程标准（2022年版）》第四学段（7～9年级）「数与代数」板块「数与式」内容要求中与本课直接相关的表述：**「能用数轴上的点表示有理数，能比较有理数的大小。」**

本课落实前半句「用数轴上的点表示有理数」；后半句「比较有理数的大小」在本章后续课时借助数轴继续落实。条目号未凭记忆标注，引文请对照课标原文核对。

## 三、教材分析

- **是什么**：数轴是把「数」放到「一条规定了原点、正方向、单位长度的直线上」的模型，是学生在初中阶段遇到的第一个正式的数形结合工具。
- **从哪来**：小学阶段已在温度、海拔、收支等情境中认识负数；本章 2.1 已学有理数的意义与分类，能用正负数表示相反意义的量。温度计是数轴最贴近的生活原型。
- **往哪去**：数轴是 2.2 第2课时（相反数）、2.3（绝对值）、后续有理数运算乃至七年级下册不等式的直观基础；「数轴上右边的点表示的数比左边的大」是本章比较大小的依据。
- **核心矛盾**：学生原有的「数」是从左往右递增的一串符号，而数轴要求把数看作直线上的「位置」——负数要落到原点左侧、刻度要向左延伸。从「数是符号」到「数是点」，是从算术思维走向代数思维的关键一步。
- **独特价值**：本课第一次让学生体会「每一个有理数都能在数轴上找到唯一对应的点」，为整个初中的数形结合思想埋下种子。

## 四、学情分析

本班共45人，开学约一个月，已完成本章 2.1 的学习，能对有理数分类、用正负数表示相反意义的量；小学阶段接触过温度计上的负数，但「把数排成一条直线」没有正式经验。预计三类起点：约三分之一学生能凭温度计经验较快画出数轴，但易漏标负方向刻度或箭头；部分学生可能把负数标到原点右侧，方向感尚未建立；个别学生对 1.5、−2.5 这类小数的定位感到困难，小学刻度经验以整数为主。按前后桌四人一组组织互查（11组，余1人并入第1组），便于教师巡视时覆盖全班。

## 五、教学目标

- **① 能说出数轴的定义与三要素（原点、正方向、单位长度），并说出三要素在温度计上的对应物。**
  证据：环节二课堂问答、环节五随堂检测第1、2题，全班正确率≥90%。
- **② 能按五步（画直线→定原点→定正方向→定单位长度→标刻度）独立画出一条规范的数轴。**
  证据：环节三「画一画」，经同桌互查通过，通过率≥90%。
- **③ 能在给定的数轴上正确标出正整数、负整数、0、小数（分数）所对应的点，方向正确、位置与单位长度对齐。**
  证据：环节四「标一标」互查、环节五随堂检测第3题，正确率≥85%。

## 六、教学重难点及成因

**重点**：数轴的概念与三要素；用数轴上的点表示有理数。
成因：本课内容是相反数、绝对值及后续有理数运算的共同直观基础，也是初中数形结合思想的起点；这个模型不建立，后续内容的直观解释都失去依托。

**难点**：正确画出规范的数轴，并在数轴上准确定位负数与小数（分数）。
难在：因为学生原有经验里数是「从左往右越写越大的一串符号」，负数要落到原点左侧、刻度要向左延伸，与既有书写习惯相反；同时 1.5、−2.5 这类数要把单位长度再等分定位，学生小学阶段的刻度经验以整数为主，等分定位意识刚起步，容易标错方向或位置。

## 七、教学准备

教师：直尺、三角板，温度计实物或图片，随堂检测单45份（题目见环节五）。
学生：直尺、铅笔、练习本。

## 八、教学过程

| 环节与时长 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|
| 环节一 情境导入（5分钟） | 1）口述情境：清晨气温−3℃，中午升到5℃，板书两数。2）提问：−3℃和5℃在温度计上各在什么位置？把温度计横过来放平，它像什么？3）收集学生的描述，板书关键词（0刻度、两个方向、刻度均匀）。 | 1）口答两个温度在温度计上的位置。2）观察横置温度计（或想象），用自己的话描述它的样子。3）互相补充描述。 | 为目标①提供直观铺垫。用学生熟悉的温度计原型引入，让数轴从实物经验中抽象出来；先观察后命名，比直接给出定义更能让学生记住三要素的来源。 |
| 环节二 数轴的定义与三要素（10分钟） | 1）引导抽象：横放的温度计上，0刻度相当于什么（原点）、温度升高的方向相当于什么（正方向）、每一格相当于什么（单位长度）。2）板书定义「规定了原点、正方向、单位长度的直线叫做数轴」，强调三要素缺一不可。3）出示三个反例（缺原点、无正方向箭头、左右刻度间距不一致），提问：它们是数轴吗？差什么？ | 1）跟随提问，把温度计与三要素一一对应说清楚。2）齐读定义，复述三要素。3）逐条判断反例，说出各缺哪个要素。 | 对应目标①（证据：课堂问答）。用反例辨析代替正例重复，学生在「差什么」的判断中主动区分三要素，形成可检查的表象，直接服务环节三的画轴自查。 |
| 环节三 画数轴（10分钟） | 1）黑板示范五步画法：画水平直线→定原点标0→右端画箭头定正方向→选合适单位长度→从原点向两侧依次标刻度并标数（1、2、3与−1、−2、−3）。2）布置「画一画」：每人独立画一条数轴。3）巡视收集典型问题（漏箭头、间距不匀、漏标负数），投影2～3份组织集体纠错。 | 1）对照五步看示范。2）独立画一条数轴。3）与同桌按三要素逐项互查互评。4）参与纠错：指出问题、说补法。 | 对应目标②（证据：互查通过的「画一画」，通过率≥90%）。示范拆成五步程序，人人动手产出可检查的作品；用本班当堂生成的错误做纠错素材，比预设错例更贴近本班实际。 |
| 环节四 用数轴上的点表示有理数（12分钟） | 1）示范表示3与−3：先定方向（正右负左），再数单位长度。2）布置「标一标」：在所画数轴上标出4、−2、0、+1.5、−2.5。3）巡视，重点看负数与小数的定位，请2～3名学生上台标注并讲思路。4）追问：0标在哪里？+1.5为什么不在刻度线上？−2.5在−2的哪一侧？点出「越往右数越大」，说明下节课将借助数轴比较大小，此处点到为止。 | 1）复述「先定方向、再数格」的方法。2）独立完成「标一标」，同桌互查。3）上台标注的学生口述定位过程，其余学生质疑补充。4）回答追问，感受数与点的对应。 | 对应目标③（证据：「标一标」互查与随堂检测第3题）。任务从整数到小数逐级设难，让难点当堂暴露；追问把「点是数的位置」逼出口头表述，检验的不仅是会标，还有定位依据。 |
| 环节五 随堂检测与反馈（5分钟） | 1）发放检测单，限时3分钟独立完成：第1题写出数轴三要素；第2题判断两条直线是否为数轴并说理由（一条缺正方向箭头、一条左右间距不一致）；第3题在同一数轴上标出−3、0、2、1.5。2）组织同桌交换互批，举手统计各题正确人数。3）点评高频错误。 | 1）独立限时完成。2）交换互批，报出正确题数。3）听点评，标记自己的错题。 | 对应目标①③（目标②的证据已在环节三采集）。纸笔检测为教学目标中的正确率指标（①≥90%、③≥85%）提供全班证据；课内互批使反馈不过夜。 |
| 环节六 小结与作业布置（3分钟） | 1）提问式小结：今天学会哪两件事？画数轴先想哪三样东西？2）布置分层作业（见「十、分层作业」），讲清①层必做、②③层递进选做的规则。 | 1）口头回答小结问题。2）记录作业与选做规则。 | 回扣目标①②③。让学生自己复述三要素与画轴步骤，完成当堂再现；分层作业规则当堂讲清，避免课后执行走样。 |

环节时长合计：5＋10＋10＋12＋5＋3＝45分钟，与课时总长一致。

## 九、板书设计

型式：主干式＋图示（数轴原型居中）。

```
                    2.2 数轴
一、定义：规定了原点、正方向、单位长度的直线叫做数轴
二、三要素：原点 | 正方向（箭头向右）| 单位长度 —— 三者缺一不可
三、画数轴五步：画直线 → 定原点 → 定正方向 → 定单位长度 → 标刻度
四、数与点：每个有理数都能在数轴上找到唯一对应的点

      −3    −2    −1     0     1     2     3
 ←────•─────•─────•─────┼─────•─────•─────•────→
              （左负右正，刻度间距一致）

 右边的点表示的数 ＞ 左边的点表示的数
```

副板书（黑板右侧）：随堂记录学生生成的典型错误（漏箭头、间距不匀、负数标错侧），纠错时对照使用。

## 十、分层作业

素养锚点（三层共同指向）：能用数轴上的点表示有理数，初步体会数与点的对应关系（指向几何直观、数感）。三层难度递进，素养目标不降低。
完成规则：基础层①全员必做；①层全部正确后进入中等层②；②层全部正确后进入拔尖层③。次日课代表收齐，教师按层批改统计。

**基础层①（全员必做）**
- A1. 写出数轴的三要素。
- A2. 判断：「任意一条直线都是数轴。」这句话对吗？若不对，指出缺少什么并改正。
- A3. 画一条数轴：标出原点与正方向，向右标出1、2、3，向左标出−1、−2、−3。
- A4. 在你所画的数轴上标出表示 2、−1、0、+3 的点。

**中等层②（①层全对后完成）**
- B1. 在同一条数轴上标出表示 −2.5、+1.5、−3.5 的点。
- B2. 数轴上点A在原点左侧2个单位长度处，点B在原点右侧3个单位长度处。写出A、B表示的数，并说出你是怎么确定的。
- B3. 小明画的数轴向右每格长1厘米，向左每格长0.5厘米。他错在哪里？说明理由并帮他改好。

**拔尖层③（②层全对后完成）**
- C1. 点M表示−2。1）M向右移动4个单位长度，到达的点表示什么数？2）M向左移动3个单位长度呢？借助数轴说明结论。
- C2. 某商品以原价为基准记作0，先降价2元，再涨价5元。在数轴上标出原价位置、降价后位置、涨价后位置，并回答：现在的价格比原价高还是低？你的结论与点的位置一致吗？
- C3. 数轴上有没有最大的正数？有没有最小的正整数？把结论和理由写下来。

## 十二、教学反思

以下为课前预设的反思要点，课后按实际填写：
1. 目标证据核对：随堂检测第1、2题正确率是否达到90%（目标①），第3题是否达到85%（目标③）；未达标学生的错误归入哪一类（漏要素、负方向、小数定位），下节课用5分钟回访。
2. 环节三互查中暴露的典型错误，纠错后是否消除；未消除的记入副板书留到下节课。
3. 分层作业数据：①层错误集中的题次日课前面批；②层小数定位错误若集中出现，下节课增加数轴口答定位练习。
4. 时间复盘：环节四12分钟是否足够；不足时将追问并入环节六小结，小结压缩为2分钟、环节四延至13分钟（合计仍为45分钟）。
