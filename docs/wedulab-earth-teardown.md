### 2. 六个自研着色器（这是精致感的核武器）

从 chunk 内 GLSL 字符串逐条还原：

1. **晨昏线着色器**（改造内置材质，`#include <common>` 后注入）：
   `sunK = dot(normal, sunDir)` 定昼夜；`nightK = 1-smoothstep(-0.2, 0.08, sunK)` 软晨昏带；
   夜面加冷蓝环境光 `vec3(.05,.08,.14)`，城市灯光 `pow(city, 1.35)` 提对比。昼夜过渡带是真实物理感的来源。
2. **星星闪烁**：每星带 size/phase/color attribute，`tw = .78+.22*sin(t*(.6+ph*2.4)+ph*40)` 独立相位闪烁；点精灵用双高斯光斑 `exp(-r²4)+.25·exp(-r².9)`。
3. **大气边缘光**：`pow(max(0,.64-dot(N,view)),2.4)` 菲涅尔式 limb glow。
4. **彗星/流星拖尾**：`tail = exp(-d*7)` 指数衰减拖尾动画。
5. **轨道环反走样**：smoothstep 双侧软边。
6. **动态条带**（极光/喷流类效果）：`pow(fract(vUv.y*2.2-t*.55),10.)` 循环上升。

### 3. 渲染栈

three.js + OrbitControls（`enableDamping` 惯性 + `minDistance` 防穿模）+ RoomEnvironment（与我们同款）。
共享 chunk 里备有 **GTAOPass（环境光遮蔽）/ BokehPass（景深）/ OutputPass** 后处理件（其他实验室在用；earth 本体靠贴图+着色器就够）。

### 4. 教学层（与 3D 同等重要）

- **双语章节导航**：`01 自转 / EARTH ROTATION`——编号 + 中文标题 + 英文副题（与 HappyVibe 壳 v3 同构，他们编号+英文双行）
- **讲稿内嵌在 chunk**：`<p class="lead">` 每章开头一段带 `<b>` 加粗术语的导语 + 分节 + 表格 + 公式（`H = 90° − |φ − δ|` 带变量说明）
- **实时公式面板**（不是装饰）：日期滑杆（doy 1-365）、北京时间滑杆（0-24 步 0.05）→ 实时算直射点纬度、昼长、正午太阳高度、自转线速度 `1670·cos(φ) km/h`、近日点/远日点标注——**数据与 3D 场景同源联动**
- **地理标注**：球面 marker 带 `纬度°N/S · 线速度` 文字
- **随堂检测**：QUESTION n/N + 实时得分 + 选项 ok/bad 态 + 每题 why 解析 + 按得分给复习建议（≥1 全对/≥0.6 回看错题/<0.6 从头复习）
- **catalog 元数据**：31 实验每个有 id/name/en/subject/desc/points[4]/preview/status 六字段（首页卡片直接消费）

### 5. 工程组织

单页应用 + 每实验室独立懒加载 chunk；i18n 六语言独立 chunk；分析/教室/字幕/集卡等通用能力也是独立 chunk。**没有用 React Three Fiber 之类的重框架抽象，就是 three.js 裸写 + 原生 DOM**。

## 二、视觉评审结论（analyze_image 两轮，earth-home.png / earth-ch2.png）

### 总览页（Chapter 00）

- **构图反直觉但正确**：地球只占画面 6-8% 宽——小而精的主体 + 巨大轨道线 = 天文尺度的敬畏感；轨道椭圆外的深空全部留白，星点极稀疏（可辨识 40-80 颗，大多 alpha 0.1-0.3）
- **光影叙事一致**：UI 里说明的光源就是画面里实际的光源（太阳 = 唯一主光）；太阳多层辉光（白核→橙球→径向光晕→放射光芒）；地球暗面保留 10-15% 微光不死黑；大气蓝边缘亮侧朝太阳
- **色彩纪律**：深蓝黑基底 #060a12 + 米白正文 + **唯一暖金强调色**，金色只给"被点击/被强调"之物，克制到吝啬；UI 低对比 + 3D 高对比两个域叠加
- **HUD 元数据**：`AZ 098° · EL 28° · R 22.3` 相机实时参数、`CHAPTER 00 / 08`、顶栏 `DATE/节气/SUBSOLAR 直射点`——"实时运行的科学仪器"叙事
- **引线注释锚点**：节气标签 = 金色 1px 描边胶囊 + 细引线指向轨道实际位置，学术图表图注式
- **底部时间轴是曲线**：随季节起伏的金线 = 直射点纬度变化本身，滑块骑在线上——控件即知识表达

### 章节页（Rotation）

- **讲义与 3D 双栏耦合**：文字每提一个视觉元素，场景就有对应物，且用一句话说明编码规则（"图中箭头长短即线速度大小"）
- **参数联动可玩**：纬度滑杆 → 线速度实时 `1670·cos(φ) km/h`，学生"拖动出结论"而非读结论
- **视角即教学动作**：北极俯视/南极俯视/侧视按钮直接对应"逆时针/顺时针"知识点
- **章节导航分组**：OVERVIEW/ROTATION/REVOLUTION/REVIEW 四组，00 总览、08 检测首尾有职能
- **关键词金色高亮**：正文结论词（自西向东/逆时针）金色/下划线，只标真正要记的

### 一句话方法论（视觉评审原话）

> 暗色同系基底 + 唯一暖金强调色 + 小而准的 3D 主体 + 引线注释系统 + 出版级双语排版 + HUD 元数据——所有元素共同讲述"这是一个真实运行的科学仪器"这一个故事。

## 三、对我们的可落地差距（按性价比排序）

1. **单物体质感靠贴图栈而非单一材质**：鼎只有 2 张 512×256 canvas 贴图；earth 用 5 张 2048 贴图。→ 我们的门面 3D 资源应配 1024+ 贴图（彩色/凹凸/高光分离），体积用 lazy 或压缩档位控制。
2. **着色器是分水岭**：晨昏线、边缘光、粒子拖尾这类 30-60 行的自研着色器，是"网页感"与"专业感"的分界线。我们已有 bump/color，缺 limb glow 与状态驱动着色（如鼎的铭文高亮可用自研 shader）。
3. **数据面板必须真算**：earth 的滑杆驱动真实天文公式。我们的数轴/展开图已做到同源，但 3D 资源（鼎）还没有"参数面板→场景联动"。
4. **quiz 反馈闭环**：每题 why + 分段复习建议，我们 quiz 有 why 但无分段建议。
5. **体积策略**：他们 3.6MB 贴图敢上，因为按实验室懒加载。我们单文件 4MB 闸门对门面资源可以单独放宽或分档（经 user 确认）。
