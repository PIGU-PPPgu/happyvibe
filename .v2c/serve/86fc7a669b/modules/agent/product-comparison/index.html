T1 · Agent 通识

大厂 Agent 产品横评

8 款 Agent 按普通教师 / 技术教师视角打分：文档、PPT、Excel、教研、网页、定时远程、生态、安全。含选型建议。

培训 PPT S36、S38-S40

一句话结论：只推一款选 WorkBuddy；教研科研选 Kimi Work；自动化与信息中心选 QoderWork；OpenClaw 仅限 IT 隔离部署。

对比维度与权重

评分维度：文档 / PPT / Excel / 教研 / 网页·桌面 / 定时·远程 / 生态 / 安全，并区分「普通教师」与「技术教师」两类视角。

怎么用这张表

  1. 先定位自己：普通教师看「文档 / PPT / Excel」三列；信息科技教师看「网页 / 定时远程 / 安全」；
  2. 再对场景：写课题 → Kimi Work；做宣传海报 → MiniMax；全校统一推 → WorkBuddy；
  3. 价格策略：标准版额度少、高级版偏贵——先用免费档试出哪款顺手，再决定要不要付费。

提醒

  • 评分会过时，「按维度选型」的方法不会；
  • 涉及学生数据的场景，优先看「安全」列，并确认数据是否用于训练（参考万事留痕的做法：全程不用用户数据训练）。
