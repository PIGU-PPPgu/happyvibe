05 · AI × 教师成长

教师智能体：造一个「懂你学科的你」

用 WorkBuddy 专家+Skill 组合出自己的数字分身：懂你的学科、你的班情、你的表达习惯——你不在时它替你答疑。

培训成长路径图 · 教师成长方向

一句话结论：教师智能体 = 你的学科知识 + 你的教学经验 + 你的表达习惯，打包成一个 7×24 在线的「数字分身」。做法只有三步：装专家、喂资料、教习惯。

它和你用过的 AI 有什么不同

普通 AI 谁问都一样答；你的智能体知道：你教初二数学、你们班函数是弱项、你讲题习惯先情境后公式。学生/家长问它，它用你的口径回答。

三步打造（今天就能做）

第 1 步 · 装专家（5 分钟）

WorkBuddy 左侧「专家·技能·连接器」→ 找教育类专家 → 添加。专家是现成的「角色底座」。

第 2 步 · 喂资料（10 分钟）

把你的三类材料给它：常用话术（如下）：

请记住我的基本情况，之后所有回答都基于这些：
1. 我教初二数学，用的是北师大版
2. 我们班共 45 人，函数与几何是普遍弱项
3. 我答疑的习惯：先给提示，不给直接答案；用生活情境引入
4. 家长沟通时语气亲切，多用鼓励

第 3 步 · 教习惯（边用边教）

每次它答得不像你，就纠正一句：「下次这种题先问我学生做到哪一步了再提示」。纠正 3 次以上 → 固化成 Skill（方法见 亲手固化一个 Skill）。

三个使用场景

场景怎么用
学生课后答疑把智能体分享给学生，它按你的教学法先提示后解答
家长常见问题作业要求、复习方法类问题，它用你的口径回复
你自己的备课助手它已懂你的班情，出的练习自动贴合你的学生

边界

  • 涉及个别学生隐私的问题不要交给它（成绩、矛盾、心理）——这些只能你本人处理；
  • 它的回答署你的名之前必须过目——智能体是分身，不是替身；
  • 定期检查它有没有「学歪」：每月抽查几段对话。

检查点

  • 装好了一个教育类专家
  • 喂过一次「基本情况」话术
  • 纠正过它至少 1 次表达习惯

下一步：把你的智能体经验固化成 Skill → Prompt 与 Skill；想玩出更多自己的花样 → 创意工坊
