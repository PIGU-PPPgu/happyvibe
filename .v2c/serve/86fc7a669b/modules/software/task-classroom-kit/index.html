T2 · WorkBuddy 实操

任务三：一周课堂三件套（点名器 + 积分板 + 抢答页）

三句话换三个课堂工具，周一点名、周三积分、周五抢答——本站有全部可交互成品，做完直接投屏用。

任务式教程（成品全部真实可玩）

一句话结论：三个 10 分钟的小任务，换一学期的课堂气氛。每个都有真实成品，点开就能玩。

任务卡

成品随机点名器 + 小组积分板 + 知识抢答页（三个独立网页）
耗时每个 10-15 分钟，可分三天做
难度★☆☆☆☆（第 2 课水平就能做）
工具WorkBuddy / 任何 AI 对话框都行（这就是普通 vibe coding）

先玩成品（30 秒决定要不要做）

随机点名器——大字滚动、金色中选、点过不重复：

→ 点开真货玩一下

小组积分板——点击加减分、实时排名、第一名金色高亮：

→ 点开真货玩一下

第 1 件 · 点名器（周一用）

准备：班级名单（Excel 或文本都行，化名亦可——要投屏的注意隐私）。

话术：

做一个课堂随机点名网页：
- 名单我贴在下面（45 人）
- 点「开始」名字快速滚动，2 秒后停在一个名字上，大字金色显示
- 点过的自动排除，页面上显示已点/剩余人数
- 有「重置」按钮
输出 html 版本给我即可。

验收：投屏试 5 次 → 点过的名字再也没出现 → 剩余计数对。

课堂话术（对学生的仪式感）：被点到金色名字的同学，全班鼓掌三秒——气氛就是从这里来的。

第 2 件 · 积分板（周三用）

话术：

做一个小组积分板网页：
- 8 个小组（组名可改），每个有 +1 +2 -1 三个按钮
- 分数实时从高到低排序，第一名金色高亮边框
- 数据存在浏览器本地，关掉再开不丢
- 有「清零」按钮（长按 3 秒才触发，防误触）
输出 html 版本给我即可。

验收：加一组分数 → 排序变了 → 关浏览器重开 → 分数还在。

第 3 件 · 抢答页（周五复习课用）

准备：本周知识点的 10-20 道选择题（没有？让 AI 出：基于「本章知识点」出 15 道选择题，附答案）。

话术：

做一个课堂知识抢答网页：
- 题目我贴在下面，一次显示一题，先不显示选项
- 点「出题」后开始 10 秒倒计时，有小组举手就点对应组名暂停
- 显示选项 → 点「公布答案」→ 正确答案变绿
- 右侧记分板：答对的组 +2，抢答权轮流
输出 html 版本给我即可。

验收：完整走一轮 3 题的流程 → 记分正确 → 倒计时能暂停。

三个任务的共同心法

  1. 一次只要一件：别把三件套塞进一句话，分三次对话做；
  2. 验收就三条：能投屏（字够大）、数据不丢（刷新还在）、按钮够大（手指能点）；
  3. 做顺了就固化：话术存成技能 classroom-kit，下学期换名单 3 分钟重出全套。

完成标准

  • 三件都做出来了，至少两件在真实课堂上用过
  • 每件都过了「投屏三条」验收
  • 把最顺手的一套话术存进了备忘录或技能
