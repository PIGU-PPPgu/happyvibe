T2 · WorkBuddy 实操

第 2 课 · 第一次对话：从「会打字」到「会下需求」

手把手系列。三句话框架 + 任务说明六要素 + 3 个可以照抄的任务。

实机操作记录（v5.4.5）／ 参照 WorkBuddy 蓝皮书颗粒度

一句话结论：对话 = 打字 + 发送。但「帮我写个通知」和一份六要素齐备的任务说明，产出是天壤之别。

热身：先随便聊两句（1 分钟）

跟着下面的动图一起点（这就是你要做的全部动作）：

打字发送的真实样子（三步实拍）：

  1. 打开 WorkBuddy，确认在「新建任务」页；

  2. 点一下中间大输入框（光标开始闪烁）；

  3. 打字（或复制下面这句，在输入框里点右键 → 粘贴）：

    帮我写一句家长会通知的开场白

  4. 点右下角黑色圆形按钮发送；

  5. 读它的回答。随便追问一句：再亲切一点——看它重新回答。

到这一步你已经超过大多数老师了。下面是真正的分水岭。

三句话框架（起步版）

每次下需求，最少说清三件事：

【身份】你是一位有 15 年经验的班主任。
【任务】帮我写一份秋游告家长书。
【要求】500 字以内，语气亲切，列出集合时间、注意事项、回执截止日。
  • 身份：告诉 AI 它是谁——它就会用对应的口吻和专业度回答；
  • 任务：一句话说清做什么；
  • 要求：字数、语气、必须包含的内容。

要让 AI 干活交文件？还差一步

三句话管日常聊天够了；但让 AI 干具体的活（处理文件、生成材料），还需要再加三个要素（约束/输出/验收）——那是下一课的内容。

动手练：三个照抄任务

任务 A · 出题（三句话就够）：

你是一位小学二年级数学老师。
帮我出 5 道 100 以内进位加法题。
要求：由易到难，最后一道是应用题，答案单独放在最后。

任务 B · 改格式：

把上面的题目重新排成表格，两列：题号、题目。

任务 C · 六要素完整版（感受约束和验收的威力）：

【目标】为明天班会写一份「课间安全」讲话稿
【输入】无（基于你的常识）
【动作】先讲 1 个 30 字以内的小案例，再给 3 条安全要点，最后 1 句号召
【约束】全程不指责学生；不出现真实班级人名；口语化，像跟学生面对面说话
【输出】直接在对话里给出，300 字左右
【验收】我数一下字数，并且检查是不是真的没有出现人名

✓ 检查点：任务 C 发出后，对着它自己的输出核对约束——如果出现了人名，你就追问：出现了人名，请替换成"有同学"，其他不变。——验收后追问修正这个动作，比写话术本身更重要。

三个立刻能用的话术（抄进备忘录）

场景直接照抄
改文风把上面的内容改得口语化一点，像跟家长面对面说话
要格式整理成 Markdown 表格，两列：事项、负责人
让 AI 反问开始之前，先问我你需要知道的信息

检查点

  • 会发送消息、会追问
  • 用三句话框架写出过一段 ≥3 行的需求
  • 用三句话框架写过 ≥3 行的需求，并追问过一次

完成就进 第 3 课 · 任务说明六要素——让 AI 干活一次做对。
