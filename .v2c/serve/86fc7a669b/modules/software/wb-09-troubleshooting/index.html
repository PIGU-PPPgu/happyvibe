T2 · WorkBuddy 实操

第 9 课 · 排错手册：卡住了怎么办（10 种常见情况）

手把手系列完结课。任务卡住、数字不对、文件没生成、积分飞快烧——10 种最常见的坑，对照这一页自助解决。

实机操作与真实踩坑记录

一句话结论：90% 的问题能用三招解决——说「继续」、重开对话、完全重启。剩下 10%，查这一页。

万能三招（先试这个）

招怎么做解决率
① 说「继续」输入框打：继续卡住的任务多数直接续上
② 重开对话新建任务，把话术重新发（材料重新拖）跑偏的对话立刻止损
③ 完全重启退出 WorkBuddy（Mac：⌘Q / Windows：点右上角 × 完全退出）再开模型不见了/授权失效类问题

补丁不如重启：一轮对话里反复改超过 3 次还不对，别死磕——重开对话重新描述。AI 没有「越改越好」的执念，你也不需要有。

十种常见情况对照表

1. 任务执行到一半不动了 → 先打「继续」；5 分钟无响应 → 重开对话重发；连续两次 → 换个模型再试（当前脑子可能过载）。

2. 说「找不到文件」 → 话术里写全路径：「桌面 workbuddy-练习 文件夹里的 成绩.xlsx」；iCloud 文件夹右键「立即下载」再试。

3. 生成的文件不知道存哪了 → 直接问它：「你把文件保存在哪里了？给我完整路径」。

4. 数字算错了 → 把正确算法写给它（像第 3 课那样：应该是 (291+248+273)/3 = 270.67），让它照着重算。别只说「错了」。

5. 积分烧得飞快 → 三查：模型倍率是不是选了 1.62x？是不是一次塞了几百页材料？是不是让它「重新生成全部」而不是「只改第 X 部分」？→ 换免费档、只发需要的部分、用「只改不改的部分」话术。

6. 改了代码/网页，越改越乱 → 说出黄金句：「回退到第 X 步的版本，只保留___，其他不动」；或者直接重开对话用「骨架不动，只换内容」重新来。

7. 权限弹窗不停问 → 每步都问说明在「保守模式」——输入框下方「默认权限」改为自动（熟练后再改）；首次仍建议保守模式跑几单。

8. 授权/登录失效、模型列表空了 → 完全重启（⌘Q 再开）；还不行 → 检查网络 → 官网看有没有故障公告。

9. 手机小程序派单没反应 → 手机和电脑确认是同一账号；电脑端 WorkBuddy 保持登录；给任务 1-2 分钟（大本营要在线干活）。

10. 它「一本正经地编造」 → 核对永远在你：涉及事实、数据、文献的产出，抽查 2-3 处再采用。这一条没有技术解法，只有习惯解法。

什么时候该放弃这个任务

  • 同一个错误纠正 3 次还不对 → 换模型或换思路（把任务拆小）
  • 任务本身描述不清 → 停下来，先写清楚六要素再发
  • 涉及它不擅长的（如复杂 PPT 审美）→ 换工具，别硬耗积分

检查点

  • 遇到卡壳能先想到万能三招
  • 把这一页存进了自己的备忘录
