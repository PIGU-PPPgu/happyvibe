T2 · WorkBuddy 实操

实操 · 10 分钟把工作台变成网址（免费上线）

傻瓜级逐步教程：注册 Cloudflare → 拖拽上传工作台 → 手机打开网址。全程不用装软件、不用懂代码、不用买服务器，每一步告诉你屏幕上会看到什么。

任务二续篇 · 上线实操

一句话结论：把工作台文件夹拖进一个网页，10 分钟后你就有一个手机能打开的网址。全程免费、不用装任何软件。

开始前（30 秒自查）

  • ✅ 手上有工作台文件夹（里面有 index.html 那个）；
  • ✅ 有一个邮箱（QQ 邮箱/163 都行）；
  • ✅ 电脑能正常打开网页。

第 1 步 · 注册一个 Cloudflare 账号（3 分钟）

  1. 浏览器打开：dash.cloudflare.com；
  2. 你会看到登录框，下方有 「Sign up（注册）」 字样——点它；
  3. 按提示填：
    • 邮箱：填你的常用邮箱；
    • 密码：设一个你记得住的（记到备忘录！）；
  4. 点 「Create Account（创建账号）」；
  5. 去邮箱收验证邮件——找不到就看垃圾箱——点邮件里的确认按钮。

✓ 成功标志：浏览器回到 Cloudflare 页面，右上角显示你的邮箱名。

卡住了：验证邮件一直不来 → 换个邮箱重试；提示邮箱已存在 → 说明以前注册过，改点「Log in 登录」试试。

第 2 步 · 找到上传入口（1 分钟）

  1. 登录后，看左侧菜单；
  2. 找到 「Workers 和 Pages」（英文界面是 Workers & Pages）——点它；
  3. 点右上角 「创建 / Create」；
  4. 你会看到几个选项——选 「Pages」 那一栏；
  5. 点 「上传资产 / Upload assets」。

✓ 成功标志：屏幕出现一个大的虚线框，中间写着「将文件夹拖到此处 / Drag and drop」。

卡住了：界面是英文看不懂 → 页面右下角（或头像菜单里）通常可切中文；实在没有，照着本文的中英文对照，一个词一个词找。

第 3 步 · 拖入工作台（2 分钟）

  1. 打开你电脑上的文件夹，找到工作台文件夹（index.html 所在的那个）；
  2. 按住整个文件夹，拖到浏览器那个虚线框里，松手；
  3. 等待上传（几秒到一分钟，看文件大小）；
  4. 上传完，它会让你起个项目名——填一个英文短名，比如 wang-workbench（小写字母加横线，别用中文）；
  5. 点 「部署站点 / Deploy site」。

✓ 成功标志：出现绿色提示，给你一个网址，长得像 wang-workbench.pages.dev——这就是你的网址！

卡住了：提示文件类型不对 → 确认拖的是文件夹不是单个文件；上传报错 → 刷新页面重来一次。

第 4 步 · 手机测试（1 分钟）

  1. 把 xxx.pages.dev 网址发到微信（文件传输助手）；
  2. 手机点开——工作台在手机上打开了 ✓；
  3. 把网址收藏：手机浏览器菜单 → 添加到主屏幕（像 App 一样用）。

⚠️ 记住：第 2 档的手机和电脑数据各自独立（手机上记的待办电脑看不到）。要同步看下一课。

第 5 步 · 以后怎么更新（1 分钟）

改了工作台想更新？不用重学：

  1. 回到 Cloudflare → Workers 和 Pages → 点你的项目；
  2. 点 「创建新部署 / Create new deployment」；
  3. 把新的文件夹再拖一次 → 自动更新，网址不变。

常见问题速查

状况怎么办
网址打不开等 1-2 分钟（刚上线要等 1-2 分钟才打得开）；再查项目名有没有拼错
想换网址项目名定了就跟着定了；不满意就新建一个项目再拖一次
会不会收费Pages 免费档对你这个体量永远够用；不绑卡不会扣钱
别人能看到吗知道网址的人都能打开——所以真学生数据别传，用化名版

检查点

  • 手机上打开过自己的网址
  • 网址加到了手机主屏幕
  • 知道更新 = 再拖一次
