案例《AI 试卷讲评系统》

初中数学

痛点：每次月考后 300 份卷子的错题统计占两个晚上，讲评课全凭感觉挑题。

作品：AI 分析答题卡数据 → 自动生成错误率排序 → 讲评课优先讲 Top5 错题 → 配变式训练 → 学生个体错因报告。

怎么做：命题实战出卷 → 考后走月考分析话术 → 讲评课用交互页面演示错题。

更多思路：作文讲评（AI 批注 + 范文对比墙）· 复习导图（学生自画 → AI 补漏 → 差异对照）· 课堂实录 AI 反思（录音转写 → 教学行为分析）· 分层作业自动推送

案例《课本可视化》

小学语文

痛点：一年级课文《秋天》只有静态插图，低龄学生注意力撑不过三分钟。

作品：课本可视化样板——教材页 + 朗读音频 + 大雁排字动画 + 跟读练习。

怎么做：从教材索引领 PDF → 截课文页发给 AI → 走七步迭代法 → 生成配音用 TTS。

更多思路：智能学伴（答疑机器人只按你的教学法回答）· 探究学习页（学生先猜再验证的交互实验）· 个性化阅读推荐（按阅读水平推送不同版本）· 错题本自动生成（AI 归因 + 同类题推送）

案例《AI 素养校本课程》

跨学科

痛点：学校要求开 AI 通识课但没有教材，零散课件拼不成体系。

作品：8 课时 AI 素养课纲 + 每课时课件/教案/学生手册 + 教学实践一学期记录。

怎么做：用素养四层次定目标 → 创意工坊 30 点子选学生活动 → 每课时走七步法。

更多思路：跨学科 PBL（AI+地理的「校园微气候」项目）· 地方文化课程（AI 助力非遗数字化）· 学科拓展课（数学建模 + AI 工具）· 德育课程（AI 情境判定 + 后果模拟）

案例《学科助教智能体》

我们的主场

痛点：学生课后问问题找不到人，家长问学习建议口径不统一。

作品：教师智能体——装专家 + 喂你的教学资料和班情 + 教你的表达习惯 → 学生问它按你的口径答，你审核后放行。

怎么做：WorkBuddy 装教育专家 → 喂「基本情况」话术 → 固化成 Skill → 数据上云（对应赛道「数据库互联」关键词）→ 多个智能体分工（对应「多智能体协同」）。

更多思路：备课智能体（输入课标自动出三版教学设计）· 家校沟通智能体（按你的风格写家长信）· 班务管理智能体（副班主任）· 教研协作多智能体（一个查文献 + 一个写综述 + 一个审格式）· 学情预警智能体（成绩连续下滑自动提醒）

参赛要交什么

1 · 申报书 + 承诺书

官网系统填报后自动生成 → 签字 → 学校盖章（PDF 扫描件）

2 · 作品介绍文档

PDF：名称 + 3-5 个关键词 + 概要 + 教育痛点 + 技术创新点 + 落地场景 + 应用成效

3 · 演示视频 ★

≤10 分钟 ≤500MB：概述≤2min + 核心场景演示≤6min + 效果总结≤2min（录屏/实拍/解说合成均可）

4 · 支撑材料（选填）

操作手册 / 试点案例 / 教学实践记录（≤100MB）——评审加分项，建议交

评审五维度：场景适配 · 技术规范 · 创新优化 · 实施显著 · 推广适配——「真实课堂用过」和「别人也能拿去用」是拉分关键。

为什么是你

作品本身不是门槛——调一个智能体、或者用飞象老师这样一句话出页面的工具，谁都做得出图文并茂的东西。 评审和我们真正看的，是老师亲自跟 AI 把一个想法磨成作品的过程：话术怎么写、结果怎么验、课堂数据怎么留。

这个过程才是要带走的东西。比赛结束，它变成你备课、出卷、做班务的日常能力—— AI 不在课堂台前表演十分钟，在幕后替你把重复的活干了。 这也是本站教 Vibe Coding 而不是只发工具的原因。

关于飞象老师

赶时间交差，它是个好工具，站内也有对应课程。但它替你把活做了——话术、迭代、验收都留在平台里，能力没长在你身上。比赛要交的过程材料，和你要带走的手艺，都来自亲手做一遍。先在这里学会跟 AI 协作，以后用什么工具都顺手。

怎么拿下比赛

对手拼技术，我们拼「真实 + 完整 + 可推广」——评审五维度里，技术只是其中一项。

维度对手的打法我们的差异化打法
场景适配「通用 AI 教学助手」大而空钉死一个真实痛点：「初二数学几何证明题错误率高出年级 12%」——具体到班、到题、到人
实施显著做出来没在课堂用过赛前至少真实课堂用 3 次，留数据：使用前后错误率对比、学生反馈截图、使用频次
创新优化堆功能炫技「Skill 固化 + 知识库 + 多智能体协同」三选二讲透原理——评审看的是方法论不是功能数量
推广适配离开作者就跑不了附操作手册 + Skill 文件可分享——「任何老师拿到 10 分钟能上手」写进文档
技术规范—明确标注使用的 AI 工具平台（官方要求！作品简介中必须写）

三条铁律

  1. 一个作品只解决一个真实痛点——评委记住的不是功能清单，是那个「错误率降了 8%」的数字
  2. 没有课堂数据的故事不要讲——所有「应用成效」必须有截图/数据/学生反馈支撑
  3. 把「别人也能用」做成证据——操作手册 + 可分享的 Skill 文件

团队打法

一个教研组 5 个人：2 人投赛道④（智能体，各自做一个）、2 人投赛道①（教学创新，同课不同环节）、1 人投赛道②（资源）。共享同一个学科的同一个数据底座——数据一次采集，五个作品复用，但每个作品切入点不同（不违反唯一性）。
