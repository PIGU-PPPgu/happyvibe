教学设计与使用步骤

教学设计

学习目标

  1. 经历「展开与折叠」的过程，知道正方体展开图共有 11 种，能按 1-4-1、2-3-1、2-2-2、3-3 分类。
  2. 通过对面同色的直观验证，归纳「对面不相邻」的判断规律，能快速判断一个图形能否折成正方体。

易错点预设

  • 以为「田」字形（2×2）也能折——四个面两两重合；以为面数够就一定能折。
  • 把「相邻」看错行：隔着一条边的两个面未必相对，要沿折叠方向验证。

环节设计

环节学生活动教师提问资源状态
想一想（约 5 分）观察 11 种形态，先猜能否折成，按每行面数分类「它们都能折成正方体吗？每类的横排有几个面？」展开态（折叠度 0），上个/下个切换 11 种
做一做（约 10 分）拖滑杆亲手折叠，边折边预测；辨析田字形、凹字形「折到一半哪些面立起来了？为什么『田』字形不行？」半折态（折叠度 0.35），滑杆控制折叠过程
议一议（约 8 分）观察折叠后对面同色，回展开态数间隔，小组总结口诀并互相出题「相对的两个面隔着几个面？口诀怎么说？」折满态（折叠度 1）与展开态来回对照

板书式小结

正方体展开图共 11 种：1-4-1 型 6 种、2-3-1 型 3 种、2-2-2 型 1 种、3-3 型 1 种。判断口诀：对面不相邻——展开图上相对的两个面之间至少隔一个面；「田」字形、「凹」字形折不成正方体。

3规律理解：对面的位置规律干扰项「紧挨着」直击「相邻」误区

  2. 每个环节配了「讲解」弹层：引导语是抛给学生的问题，讲解词是环节知识点，备课或生讲时点开对照。
  3. 折一折环节放手让学生先猜，再用滑杆验证；田字形、凹字形用「上个/下个」找不到（11 种里没有），顺势讲反面例子。

教学设计与使用步骤

教学设计

学习目标

  1. 能说出数轴的三要素（原点、正方向、单位长度），会在数轴上用点表示有理数。
  2. 借助点在数轴上的位置，说出相反数的几何意义（关于原点对称）与绝对值的意义（到原点的距离），并能据此比较两个有理数的大小。

易错点预设

  • 画数轴漏要素：没有正方向箭头或单位长度不统一，误以为一条画了刻度的直线就是数轴。
  • 把绝对值当成”去掉负号”的操作，说不出它是”到原点的距离”这一几何意义。
  • 比较大小依赖直觉：认为 -5 大于 -3（数字大就大），不看数轴上点的左右位置。

环节设计

环节学生活动教师提问资源状态
想一想（约 5 分）观察温度计刻度与数轴的对应，说出数轴三要素「一条直线要满足哪三个条件才能当数轴？温度计为什么算一条竖着的数轴？」数轴三要素高亮标注（原点/正方向/单位长度），点停在 +2
做一做（约 8 分）拖动金点左右移动，读出点表示的数；与 0 比大小；方向键微调半格「点在原点右边表示什么数？拖到 -3.5，它比 0 大还是小？谁来读出它的相反数？」自由拖动模式，读数板实时显示数/相反数/到原点距离
议一议（约 7 分）观察对称点与两段等长弧线，讨论绝对值的几何意义，小组总结比较大小的方法「2 和 -2 到原点的距离各是多少？数轴上越往右的数越怎样？谁用一句话总结比大小？」对称演示模式：-p 镜像点、

板书式小结

数轴三要素：原点、正方向、单位长度，缺一不可。任何一个有理数都能用数轴上的一个点表示。只有符号不同的两个数互为相反数，它们对应的点关于原点对称；数 a 的绝对值 |a| 表示数 a 对应的点到原点的距离，距离非负，所以 |a| ≥ 0。比较大小看位置：数轴上的点越靠右，表示的数越大，负数比较大小离原点越远的反而越小。

课堂用法

  1. 全屏打开，从「想一想」开始：先请学生对着高亮的三要素说一遍，再用温度计反例（漏了正方向箭头）辨析。
  2. 「做一做」请学生上台拖点，全班齐读读数板三行；拖到负半轴后追问”比 0 大还是小”，落实右大左小。
  3. 「议一议」观察对称点与等距弧线后，先小组说绝对值的意义再点开讲解弹层对照。
  4. 点「检测」做 5 题随堂检测；第 5 题错的回看「议一议」，重练”离原点越远负数越小”。

教学设计

教材锚点：北师大版七年级上册第二章《有理数及其运算》2.4 有理数的加法（已过 textbook-index 校验）

学习目标

  1. 借助数轴上两次移动的合成，说出有理数加法的几何意义，会用「先定符号、再定绝对值」归纳同号、异号、与 0 相加三类法则。
  2. 通过换序操作验证加法交换律 a + b = b + a，并能用法则计算含负数的加法算式。

易错点预设

  • 异号相加先算绝对值之和再随意定号：应先比较两加数绝对值大小，取较大者的符号，再算差。
  • 把 -6 + 6 算成 -12：互为相反数的两数相加得 0，终点回原点。
  • 认为交换律只对正数成立：换序后终点不变，负数参与依然成立。

环节设计

环节学生活动教师提问资源状态
想一想说两次移动后的终点位置向东 3 米再向西 5 米，最后停在哪？加法在数轴上是什么？三要素标注 + 预设 3 + (-5) 行程
做一做拖金、紫箭头端点凑三类算式同号、异号、与 0 相加，终点和符号各怎么定？加法行程自由操作，读数卡同步两步与和
议一议观察换序预设，小组归纳并举例先 -5 再 +3 与先 +3 再 -5，终点变了吗？换序预设 (-5) + 3，对比交换律

题干要点答案解析要点
3 + (-5) 数轴结果-2异号：取大绝对值符号，差 2
-4 + (-3)-7同号：符号不变，绝对值相加

教学设计

教材锚点：北师大版七年级上册第二章《有理数及其运算》2.5 有理数的减法（已过 textbook-index 校验）

学习目标

  1. 借助数轴上的移动方向，说出减法的几何意义，归纳并会用减法法则 a − b = a + (−b)。
  2. 经历”减法转化为加法”的过程，体会负数让减法永远可做，为加减混合运算统一成连加做铺垫。

易错点预设

  • 减负数时方向不反转：3 − (−2) 算成 1，应转化为 3 + 2 = 5。
  • 只顾变号忘了被减数不动：a − b 变加法时把 a 也取负。
  • 认为 0 − 5”不够减”无法计算：终点在原点左侧，结果为 −5。

环节设计

环节学生活动教师提问资源状态
想一想列温差算式，说移动方向减去 −2 该往哪边走？终点在哪？三要素标注 + 预设 3 − (−2) 行程
做一做拖紫箭头换减数正、负、零减正数、减负数方向有何规律？差怎么变？减法行程自由操作，读数卡同步位移与差
议一议观察 0 − 5 预设，讨论封闭性小学”不够减”的算式现在都有答案吗？预设 0 − 5，终点落负数区

题干要点答案解析要点

教学设计与使用步骤

教学设计

学习目标

  1. 经历「摊平—折叠」的过程，理解表面积就是六个面面积的和，能按上下、前后、左右三组对面写出算式。
  2. 改变长、宽、高，观察算式同步变化，归纳出 S = 2(ab + ah + bh)、V = 底面积 × 高。

易错点预设

  • 数面漏掉对面：只算 4 个面。用「点亮一组对面」的功能让学生看到对面成对。
  • 混淆「表面积」与「体积」的单位与含义——面积是铺面，体积是装东西。

环节设计

环节学生活动教师提问资源状态
认一认（约 5 分）读长宽高（5×3×4），点算式行看对应对面发光「S = 30 + 40 + 24，每个数来自哪两个面？」dims=[5,3,4]，unfold=0，高亮「上下」组
摊一摊（约 6 分）拖展开滑杆把盒子摊平成十字展开图，数一数六个面「摊平后哪两个面是一对？你怎么看出来的？」unfold=1（完全摊平），无高亮
变一变（约 6 分）把长改成 4，观察算式与数值联动；使长宽高相等观察正方体算式「长变了哪组算式跟着变？什么时候变成 S = 6a×a？」dims=[4,3,4]，unfold=0，无高亮

板书式小结

长方体表面积 = 三组对面面积之和：S = 2(ab + ah + bh)；体积 = 底面积 × 高 = abh。长宽高相等时是正方体：S = 6a²，V = a³。对面完全相同，数面时成对地数。

题号考查点选项设计
1对面相同的概念干扰项「一定正方形」检验特例与一般
2表面积公式应用干扰项混入体积算式
3公式里「2」的来源直击「不知道 2 从哪来」的机械套用
4正方体体积计算16/48/64/96 三公式数值对调
5特殊与一般的关系检验「正方体公式是特例」的理解

课堂用法

  1. 全屏打开，保持盒状。拖动长、宽、高滑杆，请学生读出每个面上的尺寸标注，再说一说右侧面板里表面积、体积算式哪些数变了、哪些没变。
  2. 把展开滑杆慢慢拉到最右，六个面摊平成一张展开图。按颜色找出三组对面，对着面板里的三行算式，说清楚表面积公式 2×(长×宽＋长×高＋宽×高) 的每一项对应哪两个面。
  3. 点正方体按钮，长宽高变成相同数字，面板换成 S=6×棱长×棱长、V=底面积×高。把鼠标停在某一行算式上，对应的两个面会亮起来，请学生解释这一项为什么要乘 2。
  4. 每个环节配了「讲解」弹层：引导语抛问题，讲解词给公式每一项的几何来源；点「检测」做 5 题，第 3 题错的回看「摊一摊」讲解。

三视图空间观念几何图形初步
READY 进入教室 →
教学设计与使用步骤

教学设计

学习目标

  1. 会从正面、上面、左面观察几何体，说出对应视图的形状。
  2. 由三视图反推简单组合体的构成，发展空间观念。

易错点预设

  • 分不清「从哪边看」：三支彩色方向箭头与三张视图卡颜色一一对应，先认方向再谈视图。
  • 认为看不到的面就不存在——主视图里圆柱藏在正方体后面，俯视图却看得见。

环节设计

环节学生活动教师提问资源状态
认方向（约 4 分）对照三支箭头与三张视图卡，说清「从哪个方向看」「蓝色箭头从哪来？它对应哪张卡片？」solid=cube，视图卡为问号遮罩
猜视图（约 8 分）先猜圆锥三视图形状，再点击卡片揭晓验证「圆锥的主视图和左视图一样吗？俯视图呢？」solid=cone，遮罩待揭晓
说规律（约 6 分）观察组合体（正方体上叠圆柱）揭晓后的三视图，说遮挡关系「主视图里圆柱的下半截去哪了？哪张视图能看见？」solid=combo，open=true 全部揭晓

板书式小结

三视图从正面、上面、左面三个方向观察同一物体：主俯长对正，主左高平齐，俯左宽相等。看不见的被挡住的那部分，会在另一个方向的视图里出现。

教学设计与使用步骤

教学设计

学习目标

  1. 经历拖动 k、b 观察图像变化的过程，能说出一次函数图像的增减性与 b 的几何意义。
  2. 类比迁移到反比例函数，能说出 k 的符号与双曲线所在象限的关系，知道 k = 0 时无图像的原因。

易错点预设

  • 把「k < 0 时 y 随 x 增大而减小」记成图像「下降」——图像是直线，是倾斜方向变缓。
  • 以为反比例函数 k = 0 只是「图像看不见」，说不出「y = k/x 分母无意义」的原因。
  • 混淆 b 的符号与交点横坐标——b 是与 y 轴交点的纵坐标。

环节设计

环节学生活动教师提问资源状态
读一读（约 4 分）读出 y = 2x + 1 与两轴交点，指出式子中 1 对应的位置「式子里的 1 写到了图像的哪个位置？」一次函数 k=2, b=1 标准视图
变 k（约 6 分）先预测 k 变负后直线的转向，再拖 k 验证，对照性质表增减性「k 从 2 拖到 -2，直线怎么转？增减性换了什么说法？」一次函数 k=-2, b=1
变 b（约 6 分）拖 b 从 1 到 -3，观察平移与交点移动，说 b 的几何意义「直线往哪边平移？谁用一句话说 b 的意义？」一次函数 k=2, b=-3
反比例（约 8 分）换 y = 6/x 观察象限，拖 k 过零，解释无图像「k 为正时两支在哪个象限？拖到 0 为什么不见了？」反比例函数 invK=6 标准视图

板书式小结

一次函数 y = kx + b（k ≠ 0）：k > 0 时 y 随 x 增大而增大，k < 0 时减小；b 是直线与 y 轴交点的纵坐标，改变 b 直线上下平移；b = 0 时为正比例函数，图像过原点。反比例函数 y = k/x（k ≠ 0）：k > 0 两支在一、三象限，k < 0 在二、四象限；同支内 k > 0 时 y 随 x 增大而减小，k < 0 时增大；k = 0 时分母无意义，无图像。

教学设计与使用步骤

教学设计

学习目标

  1. 通过拖动 a、b、c，说出各系数对抛物线开口、对称轴、与坐标轴交点的影响。
  2. 会由图像读出对称轴 x = -b/2a 与顶点坐标，并能反推系数符号。

易错点预设

  • 认为 a 决定「上下平移」——a 决定开口方向与宽窄，c 才是与 y 轴交点。
  • 对称轴公式 x = -b/2a 里 a、b 异号时轴在 y 轴右侧，容易弄反。

环节设计

环节学生活动教师提问资源状态
看开口（约 5 分）观察 y = x² - 2x - 3，拖 a 从 1 到 -1 看开口翻转「a 从正变负，图像怎么变？开口宽窄谁说了算？」a=-1→1 过渡，b=-2, c=-3
找顶点（约 6 分）拖 b 改变对称轴位置，读出紫色虚线与顶点坐标「b 变大对称轴往哪边跑？x = -b/2a 验证一下。」a=1, b=2, c=-3
数交点（约 6 分）拖 c 上下平移，数与 x 轴交点个数，读 Δ 与两根「c 从 -3 拖到 1，交点少了几个？Δ 谁决定的？」a=1, b=-2, c=1（Δ=0 相切）

板书式小结

y = ax² + bx + c（a ≠ 0）：a 定开口方向与宽窄，c 定与 y 轴交点 (0, c)；对称轴 x = -b/2a，顶点 (-b/2a, (4ac-b²)/4a)；Δ = b² - 4ac 定与 x 轴交点个数：Δ > 0 两个、Δ = 0 一个（相切）、Δ < 0 无。

课堂用法

  2. 拖 b 滑杆，对照紫色虚线对称轴与顶点标注读出 h、k，看右侧顶点式和三行配方推导如何跟着变；点复位回到标准视图再试一组。
  3. 每个环节配了「讲解」弹层：引导语抛问题，讲解词给规律与口诀（左同右异、Δ 三情况）。

教学设计与使用步骤

教学设计

学习目标

  1. 经历「猜想—验证」发现同弧上圆周角相等、圆周角等于同弧圆心角的一半。
  2. 掌握直径所对圆周角是直角，并能用于简单判断。

易错点预设

  • 把「同弧」看成「同侧」：P、Q 在弧的两段时是互补关系（和为 180°），不是相等。
  • 圆心在圆周角外部/内部时图形变式认不出——资源里拖 P 跨过直径即可看到变化。

环节设计

环节学生活动教师提问资源状态
猜一猜（约 4 分）观察 ∠APB 与 ∠AQB，先猜大小再拖 P 验证「P 沿弧拖动，∠APB 的度数变不变？」A=200, B=340, P=60, Q=130
验一验（约 7 分）读面板三角：两个圆周角相等且为圆心角一半；换 A、B 再验「70°、70°、140° 之间有什么关系？换一组还成立吗？」A=190, B=350, P=70, Q=110
用一用（约 5 分）把 AB 调成直径，发现两角恒为 90°，总结结论「AB 是直径时∠APB 是多少？拖拖看会不会变。」A=180, B=0, P=90, Q=270（AB 为直径）

板书式小结

同弧（等弧）上的圆周角相等；圆周角等于同弧上圆心角的一半；直径所对的圆周角是直角（90°）。判断时先看两个角是否对着同一条弧。

教学设计与使用步骤

教学设计

学习目标

  1. 借助单位圆理解 sin、cos、tan 的定义：角终边与圆交点的坐标（或斜率）。
  2. 观察三角函数图像随角连续变化的生成过程，能读出特殊角的三角函数值。

易错点预设

  • 把 sin 画成 x 坐标——金色线段是纵坐标（正弦），紫色才是横坐标（余弦）。
  • tan 在 90° 附近「消失」的原因：终边竖直，斜率不存在。

环节设计

环节学生活动教师提问资源状态
认一认（约 5 分）读 60° 时三条彩色线段与圆上点的坐标「金线段长是哪个值？对应点坐标怎么写？」mode=sin，theta=60，暂停
描一描（约 6 分）播放键自动扫过一个周期，看正弦曲线被逐点描出「角从 0 转到 360°，曲线为什么先升后降再来一遍？」mode=sin，theta=30，播放中
辨一辨（约 5 分）切到 tan，观察 45° 的切线段，试着拖向 90°「为什么接近 90° 时蓝色线段猛地变长又消失？」mode=tan，theta=45，暂停
找规律（约 4 分）读 150° 的 sin 值，联系诱导公式 sin(180°-α)=sin α「150° 和 30° 的正弦为什么一样大？」mode=sin，theta=150，暂停

板书式小结

设角 α 的终边与单位圆交于 P(x, y)，则 sin α = y（金），cos α = x（紫），tan α = y/x（蓝，α ≠ 90°）。图像就是这三个值随角连续变化的轨迹；sin(180° - α) = sin α，cos(180° - α) = -cos α。

教学设计

学习目标

  1. 经历用平面截正方体的过程，认识截面可以是三角形、四边形、五边形、六边形。
  2. 迁移到旋转体：了解平面截圆锥所得曲线（圆、椭圆等）随角度变化。

易错点预设

  • 以为截面最多是四边形——斜着切能切出六边形，让学生亲手动一次。
  • 把「截面形状」与「切口位置」混淆：同一几何体不同角度截面形状不同。

环节设计

环节学生活动教师提问资源状态

课堂用法

  1. 全屏打开，默认正方体、过中心的斜平面，左上角显示截面：六边形。拖动画面旋转，从不同角度确认金色截面落在正方体内。
  2. 只动倾角滑杆：0° 时是正方形，慢慢加大依次出现五边形、六边形；再拖平移滑杆把平面移出几何体，观察截面消失。每一步先请学生说出预测，再看左上角的形状名对照。
  3. 切换圆柱、圆锥：圆柱倾角 0° 得到圆，斜切得到椭圆；圆锥斜切角度不同，左上角会在椭圆、抛物线、双曲线之间切换（平面与轴的交角和母线倾角的关系）。拖开切开滑杆，把两半分开检查截面。
  4. 每个环节配了「讲解」弹层：引导语抛问题，讲解词给「边数=相交面数」与圆锥截线的夹角判据；点「检测」做 5 题。
